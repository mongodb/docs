===========================================================
Install the MongoDB Agent to Monitor or Back Up Deployments
===========================================================

.. meta::
   :description: Install the MongoDB Agent on Windows, Linux, Ubuntu, Debian, or RHEL to monitor or back up MongoDB deployments in Ops Manager without placing them under Automation management.

.. default-domain:: mongodb

.. _automation-agent-install-steps:
.. _automation-agent-install-steps-monitor:
.. _mongodb-agent-install-steps:
.. _mongodb-agent-install-from-package:
.. _mongodb-agent-install-from-archive:

Install the {+mdbagent+} on each host that runs a MongoDB process you
want to monitor, back up, or both. This workflow doesn't place those
deployments under {+aagent+} management.

Before you install the {+mdbagent+}, review the
:ref:`install-mongodb-agent-prereq`.
