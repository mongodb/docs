.. _update-mongodb-agent:

=========================================
Update Legacy Agents to the {+mdbagent+}
=========================================

.. meta::
   :description: Update your legacy Ops Manager Monitoring, Backup, and Automation Agents to the unified MongoDB Agent by following the appropriate transition scenario.
   :robots: noindex, nosnippet

.. default-domain:: mongodb

.. contents:: On this page
   :local:
   :backlinks: none
   :depth: 1
   :class: singlecol

The {+mdbagent+} replaces the legacy {+magent+}, {+bagent+}, and
{+aagent+} Agents with a single unified agent. The procedure you follow
depends on which legacy Agents your hosts run and whether {+aagent+}
manages them.

Update Scenarios
----------------

Choose the scenario that matches your project:

.. list-table::
   :header-rows: 1
   :widths: 40 60

   * - Scenario
     - When to Use

   * - :ref:`update-mongodb-agent-from-all-agents`
     - Your project has automated MongoDB deployments that use
       {+magent+}, {+bagent+}, or both.

   * - :ref:`update-mongodb-agent-from-monitoring-agent`
     - Your project has monitored MongoDB deployments that {+aagent+}
       doesn't manage.

   * - :ref:`update-mongodb-agent-from-backup-and-monitoring-agents`
     - Your project has monitored and backed up MongoDB deployments
       that {+aagent+} doesn't manage.

   * - :ref:`update-mongodb-agent-from-automation-agent`
     - Your project has automated MongoDB deployments that include both
       {+aagent+}-managed and standalone {+bagent+} and {+magent+}
       Agents.

Each scenario lists the prerequisites to review before you start and
the steps to complete after the update finishes.
