.. step:: Finish the setup.

   In Atlas, click :guilabel:`Done` to exit the creation page.

   .. tip::

      To manage this configuration later, open the
      :guilabel:`Atlas Managed MCP` card on the :guilabel:`Service Accounts`
      page. Click the ellipsis (:guilabel:`...`) icon in the configuration's
      row, then click :guilabel:`View Details` to generate or revoke client
      secrets and update the configuration's name, roles, and API access
      list. You can also delete the configuration from this card.
