=============================================
Connect to and Query Data with Free SQL Tools
=============================================

.. meta::
   :description: Connect to an Atlas dedicated cluster or a federated database instance using the free MongoDB JDBC Driver and DBeaver, then run MongoSQL queries against your data.

This tutorial guides you through connecting to an {+service+}
{+dedicated-cluster+} or a {+fdi+} with the free tools MongoDB |jdbc|
Driver and DBeaver (Community Edition).

If you loaded sample data into your deployment, this tutorial also
guides you through querying it.

Before you start, configure your deployment to accept SQL connections.
To learn how, see :ref:`connect-with-sql-composable`.

Install Client Software
-----------------------

Install the following client software to connect to and query your data 
with {+asql+}.

.. procedure::
   :style: normal

   .. step:: Install DBeaver

      DBeaver is a free, universal database tool. You can use it to 
      explore your sample data in this tutorial. Download and install 
      `DBeaver (Community Edition) <https://dbeaver.io/download/>`__.

   .. step:: Install the JDBC Driver

      .. include:: /includes/jdbc-list-download.rst

Connect from DBeaver
--------------------

Choose your deployment type to get your connection string and configure
DBeaver:

.. composable-tutorial::
   :options: deployment-type, atlas-deployment
   :defaults: atlas, dedicated

   .. selected-content::
      :selections: atlas, dedicated

      .. procedure::
         :style: normal

         .. include:: /includes/nav/steps-db-deployments-page.rst

         .. step:: On the {+cluster+} card, click :guilabel:`Connect`.

         .. step:: Click :guilabel:`Atlas SQL`.

            The option is under
            :guilabel:`Access your data through tools`.

            If the {+cluster+} reports that the {+sql-interface+} isn't
            enabled, click :guilabel:`Configure Atlas SQL` and enable it
            first. {+service+} applies the change asynchronously, so the
            connection details can take a few minutes to appear.

         .. step:: Select your driver.

            From :guilabel:`Select your driver`, select
            :guilabel:`JDBC Driver`.

         .. step:: Copy your connection information.

            Under :guilabel:`Get Connection String`, copy the
            :guilabel:`Connection URL`. You'll need this in a later
            step.

         .. include:: /includes/configure-dbeaver-steps.rst

   .. selected-content::
      :selections: atlas, federated

      .. procedure::
         :style: normal

         .. include:: /includes/nav/steps-data-federation.rst

         .. step:: On the federated database card, click
            :guilabel:`Connect`.

            A connection dialog box opens.

         .. step:: Click :guilabel:`Atlas SQL`.

         .. step:: Select your driver.

            From :guilabel:`Select your driver`, select
            :guilabel:`JDBC Driver`.

         .. step:: Copy your connection information.

            Select a database from the :guilabel:`Database` dropdown,
            then click :icon-lg:`Copy` to copy the connection string.
            You'll need this in a later step.

         .. include:: /includes/configure-dbeaver-steps.rst

To learn more about the different methods you can use to connect, see
:ref:`sql-connect`.

Run {+asql+} Queries
------------------------------------

To run {+asql+} queries in DBeaver:

.. procedure::
   :style:  normal

   .. step:: Expand your MongoDB connection. 

      The DBeaver :guilabel:`Database Navigator` displays your 
      virtual databases.

   .. step:: Open a SQL console.
     
      a. Right-click the virtual database you want to query.
      
      #. Select :guilabel:`SQL Editor`.

      #. Select :guilabel:`Open SQL console`.

         A new SQL console window opens connected to the virtual 
         database you selected.

   .. step:: Enter a SQL query in the console.

   .. step:: Click :guilabel:`Execute SQL Statement` to run your SQL query.
      
      If the query is successful, {+asql+} displays the results in a 
      table view below your query.

Example {+asql+} Queries
~~~~~~~~~~~~~~~~~~~~~~~~

If you loaded sample data into your deployment, try running the
following {+asql+} queries against it.

Otherwise, you can modify these example queries for your namespaces.

SELECT Statement
````````````````

.. code-block:: sh
   :copyable: true
      
   SELECT * 
   FROM Sessions

{+asql+} returns all documents from the ``Sessions`` collection.

LIMIT Statement
```````````````

.. code-block:: sh
   :copyable: true
      
   SELECT * 
   FROM Users 
   LIMIT 2

{+asql+} returns two documents from the ``Users`` collection.

WHERE Statement
```````````````

.. code-block:: sh
   :copyable: true
      
   SELECT * 
   FROM Users 
   WHERE name = 'Jon Snow'

{+asql+} returns documents from the ``Users`` collection where the 
user's ``name`` is ``Jon Snow``.

For an {+asql+} command reference, see :ref:`sql-reference`.
