.. _agentengine_context_delete:

agentengine context delete
--------------------------

Delete a named platform target from this machine.

Synopsis
~~~~~~~~

Delete context NAME from ~/.agentengine/contexts.json.

This removes only the local context; its organization, project,
workspaces, saved login, directory pins, and registrations are left in
place. Directories pinned to the deleted context stop resolving until
they are pinned to another context.

Interactive use asks for confirmation; --yes skips the prompt, and --json
requires --yes.

.. code-block:: bash

   agentengine context delete NAME [flags]

Examples
~~~~~~~~

.. code-block:: bash

     agentengine context delete staging
     agentengine context delete staging --yes

Options
~~~~~~~

.. code-block:: bash

     -h, --help   help for delete
         --json   Output JSON
     -y, --yes    Skip the interactive confirmation prompt
