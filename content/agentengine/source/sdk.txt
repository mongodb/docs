Overview
--------

You can use the {+platform-short+} SDK to build AI agents that run on the
{+platform-short+} platform. The platform manages execution, state, and tool
calls so your agent code only manages the model and the workflow. The SDK is
available for the following languages and frameworks:

- LangGraph (TypeScript and Python)
- Google ADK (Python)

See the :ref:`Atlas Agent Engine CLI<agentengine>` for supporting command-line interactions.
