This section documents the reStructuredText (RST) markup, custom
directives, and roles used to author MongoDB documentation. Use
these pages to look up the syntax and available options for the
markup elements you use most often.

`Syntax <https://docutils.sourceforge.io/docs/ref/rst/restructuredtext.html>`__
   Documentation for the RST markup used in MongoDB documentation.

`Docutils Directives <http://docutils.sourceforge.net/docs/ref/rst/directives.html>`__
   Documentation for the custom directives used in MongoDB documentation.

`Sphinx Documentation <http://www.sphinx-doc.org/en/stable/contents.html>`__
   Documentation for the Sphinx tool.

   Information on types of the conditional directives and examples of their usage.

:doc:`/reference/code-blocks/`
   Information on how to use code block directives. For guidance on code example
   types, guidelines, and formatting, see the  :ref:`code-examples-landing`
   section.

   Learn how to use substitutions.
