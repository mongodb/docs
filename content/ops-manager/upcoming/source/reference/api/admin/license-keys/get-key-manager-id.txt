=========================================
Get the Key Manager ID of an Installation
=========================================

.. default-domain:: mongodb

.. meta::
   :description: Retrieve the holderId, shown as the Key Manager ID in the Ops Manager interface, that identifies your installation. This endpoint requires the Global Owner role.

.. contents:: On this page
   :local:
   :backlinks: none
   :depth: 1
   :class: singlecol

Retrieves the Key Manager ID of an |mms| installation. The Key Manager
ID identifies the installation, including every instance in a
high-availability setup. The Key Portal uses it to issue a license key
for your installation. |mms| returns it in the ``holderId`` field and
rejects a license key that MongoDB issued for a different Key Manager
ID.

Required Roles
--------------

To access this resource, your |api| key must have
the :authrole:`Global Owner` role. The Global Owner role is the
highest role in |mms|. Only users with this role can view and manage
license keys.

Request
-------

Send a ``GET`` request to retrieve the Key Manager ID.

.. include:: /includes/api/base-api-uri.rst

.. code-block:: http

   GET /admin/artifacts/identity

~~~~~~~~~~~~~~~~~~~~~~~

This endpoint doesn't use HTTP request path parameters.

.. include:: /includes/api/base-query-single-parameters.rst

Response
--------

The response contains the following field:

.. list-table::
   :header-rows: 1
   :widths: 30 15 55
   :stub-columns: 1

   * - Field
     - Type
     - Description

   * - ``holderId``
     - string
     - Key Manager ID of the |mms| installation.

Example Request
---------------

Use ``curl`` to send a ``GET`` request to the ``/admin/artifacts/identity`` endpoint:

.. code-block:: sh

   curl --user "{PUBLIC-KEY}:{PRIVATE-KEY}" --digest \
        --header "Accept: application/json" \
        --include \
        --request GET \
        "https://{+opsmgr-url+}/api/public/v1.0/admin/artifacts/identity?pretty=true"
