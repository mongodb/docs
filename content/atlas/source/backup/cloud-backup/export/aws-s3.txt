===========================================
Export {+Cloud-Backup+} Snapshots to AWS S3
===========================================

.. default-domain:: mongodb

.. contents:: On this page
   :local:
   :backlinks: none
   :depth: 2
   :class: singlecol

.. include:: /includes/fact-atlas-free-tier-limits.rst

|service| lets you export your {+Cloud-Backup+} snapshots to |aws|
|s3| buckets. You can export snapshots over the public network or over
|aws| PrivateLink. You can export snapshots in two ways:

- To automatically export snapshots as your :ref:`backup policy
  <configure-backup-policy>` creates them, see
  :ref:`cloud-backup-configure-snapshot-policy-aws`.
- To manually export a single existing snapshot, see
  :ref:`cloud-backup-create-export-job-aws`.

Each procedure requires the same
:ref:`prerequisites <cloud-backup-export-prereqs-aws>`.

For an overview of how {+service+} exports snapshots and the files it
uploads, see :ref:`cloud-provider-snapshot-export`.

.. note::

   To ensure the immutability of your backup files for compliance
   and security, you can enable `AWS S3 Object Lock
   <https://docs.aws.amazon.com/AmazonS3/latest/userguide/object-lock-configure.html>`__.
   Object locks prevent deletions and modifications of exported
   backup files.
