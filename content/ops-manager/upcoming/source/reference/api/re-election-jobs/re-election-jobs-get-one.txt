====================================
Get One Replica Set Re-Election Job
====================================

.. meta::
   :description: Use the Ops Manager API to retrieve the status of a single replica set re-election job by its unique identifier, including whether it completed, failed, or expired.

.. default-domain:: mongodb

.. contents:: On this page
   :local:
   :backlinks: none
   :depth: 1
   :class: singlecol

.. include:: /includes/fact-groups-projects-synonyms.rst

Use this endpoint to retrieve a single re-election job by its unique
identifier. Poll this endpoint until the job reaches a terminal
status.

.. include:: /includes/api/base-api-uri.rst

Resource
--------

.. code-block:: http
   :copyable: false

   GET /groups/{GROUP-ID}/replicaSets/{RS-ID}/reElectionJobs/{REELECTION-JOB-ID}

Required Roles
--------------

The API key that makes this request must have the ``Project
Automation Admin`` role.

Request Path Parameters
~~~~~~~~~~~~~~~~~~~~~~~~

.. list-table::
   :widths: 20 14 11 55
   :header-rows: 1
   :stub-columns: 1

   * - Name
     - Type
     - Necessity
     - Description

   * - GROUP-ID
     - string
     - Required
     - Unique 24-hexadecimal digit string that identifies your
       project.

   * - RS-ID
     - string
     - Required
     - Name of the replica set that contains the re-election job.

   * - REELECTION-JOB-ID
     - string
     - Required
     - Unique 24-hexadecimal digit string that identifies the
       re-election job, as returned by the step down or step up
       endpoint.

Response
--------

The response returns a single re-election job.

.. list-table::
   :widths: 20 14 66
   :header-rows: 1
   :stub-columns: 1

   * - Name
     - Type
     - Description

   * - id
     - string
     - Unique 24-hexadecimal digit string that identifies the
       re-election job.

   * - groupId
     - string
     - Unique 24-hexadecimal digit string that identifies the
       project.

   * - action
     - string
     - Action that this job performs. Returns one of the following
       values: ``STEP_DOWN`` or ``STEP_UP``.

   * - replicaSetName
     - string
     - Name of the target replica set.

   * - hostname
     - string
     - Hostname of the target process.

   * - port
     - integer
     - Port of the target process.

   * - status
     - string
     - Status of the job. Returns one of the following values:
       ``QUEUED``, ``RUNNING``, ``COMPLETED``, ``FAILED``, or
       ``EXPIRED``.

   * - noOp
     - boolean
     - Flag that indicates whether the operation completed as a
       no-op.

   * - message
     - string
     - Human-readable detail about the job. |mms| populates this
       field after the agent reports a result.

   * - created
     - string
     - Timestamp, in ISO 8601 UTC format, when |mms| created the job.

   * - lastUpdated
     - string
     - Timestamp, in ISO 8601 UTC format, when |mms| last updated the
       job.

   * - expires
     - string
     - Timestamp, in ISO 8601 UTC format, after which an Automation
       Agent no longer picks up this job.

Job Status Values
~~~~~~~~~~~~~~~~~

.. list-table::
   :widths: 20 14 66
   :header-rows: 1

   * - Status
     - Terminal
     - Meaning

   * - QUEUED
     - No
     - |mms| created the job. It is waiting for the target host's
       Automation Agent to pick it up.

   * - RUNNING
     - No
     - The agent is running the job.

   * - COMPLETED
     - Yes
     - The operation finished. Check ``noOp`` to determine whether
       the operation made a change.

   * - FAILED
     - Yes
     - The operation could not complete. See ``message`` for the
       reason.

   * - EXPIRED
     - Yes
     - No agent picked up the job before ``expiresAfterSeconds``
       elapsed.

Example Request
---------------

.. code-block:: sh
   :linenos:

   curl --user "{PUBLIC-KEY}:{PRIVATE-KEY}" --digest \
        --header "Accept: application/json" \
        --include \
        --request GET "https://{+opsmgr-url+}/api/public/v1.0/groups/{GROUP-ID}/replicaSets/{RS-ID}/reElectionJobs/{REELECTION-JOB-ID}?pretty=true"

Response Codes
--------------

.. list-table::
   :widths: 14 26 60
   :header-rows: 1

   * - HTTP Status
     - Error Code
     - Description

   * - 200
     - --
     - Returns the re-election job document.

   * - 401
     - USER_UNAUTHORIZED
     - The API key does not have the ``Project Automation Admin``
       role.

   * - 404
     - REELECTION_JOB_NOT_FOUND
     - ``REELECTION-JOB-ID`` is unknown or malformed, or the job does
       not belong to the replica set named in ``RS-ID``.
