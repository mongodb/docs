The {+platform-short+} GitHub App is not available during Public
Preview. You can't install the app on your GitHub organization, so
you can't use the :guilabel:`Connect Repository` flow in the
{+platform-short+} UI, create a workspace from a GitHub repository, or
recieve GitHub App webhook events.

To create and deploy a workspace during Public Preview, run the
``agentengine deploy`` command from a local clone of your repository
instead.
