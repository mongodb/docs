agentengine dev mcp
-------------------

Prepare remote MCP server credentials for agentengine dev.

Synopsis
~~~~~~~~

Prepare remote MCP server credentials for agentengine dev.

OAuth credentials are cached per project under the CLI user state
directory at ~/.agentengine/mcp-oauth// and mounted into dev up stacks.
