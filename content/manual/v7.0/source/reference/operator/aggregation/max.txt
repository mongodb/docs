===========================
$max (accumulator operator)
===========================

.. meta::
   :description: Use the $max accumulator in MongoDB to return the maximum value across a group of input documents in $group, $bucket, $bucketAuto, and other aggregation stages.

.. Substitution used in includes and in the body of this text
.. |operatorName| replace:: ``$max``

.. contents:: On this page
   :local:
   :backlinks: none
   :depth: 1
   :class: singlecol

Definition
----------

.. group:: $max

Returns the maximum value. ``$max`` compares both value and
type, using the :ref:`specified BSON comparison order
<bson-types-comparison-order>` for values of different types.

The ``$max`` accumulator is available in these stages:

- :pipeline:`$bucket`
- :pipeline:`$bucketAuto`
- :pipeline:`$group`

.. note:: Disambiguation

   This page describes ``$max`` when used as an **accumulator**.
   Accumulators return a single aggregated value like sum, maximum,
   or minimum across a group of input documents.

   You can also use ``$max`` in these other contexts:

   - :expression:`$max (expression) <$max>`, which returns the
     maximum value from an array or a list of values.

   - :window:`$max (window function) <$max>`, which is used in
     the :pipeline:`$setWindowFields` stage to return the maximum
     value from documents in a particular window.

Syntax
------

.. code-block:: javascript
   :copyable: false

   { $max: <expression> }

Array Operand
~~~~~~~~~~~~~

In the :pipeline:`$group` stage, if the expression resolves to an
array, ``$max`` does not traverse the array and compares the
array as a whole.

The preceding pipeline:

- Uses :pipeline:`$match` to filter for movies with a common US
  rating, a valid IMDb rating, and a known runtime.
- Sorts documents by ``rated`` to ensure consistent grouping
  order.
- Uses :pipeline:`$group` with ``$max`` to find the highest IMDb
  rating and longest runtime for each ``rated`` group.
- Sorts the output alphabetically by rating category.
