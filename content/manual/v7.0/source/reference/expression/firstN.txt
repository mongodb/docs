====================
$firstN (expression)
====================

.. meta::
   :description: Use `$firstN` to return the first `n` elements from an array.

.. contents:: On this page
   :local:
   :backlinks: none
   :depth: 1
   :class: singlecol

Definition
----------

.. expression:: $firstN 

Returns the specified number of elements from the beginning of an array.

.. note:: Disambiguation

   This page describes ``$firstN`` when used as an **expression**, which
   returns the specified number of elements from the beginning of an array.

   You can also use ``$firstN`` in these other contexts:

   - :group:`$firstN (accumulator) <$firstN>`, used in grouping to
     return the first ``n`` elements from each group.

   - :window:`$firstN (window function) <$firstN>`, which is used in the
     :pipeline:`$setWindowFields` stage to return the first ``n`` values
     from documents in a particular window.

Syntax
------

.. code-block:: javascript

   { $firstN: { input: <expression>, n: <expression> } }

Options
~~~~~~~

.. list-table::
   :header-rows: 1
   :widths: 20 20 80

   * - Field
     - Type
     - Description

   * - ``input``
     - Expression
     - The array from which to return the first ``n`` elements.
   
   * - ``n``
     - Expression
     - The number of elements that ``$firstN`` returns. Must resolve to a
       positive integer.

Behavior
--------

- ``$firstN`` returns elements in the same order they appear in 
  the input array.

- ``$firstN`` does not filter out ``null`` values in the input 
  array.

- You cannot specify a value of ``n`` less than ``1``.

- If the specified ``n`` is greater than or equal to the number of
  elements in the ``input`` array, ``$firstN`` returns the entire
  ``input`` array. 

- If ``input`` resolves to a non-array value, the aggregation operation 
  errors.

The preceding pipeline:

- Uses :pipeline:`$match` to filter for three specific movies.
- Uses :pipeline:`$addFields` with ``$firstN`` to create a new field
  ``firstThreeCast`` containing the first three elements from the
  ``cast`` array with ``n: 3``.
- Uses :pipeline:`$project` to include only the ``title``, ``cast``,
  and ``firstThreeCast`` fields in the output.
- Uses :pipeline:`$sort` to sort the results by title.
