.. _typescript-packages-agent-engine-sdk-docs-api-anycontentblockschema:

AnyContentBlockSchema
---------------------

.. code-block:: typescript

   const AnyContentBlockSchema: ZodDiscriminatedUnion<[ZodObject<{
     text: ZodString;
     type: ZodDefault<ZodLiteral<"text">>;
   }, $strip>, ZodObject<{
     mime_type: ZodOptional<ZodString>;
     type: ZodDefault<ZodLiteral<"image">>;
     url: ZodString;
   }, $strip>, ZodObject<{
     filename: ZodOptional<ZodString>;
     mime_type: ZodOptional<ZodString>;
     type: ZodDefault<ZodLiteral<"document">>;
     url: ZodString;
   }, $strip>], "type">;

Discriminated on ``type`` so a document block is never misparsed as an
image (a plain union would match ``{ url }`` against
``ImageBlockSchema`` first and silently drop ``filename``). Inputs must
carry an explicit ``type``.
