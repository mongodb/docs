==========================================================
Access the FOCUS Cost and Usage Report in |cloudgov-short|
==========================================================

.. meta::
   :description: Generate and download your Atlas for Government billing data in the industry-standard FOCUS format from the Invoices page in the console or with the FOCUS Data API.

The `FinOps Open Cost and Usage Specification (FOCUS)
<https://focus.finops.org/focus-specification/>`__ establishes uniform
requirements for technology billing datasets. |cloudgov| provides
billing cost and usage data in the FOCUS 1.3 format. You can generate
a FOCUS report from the :guilabel:`Invoices` page in the
|cloudgov-short| console or with the FOCUS Data API.

|cloudgov-short| supports the FOCUS cost and usage report in the same
way as |service|, except that the FOCUS Data API uses a different base
URL. To learn about the FOCUS format and the report columns, see the
|service| documentation:
:atlas:`Access the FOCUS Cost and Usage Report </billing/focus-report/>`.

Download a FOCUS Report from the Console
----------------------------------------

You can download the FOCUS cost and usage report for an invoice from
the :guilabel:`Invoices` page in the |cloudgov-short| console. Select
:guilabel:`CSV FOCUS Cost & Usage Report` when you choose the invoice
format.

To download the report for the current billing period, see
:ref:`download-current-invoice`. To download the report for a past
billing period, see :ref:`download-past-invoices`.

.. note::

   To view and download billing data, you must have the
   :authrole:`Organization Billing Admin`,
   :authrole:`Organization Owner`, or
   :authrole:`Organization Billing Viewer` role.

FOCUS Data API Base URL
-----------------------

The |cloudgov-short| FOCUS Data API uses the following base URL:

.. code-block:: none

   https://cloud.mongodbgov.com/api/atlas/v2

The endpoints, request parameters, and responses are otherwise the
same as in |service|.

Authentication
~~~~~~~~~~~~~~

The |cloudgov-short| FOCUS Data API extends the
{+atlas-admin-api+} and uses the same authentication methods. To learn
more, see :ref:`api`.

Considerations
--------------

|cloudgov-short| is designed with additional security, compliance, and
operational considerations. To learn how these considerations affect
feature availability, see :ref:`gov-considerations`.
