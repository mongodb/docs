=====================================
Get All Hosts with Replication Health
=====================================

.. meta::
   :description: Use the v2.0 Ops Manager Public API to retrieve all hosts in a project, including the tooStale and lastReplError replication health fields for each member.

.. default-domain:: mongodb

.. contents:: On this page
   :local:
   :backlinks: none
   :depth: 1
   :class: singlecol

.. include:: /includes/fact-groups-projects-synonyms.rst

Returns all hosts in the project, including the replication health of
each host's replica set member.

.. include:: /includes/api/base-api-v2-uri.rst

Resource
--------

.. code-block:: http
   :copyable: false

   GET /groups/{PROJECT-ID}/hosts

Required Roles
--------------

The API key that makes this request must have the
:authrole:`Project Read Only` role.

Request Path Parameters
~~~~~~~~~~~~~~~~~~~~~~~

.. list-table::
   :widths: 20 14 11 55
   :header-rows: 1
   :stub-columns: 1

   * - Name
     - Type
     - Necessity
     - Description

   * - PROJECT-ID
     - string
     - Required
     - Unique 24-hexadecimal digit string that identifies your
       project.

.. include:: /includes/api/no-body-parameters.rst

Response
--------

.. include:: /includes/api/get-all-note.rst

Each **result** is one host and contains the same fields as the v1.0
endpoint.

.. include:: /includes/api/list-tables/hosts/response.rst

The v2.0 endpoint also returns the following fields for each host.

.. list-table::
   :widths: 20 14 66
   :header-rows: 1
   :stub-columns: 1

   * - Name
     - Type
     - Description

   * - tooStale
     - boolean
     - ``true`` if this member fell behind the oplog window and cannot
       catch up. The member requires an initial sync.

   * - lastReplError
     - string
     - The member's last replication error, from the ``errmsg``
       field of ``rs.status()``.

Both fields describe each host's own member entry in its replica set,
not the whole replica set. |mms| omits them for hosts that aren't
replica set members, and omits ``lastReplError`` when the member
reports no error.

Example Request
---------------

The following example retrieves all hosts in the project.

.. code-block:: sh
   :linenos:

   curl --user "{PUBLIC-KEY}:{PRIVATE-KEY}" --digest \
        --header "Accept: application/json" \
        --include \
        --request GET "https://{+opsmgr-url+}/api/public/v2.0/groups/{PROJECT-ID}/hosts?pretty=true"
