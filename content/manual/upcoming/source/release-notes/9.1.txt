General Changes
---------------

Detach Output Streams
~~~~~~~~~~~~~~~~~~~~~

Starting in MongoDB 9.1, when starting :program:`mongod` or
:program:`mongos` as a system :term:`daemon`, you can configure whether
the instance detaches the standard streams (``stdout`` and ``stderr``)
and redirects their output to ``/dev/null``.

To prevent the instance from detaching these streams while running in
the background, set the configuration setting or appropriate option
to ``false``:

- :setting:`processManagement.forkDetachesOutputStreams`
- :option:`mongod --forkDetachesOutputStreams`
- :option:`mongos --forkDetachesOutputStreams`

Server Status
~~~~~~~~~~~~~

MongoDB 9.1 adds the following :dbcommand:`serverStatus` metrics:

- :serverstatus:`metrics.query.out.countFailedOverQuota`
- :serverstatus:`metrics.query.out.countInvokedWithQuota`
