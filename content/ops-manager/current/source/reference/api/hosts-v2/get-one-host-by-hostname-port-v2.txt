=========================================================
Get One Host by Hostname and Port with Replication Health
=========================================================

.. meta::
   :description: Use the v2.0 Ops Manager Public API to retrieve one host by hostname and port, including the tooStale and lastReplError replication health fields for its member.

.. default-domain:: mongodb

.. contents:: On this page
   :local:
   :backlinks: none
   :depth: 1
   :class: singlecol

.. include:: /includes/fact-groups-projects-synonyms.rst

Returns one host by its hostname and port, including the replication
health of the host's replica set member.

.. include:: /includes/api/base-api-v2-uri.rst

Resource
--------

.. code-block:: http
   :copyable: false

   GET /groups/{PROJECT-ID}/hosts/byName/{HOSTNAME-PORT}

Required Roles
--------------

The API key that makes this request must have the
:authrole:`Project Read Only` role.

Request Path Parameters
~~~~~~~~~~~~~~~~~~~~~~~

.. list-table::
   :widths: 20 14 11 55
   :header-rows: 1
   :stub-columns: 1

   * - Name
     - Type
     - Necessity
     - Description

   * - PROJECT-ID
     - string
     - Required
     - Unique 24-hexadecimal digit string that identifies your
       project.

   * - HOSTNAME-PORT
     - string
     - Required
     - The host, as ``hostname:port``. For example,
       ``node1.example.com:27017``.

.. include:: /includes/api/no-body-parameters.rst

Response
--------

The response contains the same fields as the v1.0 endpoint.

.. include:: /includes/api/list-tables/hosts/response.rst

The v2.0 endpoint also returns the following fields.

.. list-table::
   :widths: 20 14 66
   :header-rows: 1
   :stub-columns: 1

   * - Name
     - Type
     - Description

   * - tooStale
     - boolean
     - ``true`` if this member fell behind the oplog window and cannot
       catch up. The member requires an initial sync.

   * - lastReplError
     - string
     - The member's last replication error, from the ``errmsg``
       field of ``rs.status()``.

Both fields describe this host's own member entry in its replica set.
|mms| omits them for hosts that aren't replica set members, and omits
``lastReplError`` when the member reports no error.

Example Request
---------------

The following example retrieves the host running on
``node1.example.com:27017``.

.. code-block:: sh
   :linenos:

   curl --user "{PUBLIC-KEY}:{PRIVATE-KEY}" --digest \
        --header "Accept: application/json" \
        --include \
        --request GET "https://{+opsmgr-url+}/api/public/v2.0/groups/{PROJECT-ID}/hosts/byName/node1.example.com:27017?pretty=true"

Response Codes
--------------

.. list-table::
   :widths: 14 26 60
   :header-rows: 1

   * - HTTP Status
     - Error Code
     - Description

   * - 200
     - --
     - Returns the host document.

   * - 404
     - HOSTNAME_AND_PORT_NOT_FOUND
     - ``HOSTNAME-PORT`` doesn't match a host in the project.

Other response codes match the v1.0 endpoint.
