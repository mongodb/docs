.. step:: Copy the MCP client configuration.

   In the :guilabel:`Auth helper` card, select your AI client from the
   :guilabel:`Provider` dropdown, then click the copy icon on the code
   block.

.. step:: Write your MCP client configuration.

   Open your AI client's MCP configuration file in your project or home
   directory, paste the block that you copied in the previous step, and
   save the file.

.. step:: Finish the setup.

   In Atlas, click :guilabel:`Done` to exit the creation page.

   .. tip::

      You can manage this configuration at any time from the
      :guilabel:`Atlas Managed MCP` card on the
      :guilabel:`Service Accounts` page. Click the ellipsis
      (:guilabel:`...`) icon in the configuration's row, then click
      :guilabel:`View Details`. From the detail page, you can generate
      or revoke client secrets and update the configuration's name,
      roles, and API access list. You can delete the configuration
      at any time from the :guilabel:`Atlas Managed MCP` card.
