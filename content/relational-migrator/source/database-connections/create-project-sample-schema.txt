============================================
Use Relational Migrator With a Sample Schema
============================================

.. meta::
   :description: Create a Relational Migrator project from the pre-defined Northwind sample schema. No relational database is required to model your data and build mapping rules.

.. default-domain:: mongodb

.. contents:: On this page
   :local:
   :backlinks: none
   :depth: 1
   :class: singlecol

You can create a project using a pre-defined sample schema. The sample
schema allows you to try {+rel-mig+} even if you don't have a relational
database to connect to.

About this Task
---------------

Creating a project with a sample schema is the quickest and easiest way 
to test drive {+rel-mig+}.

.. include:: /includes/project-initial-mappings-att.rst

Steps
-----

These steps create a project from the sample schema. You don't need a
relational database connection to complete them.

1. In {+rel-mig+}, click :guilabel:`New Project` at the top-right of the
   {+rel-mig+} home screen.

#. Click the :guilabel:`Create sample` button.

#. From the :guilabel:`Select tables` screen, indicate the tables you want to migrate and click :guilabel:`Next`.
   
   The tabs below explain the different ways you can select tables to migrate: 
   
   .. include:: /includes/steps-select-tables.rst

#. Choose a :guilabel:`Global casing` option for collection names. 
   
   This option affects the names of your collections created from the
   tables in your relational database:

   - :guilabel:`Keep Original`: Keep the original casing used in your relational
     database table name.

   - :guilabel:`Override with Global Casing`: Override the original table name
     with a global casing convention.

     - ``camelCase``
     - ``TitleCase``
     - ``kebab-case``
     - ``snake_case``
     - ``UPPER_SNAKE_CASE``

#. Choose an :guilabel:`Initial mappings` option for your MongoDB schema.

   .. include:: /includes/project-initial-mappings.rst

#. Enter a name for your project.

#. Click :guilabel:`Done`.

Add Sample Data (Optional)
--------------------------

Migration jobs and other features require a live connection to a
relational database. MongoDB provides a sample relational database so
that you can test those features with the project that you created. The
sample database is a PostgreSQL instance of ``Northwind``, packaged as a
Docker container.

To start the container, run the following command:

.. code-block::

   docker run -p 5432:5432 public.ecr.aws/v4d7k6c9/relational-migrator-sample-database

The database listens on port ``5432``. The username and password are
both ``postgres``. Use these credentials to add the container to your
project as a connection. To learn more, see
:ref:`rm-connect-to-postgres`.
