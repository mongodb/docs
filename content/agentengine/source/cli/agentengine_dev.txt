.. _agentengine_dev:

agentengine dev
---------------

Local dev environment commands.

Synopsis
~~~~~~~~

Manage the local development environment.

Two modes are available:

Hot reload (default): One app container runs the application processes
and file watching restarts them on change. Isolated (--isolated): One
container per process, matching the production topology. Changes require
a rebuild.

Options
~~~~~~~

.. code-block:: bash

     -h, --help   help for dev
