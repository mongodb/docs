Overview
--------

|mms| retains snapshots for the number of days specified in the
:setting:`Base Retention of Snapshots (in Days)` setting. This procedure changes
how long |mms| retains *one specific snapshot*.

If you change the retention policy in the
:ref:`snapshot schedule <edit-snapshot-schedule>`, the new policy
applies only to snapshots taken after you make the change. Existing
snapshots keep their current expiration dates. Use the following
procedure to change how long |mms| retains an existing snapshot.

.. seealso::

   To learn more about snapshot frequency, retention policies, and monthly
   snapshots being full by default, see :ref:`snapshot-frequency-and-retention`.
