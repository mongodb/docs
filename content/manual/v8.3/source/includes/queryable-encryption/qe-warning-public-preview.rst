.. note:: 

   MongoDB 8.3 includes a public preview version of prefix, suffix, and 
   substring queries. Do not enable these preview query types in production.

   {+qe+} prefix, suffix, and substring queries are generally available (GA)
   in MongoDB 9.0. To use these query types in production, 
   `upgrade to MongoDB 9.0
   <https://www.mongodb.com/docs/manual/release-notes/9.0-compatibility/#std-label-qe-prefix-suffix-substring-preview-to-ga-migration>`__.
