agentengine context create
--------------------------

Create a named platform target.

Synopsis
~~~~~~~~

Create a context named NAME binding a platform base URL, organization,
and project. Without --org-id or --project-id this prompts with the
organizations and projects visible to your current login. --base-url
defaults to the only platform you are logged into, and is required when
you are logged into more than one.

Creating a name that already exists fails; a context cannot be rebound
yet.

.. code-block:: bash

   agentengine context create NAME [flags]

Examples
~~~~~~~~

.. code-block:: bash

     agentengine context create prod
     agentengine context create local --base-url http://localhost:30050

Options
~~~~~~~

.. code-block:: bash

         --base-url string     Platform API base URL (default: your current login, if you are logged into only one platform; required otherwise)
     -h, --help                help for create
         --json                Output JSON
         --org-id string       Organization ID (default: prompts)
         --project-id string   Project ID (default: prompts)
