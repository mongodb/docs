Bug Fixes
~~~~~~~~~

.. list-table::
   :header-rows: 1
   :widths: 70 15 15

   * - Description
     - Available in Community Edition
     - Available in Enterprise Advanced

   * - **httpcore5 security upgrade.** ``mongot`` used httpcore5 and
       httpcore5-h2 versions affected by CVE-2026-54428. Both libraries
       are upgraded to 5.4.3. *Fixed in v1.70.4.*
     - |checkmark|
     - |checkmark|

   * - **Unauthenticated requests could exhaust memory or crash**
       ``mongot``. Before authentication, a client could send messages
       with oversized or forged length fields, including in SCRAM
       authentication payloads. These messages could cause ``mongot``
       to exhaust memory or stop with an ``OutOfMemoryError``.
       ``mongot`` now limits these payload sizes before authentication.
       *Fixed in v1.70.4.*
     - |checkmark|
     - |checkmark|

   * - **Security dependency upgrades.** Third-party libraries with
       known CVEs were updated: Jackson upgraded to 2.18.9
       (CVE-2026-54515), Netty (CVE-2026-59903), Micrometer
       (CVE-2026-59296), and Bouncy Castle. The Docker base images
       were also upgraded. *Fixed in v1.70.4.*
     - |checkmark|
     - |checkmark|
