LLM_CREDENTIAL_REJECTED_ERROR_CODE
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

.. code-block:: typescript

   const LLM_CREDENTIAL_REJECTED_ERROR_CODE: "llm_credential_rejected" = "llm_credential_rejected";

Machine-readable discriminator set on ``metadata.error_code`` when the
LLM provider rejected the configured credential (HTTP 401/403). Unlike
``llm_invocation_failed`` this is deliberately stamped WITHOUT
``metadata.source``: the fix is the customer's own project secret, and
the gateway's owner switch maps the bare code to client-owned, whereas
an ``llm`` source would attribute it to provider flakiness.

--------------

LLM_INVOCATION_ERROR_CODE
^^^^^^^^^^^^^^^^^^^^^^^^^

.. code-block:: typescript

   const LLM_INVOCATION_ERROR_CODE: "llm_invocation_failed" = "llm_invocation_failed";

Machine-readable discriminator set on ``metadata.error_code`` of an
ERROR chunk/callback when the agent's LLM call failed after OE approval
(provider 401/404, rate limit, etc.). ``metadata.source`` is ``llm`` so
invoke attribution does not have to string-match the error prose.

--------------

LLM_INVOCATION_ERROR_SOURCE
^^^^^^^^^^^^^^^^^^^^^^^^^^^

.. code-block:: typescript

   const LLM_INVOCATION_ERROR_SOURCE: "llm" = "llm";

Owner attribution for LLM-provider failures. Must match the gateway
invoke-owner source switch.

TEXT
^^^^

.. code-block:: typescript

   const TEXT: "text" = "text";

Wire-protocol constants for AER → OE stream chunks.

Centralized so a typo in one site can't silently desync the consumer.
Values are stable strings forwarded verbatim through OE to the API
gateway and on to the UI; do not rename without coordinating across all
three layers (and the Go-side StreamChunk model).

--------------

TIMEOUT_ERROR_CODE
^^^^^^^^^^^^^^^^^^

.. code-block:: typescript

   const TIMEOUT_ERROR_CODE: "timeout" = "timeout";

Machine-readable discriminator set on ``metadata.error_code`` of an
ERROR chunk/callback when a tool or LLM call exceeds its deadline. Older
runners also use this code for whole-turn expiry, so consumers cannot
assume which deadline a bare timeout describes.

--------------

TOOL_CREDENTIAL_REJECTED_ERROR_CODE
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

.. code-block:: typescript

   const TOOL_CREDENTIAL_REJECTED_ERROR_CODE: "tool_credential_rejected" = "tool_credential_rejected";

Same carrier when a run fails because a tool call's classified
external-API failure was an auth rejection (AUTH_FAILED): the rejected
credential is one of the project's secrets for that tool, not the LLM
key. Also stamped without ``metadata.source`` so the code drives
client-owned attribution.
