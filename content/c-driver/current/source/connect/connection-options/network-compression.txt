Version Compatibility
---------------------

The following table lists the minimum supported driver and
{+mdb-server+} version for each compression algorithm:

.. list-table::
   :header-rows: 1
   :stub-columns: 1

   * - Compression Algorithm
     - Minimum Driver Version
     - Minimum Server Version

   * - `Snappy <https://google.github.io/snappy/>`__
     - 1.7
     - 4.2

   * - `Zlib <https://zlib.net/>`__
     - 1.7
     - 4.2

   * - `Zstandard <https://facebook.github.io/zstd/>`__
     - 1.15
     - 4.2

.. _c-enable-compression:

Enable Network Compression
--------------------------

To enable network compression for your MongoDB connection, build
the {+driver-short+} with the required dependencies and specify the
compression algorithms that you want to use.

.. _c-compression-dependencies:

Install Dependencies
~~~~~~~~~~~~~~~~~~~~

The following table lists each algorithm and the dependency it
requires, if any:

.. list-table::
   :header-rows: 1
   :widths: 30 70

   * - Compression Algorithm
     - Dependency

   * - Snappy
     - Install the Snappy library. To view installation instructions, see
       the :github:`snappy </google/snappy>` GitHub repository.

   * - Zlib
     - None. The driver bundles Zlib by default.

   * - Zstandard
     - Install the Zstandard library. To view installation instructions,
       see the :github:`zstd </facebook/zstd>` GitHub repository.

Specify Compression Algorithms
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

You can enable compression for the connection to your MongoDB instance
by specifying the algorithms in one of the following ways:

- Add the ``compressors`` parameter to your connection string
- Set the compressors on a ``mongoc_uri_t`` struct

Select the :guilabel:`Connection String` or :guilabel:`URI Option` tab
to view an example that specifies all available compressors:

.. include:: /includes/connect/compression-tabs.rst

Zlib Compression Level
~~~~~~~~~~~~~~~~~~~~~~

When you use the Zlib algorithm, you can specify a compression level
from ``-1`` to ``9``. Lower levels generally provide faster
compression with a lower compression ratio, and higher levels provide
slower compression with a higher compression ratio.

Select the :guilabel:`Connection String` or :guilabel:`URI Option` tab
to view an example that specifies a compression level for
the ``zlib`` compressor:

.. include:: /includes/connect/zlib-level-tabs.rst
