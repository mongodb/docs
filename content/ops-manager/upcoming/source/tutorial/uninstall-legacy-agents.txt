====================
Remove Legacy Agents
====================

.. meta::
   :description: Uninstall legacy Backup and Monitoring Agents from Ops Manager and servers after installing the MongoDB Agent.

.. default-domain:: mongodb

.. contents:: On this page
   :local:
   :backlinks: none
   :depth: 1
   :class: singlecol

The legacy Backup and Monitoring Agents can be removed after the
{+mdbagent+} has been
:ref:`installed <install-agent>`.

.. _delete-backup-agent:

Remove the Backup Agent from |mms|
----------------------------------

Stop the Backup Agent
~~~~~~~~~~~~~~~~~~~~~

If you installed the Backup Agent using an ``rpm`` package, such as
on RHEL, CentOS, or SUSE, issue the following command to stop the
agent:

.. code-block:: none

   sudo service mongodb-mms-backup-agent stop

If you installed the Backup Agent using a ``deb`` package, as on
Ubuntu, issue the following command to stop the agent:

.. code-block:: none

   sudo stop mongodb-mms-backup-agent

If you installed the Backup Agent to Linux or macOS using a ``tar``
file, issue the following command to stop the agent:

.. code-block:: none

   pkill -f mongodb-mms-backup-agent

To stop the Backup Agent on Windows, open ``Administrative Tools``
in the Windows ``Control Panel`` and then open ``Services``. In the
list of services, select ``MongoDB Backup Agent``, open the
``Action`` menu, and select ``Stop``.

Remove from |mms|
~~~~~~~~~~~~~~~~~

To remove a Backup Agent from |mms|, stop the agent and then wait 24
hours.

Delete from the Server
~~~~~~~~~~~~~~~~~~~~~~

To delete the Backup Agent **from a Linux or macOS server**, stop the
agent and then remove the ``mongodb-mms-backup-agent`` file from the
``/usr/bin`` directory. If you installed the agent using a ``tar.gz``
file, the agent is in the directory you chose during installation.

To delete the Backup Agent **from a Windows server**, stop the agent
and then use the Windows program uninstaller to remove the
``MongoDB Backup Agent`` program.

.. _delete-monitoring-agent:

Remove Monitoring Agents from |mms|
-----------------------------------

Stop the Monitoring Agent
~~~~~~~~~~~~~~~~~~~~~~~~~

If you installed the Monitoring Agent using an ``rpm`` package, such as
on RHEL, CentOS, or SUSE, issue the following command to stop the
agent:

.. code-block:: none

   sudo service mongodb-mms-monitoring-agent stop

If you installed the Monitoring Agent using a ``deb`` package, as on
Ubuntu, issue the following command to stop the agent:

.. code-block:: none

   sudo stop mongodb-mms-monitoring-agent

If you installed the Monitoring Agent to Linux or macOS using a ``tar``
file, issue the following command to stop the agent:

.. code-block:: none

   pkill -f mongodb-mms-monitoring-agent

To stop the Monitoring Agent on Windows, open ``Administrative Tools``
in the Windows ``Control Panel`` and then open ``Services``. In the
list of services, select ``MongoDB Monitoring Agent``, open the
``Action`` menu, and select ``Stop``.

Remove from |mms|
~~~~~~~~~~~~~~~~~

To remove a Monitoring Agent from |mms|, stop the agent and then wait
5 minutes.

When an agent fails to ping |mms| for 5 minutes, |mms| views the agent
as inactive and distributes the agent's assignments to other agents
(if available).

.. note::

   The :guilabel:`All Agents` page displays an inactive agent for 24
   hours before |mms| removes it from the page.

Delete from the Server
~~~~~~~~~~~~~~~~~~~~~~

To delete the Monitoring Agent **from a Linux or macOS server**, stop
the agent and then remove the ``mongodb-mms-monitoring-agent`` file
from the ``/usr/bin`` directory. If you installed the agent using a
``tar.gz`` file, the agent is in the directory you chose during
installation.

To delete the Monitoring Agent **from a Windows server**, stop the
agent and then use the Windows program uninstaller to remove the
``MongoDB Monitoring Agent`` program.
