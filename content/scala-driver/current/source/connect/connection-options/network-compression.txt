Overview
--------

The {+driver-short+} provides a connection option to compress
messages, which reduces the amount of data passed over the network
between MongoDB and your application.

The driver supports the following algorithms:

- `Snappy <https://google.github.io/snappy/>`__
- `Zlib <https://zlib.net/>`__
- `Zstandard <https://facebook.github.io/zstd/>`__

If you specify multiple compression algorithms, the driver selects the
first one in the list that your MongoDB instance supports.

.. _scala-compression-dependencies:

Compression Algorithm Dependencies
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

The Java Development Kit (JDK) supports `Zlib <https://zlib.net/>`__
compression. However, Snappy and Zstandard depend on open source Java
implementations, and you must add explicit dependencies for those
algorithms. The driver tests against the following versions:

- ``{+snappy-version+}``
- ``{+zstd-version+}``

To learn more, see the `snappy-java
<https://github.com/xerial/snappy-java>`__ and `zstd-jni
<https://github.com/luben/zstd-jni>`__ GitHub pages.

.. _scala-enable-compression:

Specify Compression Algorithms
-------------------------------

You can enable compression for the connection to your MongoDB
instance by specifying the algorithms in one of the following ways:

- In the ``compressors`` parameter of your connection string
- In the ``compressorList`` method chained to the
  ``MongoClientSettings.builder()`` method
