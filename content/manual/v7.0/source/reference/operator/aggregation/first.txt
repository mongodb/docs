=============================
$first (accumulator operator)
=============================

.. meta::
   :description: Use $first to return a value for the first document in a group, for use in `$group`, `$bucket`, and `$bucketAuto` stages.

.. contents:: On this page
   :local:
   :backlinks: none
   :depth: 1
   :class: singlecol

Definition
----------

.. group:: $first

Returns the result of an :ref:`expression <aggregation-expressions>` for
the first document in a group of documents. Only meaningful when
documents are in a defined order.

The ``$first`` accumulator is available in these stages:

- :pipeline:`$bucket`
- :pipeline:`$bucketAuto`
- :pipeline:`$group`

.. note:: Disambiguation

   This page describes ``$first`` when used as an **accumulator**.
   Accumulators return a single aggregated value like sum, maximum, or
   minimum across a group of input documents.

   You can also use ``$first`` in these other contexts:

   - :expression:`$first (expression) <$first>`, which returns the first
     element of an array.
   - :window:`$first (window function) <$first>`, which is used in the
     :pipeline:`$setWindowFields` stage to return a value for the first
     document in a window.

Syntax
------

.. code-block:: javascript

   { $first: <expression> }

Behavior
--------

Define Document Order
~~~~~~~~~~~~~~~~~~~~~

To define document order for ``$first`` in a grouping stage, add a
preceding :pipeline:`$sort` stage.

.. _first-missing-values-example:

Missing Values
~~~~~~~~~~~~~~

Documents in a group may be missing fields. ``$first`` handles missing
values as follows:

- If there are no documents from the prior pipeline stage, the
  :pipeline:`$group` stage returns nothing.

- If the field that the ``$first`` accumulator is processing is
  missing, ``$first`` returns ``null``.

``null`` value for the ``_id`` field. When the accumulator field is
missing (``quantity`` in this example), ``$first`` returns ``null``.

In the preceding pipeline:

- :pipeline:`$sort` orders movies by ``year`` in ascending order, then
  ``title`` in alphabetical order.
- :pipeline:`$unwind` creates a separate document for each genre in the
  ``genres`` array, maintaining the sort order established by the
  previous stage.
- :pipeline:`$group` with ``$first`` returns the ``title`` and ``year``
  of the first movie (earliest by year, then alphabetically by title)
  for each genre.
- A second :pipeline:`$sort` sorts the results alphabetically
  by genre.
- :pipeline:`$limit` restricts the output to 5 genres.
