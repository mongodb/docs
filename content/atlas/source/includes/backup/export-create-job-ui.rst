.. step:: Create a snapshot export job.

   a. In the :guilabel:`Snapshot` tab, click the
      :icon-fa5:`ellipsis-v` :guilabel:`Actions` menu for the
      snapshot that you want to export.

      This displays the snapshot details.

   #. From the dropdown, select :guilabel:`Export`.

      This displays the :guilabel:`Export Snapshot` dialog box.

   #. From the :guilabel:`Export bucket` dropdown, select the export
      bucket that you want to use.

   #. Click :guilabel:`Export`.

      This starts the export job and displays the :guilabel:`Exports`
      tab.

   #. Click :guilabel:`Refresh` to view the export job status.
