To create outbound |vpc| peering connections from your {+spw+}
to your cloud provider |vpc| using the {+atlas-ui+}, see
:ref:`Add an Atlas Stream Processing Connection
<atlas-sp-add-connection>` and select :guilabel:`Apache Kafka`
as your connection type, and :guilabel:`Atlas UI` as your
interface.

You must select ``SASL_SSL`` as your security protocol for |vpc|
peering connections.
