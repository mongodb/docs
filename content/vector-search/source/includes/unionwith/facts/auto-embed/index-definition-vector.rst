The ``multiple-models-search`` index definition indexes the
following field:

- ``plot_embedding`` field, which contains pre-computed embeddings
  that represent a movie's plot summary generated by the OpenAI 
  ``text-embedding-ada-002`` embedding model.

  This field mapping is required for the :ref:`third use case
  <avs-unionwith-use-cases>`.

This field uses the ``vector`` :ref:`type <avs-types-vector>` and
``dotProduct`` :ref:`similarity <avs-similarity-functions>`. The
``1536``-dimensional embeddings are generated by the OpenAI
``ada-v2`` embedding model.
