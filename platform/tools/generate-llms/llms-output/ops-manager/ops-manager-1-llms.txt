# Ops Manager - (current) (Part 1 of 5)

> Ops Manager automates, monitors, and backs up your MongoDB infrastructure, with core administration features, a data explorer, and a performance advisor.

- [Administration Console](https://www.mongodb.com/docs/ops-manager/current/admin-console.md): Access the administration console in Ops Manager if you have the Global Owner role.
- [Administration Console : Alerts Tab](https://www.mongodb.com/docs/ops-manager/current/admin/admin-tab-alerts.md): Access and manage global and system alerts in the Ops Manager Admin interface, including project-level alert conditions and system health monitoring for deployments.
- [Administration Console : Backup Tab](https://www.mongodb.com/docs/ops-manager/current/admin/admin-tab-backup.md): Access and manage Ops Manager Backup resources, including jobs, daemons, blockstores, oplog stores, and snapshot storage, from the Admin interface Backup tab.
- [Administration Console : Control Panel Tab](https://www.mongodb.com/docs/ops-manager/current/admin/admin-tab-control-panel.md): Use the Control Panel tab in the Ops Manager Administration Console to review email and SMS alert notification history and send test messages to verify delivery.
- [Administration Console : General Tab](https://www.mongodb.com/docs/ops-manager/current/admin/admin-tab-general.md): Access system topology, users, API keys, audit events, MongoDB version manifest, and configuration settings through the Ops Manager Administration Console General tab.
- [Daemons](https://www.mongodb.com/docs/ops-manager/current/admin/backup/daemons-page.md)
- [Deployment Regions for Backup Regionalization](https://www.mongodb.com/docs/ops-manager/current/admin/backup/deployment-regions-page.md)
- [Groom Priority](https://www.mongodb.com/docs/ops-manager/current/admin/backup/groom-priority-page.md): View and manage the status of backup jobs and blockstores in Ops Manager. Schedule groom and integrity check jobs, or move blocks between blockstores.
- [Grooms](https://www.mongodb.com/docs/ops-manager/current/admin/backup/grooms-page.md)
- [Job Timeline](https://www.mongodb.com/docs/ops-manager/current/admin/backup/job-timeline-page.md)
- [Jobs](https://www.mongodb.com/docs/ops-manager/current/admin/backup/jobs-page.md): Manage Backup jobs and resources in Ops Manager, including assigning projects to Backup Daemons, configuring WTCheckpoint settings, viewing job logs, and setting up KMIP.
- [System Logs](https://www.mongodb.com/docs/ops-manager/current/admin/backup/logs-page.md): Explore Ops Manager system logs by job and class, with message counts for the last two hours, day, and three days.
- [Manage Oplog Stores](https://www.mongodb.com/docs/ops-manager/current/admin/backup/oplog-stores-page.md): Configure and manage local and S3 oplog stores used by Ops Manager to store oplog slices for continuous backup and point-in-time restore of replica sets.
- [Backup Job and Project Resource Usage](https://www.mongodb.com/docs/ops-manager/current/admin/backup/resource-usage-page.md): View size, throughput, and graph-based resource usage statistics for Ops Manager backup jobs and projects, including network, disk, oplog, and SnapshotStore metrics for each job.
- [Restores](https://www.mongodb.com/docs/ops-manager/current/admin/backup/restores-page.md)
- [Snapshot Storage](https://www.mongodb.com/docs/ops-manager/current/admin/backup/snapshot-storage-page.md)
- [Snapshots for Ops Manager Admin](https://www.mongodb.com/docs/ops-manager/current/admin/backup/snapshots-page.md): View backup snapshot details and metadata in the Ops Manager Admin interface, including snapshot timestamps, completion status, transfer speed, duration metrics, file counts, and storage size.
- [Alert Email History](https://www.mongodb.com/docs/ops-manager/current/admin/controlpanel/email-history-page.md): View and filter the list of alert emails sent by Ops Manager and their recipients to audit notification delivery or troubleshoot missing or delayed alerts.
- [Send a Test Message to Ops Manager Users](https://www.mongodb.com/docs/ops-manager/current/admin/controlpanel/send-test-message-page.md): Send test email or SMS messages to users from Ops Manager to verify that notification addresses are valid and alert delivery channels are configured correctly.
- [Alert :abbr:`SMS (short message service)` History](https://www.mongodb.com/docs/ops-manager/current/admin/controlpanel/sms-history-page.md): View and filter the history of alert SMS messages sent by Ops Manager and their recipients to audit notification delivery or troubleshoot missing alerts.
- [API Keys Page](https://www.mongodb.com/docs/ops-manager/current/admin/general/api-keys-page.md)
- [Ops Manager Audits](https://www.mongodb.com/docs/ops-manager/current/admin/general/audits-page.md): View all events tracked by Ops Manager, including group-level, internal, and system events, to review administrative actions and satisfy compliance requirements.
- [Global Access List](https://www.mongodb.com/docs/ops-manager/current/admin/general/global-access-list-page.md)
- [Logs Page](https://www.mongodb.com/docs/ops-manager/current/admin/general/logs-page.md): Explore backup logs by job and class, with messages grouped and counted over different time periods.
- [Messages Page](https://www.mongodb.com/docs/ops-manager/current/admin/general/messages-page.md): View and manage messages added to the Ops Manager interface for user notifications and events.
- [MongoDB Usage Page](https://www.mongodb.com/docs/ops-manager/current/admin/general/mongodb-usage-page.md)
- [Ops Manager Config Page](https://www.mongodb.com/docs/ops-manager/current/admin/general/ops-manager-config-page.md): Update Ops Manager settings including email and SMS notification providers, backup configuration, and other system-level options through the General tab Config page.
- [Overview Page](https://www.mongodb.com/docs/ops-manager/current/admin/general/overview-page.md)
- [Projects Page](https://www.mongodb.com/docs/ops-manager/current/admin/general/projects-page.md)

- [Version Manifest Page](https://www.mongodb.com/docs/ops-manager/current/admin/general/version-manifest-page.md): View all released MongoDB versions in the Ops Manager version manifest, which is required for running Ops Manager in local mode without internet access.
