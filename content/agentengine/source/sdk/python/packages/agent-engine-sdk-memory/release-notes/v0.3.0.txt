agent-engine-sdk-memory v0.3.0
==============================

Bug fixes
---------

- Episodic search on a bound handle now returns consolidated
  (agent-extracted) memories. Previously, ``bind(session_id=...)``
  followed by ``search_episodes()`` (or ``search()`` over episodic)
  injected the bound session into the query. Since consolidated episodic
  memory is stored without a session, the exact match returned an empty
  list with no error. ``record_turn`` and ``build_context`` still scope
  by the bound session.

Breaking changes
----------------

- **Episodic search session scope:** ``search_episodes``,
  ``list_episodes``, and the episodic leg of ``search()`` no longer
  inherit ``session_id`` from ``bind()`` or the ambient runtime. A
  caller that relied on a bound session scoping an episodic read must
  now pass ``session_id=`` explicitly on that call. Conversation I/O
  (``record_turn``, ``build_context``) is unchanged.
