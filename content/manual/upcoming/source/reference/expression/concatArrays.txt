==========================
$concatArrays (expression)
==========================

.. meta::
   :description: Use the $concatArrays expression in MongoDB aggregation to concatenate two or more arrays into a single array containing all their elements within a single document.

.. contents:: On this page
   :local:
   :backlinks: none
   :depth: 1
   :class: singlecol

.. facet::
   :name: genre
   :values: reference

Definition
----------

.. expression:: $concatArrays

Returns a single array that concatenates two or more arrays.

.. note:: Disambiguation

   This page describes ``$concatArrays`` when used as an **expression**,
   which concatenates two or more arrays into a single array within a
   single document.

   You can also use ``$concatArrays`` in these other contexts:

   - :group:`$concatArrays (accumulator) <$concatArrays>`, which
     concatenates the array values from a field across a group of
     documents.

   - :window:`$concatArrays (window function) <$concatArrays>`, which
     is used in the :pipeline:`$setWindowFields` stage to concatenate
     the array values from a field across a window of documents.

Syntax
------

When used as an expression, ``$concatArrays`` has the following syntax:

.. code-block:: javascript
   :copyable: false
   :category: syntax example

   { $concatArrays: [ <expression1>, <expression2>, ... ] }

Behavior
--------

.. include:: /includes/fact-array-expr.rst

If any argument resolves to a value of ``null`` or refers to a field
that is missing, :expression:`$concatArrays` returns ``null``.

The following table shows how ``$concatArrays`` handles arrays and
nested arrays:

.. list-table::
   :header-rows: 1
   :widths: 60 40
   :class: border-table

   * - Example
     - Results

   * - .. code-block:: javascript
          :copyable: false

          { $concatArrays: [
             [ "hello", " " ], [ "world" ]
          ] }

     - .. code-block:: javascript
          :copyable: false

          [ "hello", " ", "world" ]

   * - .. code-block:: javascript
          :copyable: false

          { $concatArrays: [
             [ "hello", " " ],
             [ [ "world" ], "again" ]
          ] }

     - .. code-block:: javascript
          :copyable: false

          [ "hello", " ", [ "world" ], "again" ]

Limitations
-----------

``$concatArrays`` only supports arrays and expressions that resolve to
an array.
