================
Window Functions
================

.. meta::
   :description: Explore MongoDB window functions for use in $setWindowFields. Reference for $topN, $bottomN, $first, $last, $avg, $sum, and other windowed aggregation operators.

Window functions are used in :pipeline:`$setWindowFields` to return an
aggregated value based on documents in a particular window.
