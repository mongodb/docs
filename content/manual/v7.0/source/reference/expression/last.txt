==================
$last (expression)
==================

.. meta::
   :description: Use $last as an expression in aggregation pipeline stages like $project and $addFields to return the last element of the input array.

.. contents:: On this page
   :local:
   :backlinks: none
   :depth: 1
   :class: singlecol

Definition
----------

.. expression:: $last

Returns the last element of an array.

.. note:: Disambiguation

   This page describes ``$last`` when used as an **expression**, which
   returns the last element of an array.

   You can also use ``$last`` in these other contexts:

   - :group:`$last (accumulator) <$last>`, used in grouping to return
     a value for the last document in each group.
   - :window:`$last (window function) <$last>`, used in the
     :pipeline:`$setWindowFields` stage to return a value for the last
     document in a window.

Syntax
------

.. code-block:: javascript
   :copyable: false
   :category: syntax example

   { $last: <expression> }

The ``<expression>`` must evaluate to an array.

Behavior
--------

- If the array is empty, ``$last`` returns ``null``.

- If the expression evaluates to ``null`` or refers to a missing field,
  ``$last`` returns ``null``.

In the preceding pipeline:

- :pipeline:`$match` filters for three specific movies.
- :pipeline:`$addFields` with ``$last`` creates a new field ``lastCast``
  containing the last element of the ``cast`` array.
- :pipeline:`$project` includes only the ``title``, ``cast``,
  and ``lastCast`` fields in the output.
- :pipeline:`$sort` sorts the results by title.
