==================================
$percentile (accumulator operator)
==================================

.. meta::
   :description: Use $percentile as an accumulator in the $group aggregation stage to return an array of approximate percentile values across a group of input documents.

.. contents:: On this page
  :local:
  :backlinks: none
  :depth: 1
  :class: singlecol

.. Substitution used in includes and in the body of this text
.. |operatorName| replace:: ``$percentile``

Definition
----------

.. group:: $percentile

   .. versionadded:: 7.0

   .. include:: /includes/aggregation/fact-return-percentile.rst

   Available in these stages:

   - :pipeline:`$bucket`
   - :pipeline:`$bucketAuto`
   - :pipeline:`$group`

   .. note:: Disambiguation

      This page describes ``$percentile`` when used as an
      **accumulator**. Accumulators return an aggregated value across a
      group of input documents.

      You can also use ``$percentile`` in these other contexts:

      - :expression:`$percentile (expression) <$percentile>`, which
        calculates percentile values over an array of input values.

      - :window:`$percentile (window function) <$percentile>`, which
        is used in the :pipeline:`$setWindowFields` stage to return
        an array of percentile values for documents in a particular
        window.

Syntax
------

.. code-block:: javascript
   :copyable: false
   :category: syntax example

   {
      $percentile: {
         input: <expression>,
         p: [ <expression1>, <expression2>, ... ],
         method: <string>
      }
   }

.. _percentile-calculation-considerations:

Behavior
--------

When used as an accumulator, |operatorName|:

- Calculates one set of percentiles per group, aggregated across all
  documents in the group.
- Uses the `t-digest <https://arxiv.org/abs/1902.04023>`__ algorithm
  for calculation of approximate percentiles. Approximation is
  necessary to calculate percentiles using a data structure of
  bounded size.

Calculation Considerations
~~~~~~~~~~~~~~~~~~~~~~~~~~

When used as an accumulator, |operatorName| always uses an approximation
algorithm. Due to pseudorandomness in the t-digest approximation
algorithm, the computed percentile values on the same data set might
differ on each run. Additionally, |operatorName| may return values that
differ slightly from the true statistical percentiles.

Calculate Rating Percentiles by Genre
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

The following example uses the ``$percentile`` accumulator to
calculate the 50th and 90th percentile IMDB ratings for movies in
the ``Action`` and ``Drama`` genres:

.. io-code-block::
   :copyable: true

   .. input:: /code-examples/tested/command-line/mongosh/aggregation/accumulators/percentile/rating-percentiles-by-genre.js
      :language: javascript
      :category: usage example

   .. output:: /code-examples/tested/command-line/mongosh/aggregation/accumulators/percentile/rating-percentiles-by-genre-output.sh
      :visible: false
      :language: javascript

The preceding pipeline:

- Uses :pipeline:`$unwind` to create a separate document for each
  genre in the ``genres`` array.
- Uses :pipeline:`$match` to filter for movies that are classified
  as ``Action`` or ``Drama`` and have an IMDB rating field.
- Groups movies by genre.
- Uses ``$percentile`` to calculate the 50th and 90th percentile
  IMDB ratings for each genre with ``p: [0.5, 0.9]``.
- Uses :pipeline:`$sort` to order the output by genre name.

The output ``ratingPercentiles`` array contains two values: the
50th percentile and the 90th percentile IMDB rating for each genre.
