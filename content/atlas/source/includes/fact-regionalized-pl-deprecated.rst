.. important:: Deprecation

   The regionalized private endpoint setting is deprecated and will
   be removed after August 1, 2028. Until then, projects that use the
   setting continue to work without changes.

   For new deployments, use :ref:`private endpoint connection strings
   <private-endpoint-connection-strings-resource>` instead. If your
   project opts in to connection strings, you can't change the
   regionalized private endpoint setting, and you select regions for
   each connection string instead.
