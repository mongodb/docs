.. _k8s-deploy-mdb-resources:

==================================
Deploy a MongoDB Database Resource
==================================

.. meta::
   :description: Deploy MongoDB instances, replica sets, or sharded clusters using Kubernetes Operator, with optional Prometheus monitoring.

.. default-domain:: mongodb

.. contents:: On this page
   :local:
   :backlinks: none
   :depth: 1
   :class: singlecol

:ref:`deploy-standalone`
  Use |k8s-op-short| to deploy a new standalone MongoDB instance.
  Deprecated in |k8s-op-short| 1.15. Deploy a one-member replica set
  instead. To migrate an existing standalone deployment, see
  :ref:`migrate-standalone-to-replica-set`.

:ref:`deploy-replica-set`
  Use |k8s-op-short| to deploy a replica set.

:ref:`deploy-sharded-cluster`
  Use |k8s-op-short| to deploy a sharded cluster.

:ref:`deploy-prometheus`
  Use |k8s-op-short| to deploy a MongoDB resource to use with
  Prometheus monitoring enabled.

:ref:`migrate-standalone-to-replica-set`
  Migrate a standalone deployment to a one-member replica set.

:ref:`k8s-migration-om-to-kubernetes`
  Migrate a self-managed deployment into Kubernetes under
  |k8s-op-short|.
