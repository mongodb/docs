Changed
~~~~~~~

- ``SessionMessage.role`` for human-authored session-history messages is
  now documented and emitted as ``"user"`` instead of ``"human"``,
  matching the live invoke/stream ``Message.role`` vocabulary (``user``,
  ``assistant``, ``tool``, ``system``).
- ``MemoryClient.buildContext`` rejects non-positive, non-integer, and
  non-finite ``maxTokens`` with ``RangeError`` before sending the
  request.
