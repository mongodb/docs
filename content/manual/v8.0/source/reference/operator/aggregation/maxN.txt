============================
$maxN (accumulator operator)
============================

.. meta::
   :description: Use `$maxN` to aggregate the maximum `n` values within a group, filtering out null and missing values, and compare it with `$topN` for sorting needs.

.. default-domain:: mongodb

.. contents:: On this page
   :local:
   :backlinks: none
   :depth: 1
   :class: singlecol

.. Substitution used in includes and in the body of this text
.. |operatorName| replace:: ``$maxN``
.. |operatorOrder| replace:: highest

Definition
----------

.. group:: $maxN

   Returns an aggregation of the maximum value ``n`` elements within a
   group. If the group contains fewer than ``n`` elements, ``$maxN``
   returns all elements in the group.

The ``$maxN`` accumulator is available in these stages:

- :pipeline:`$bucket`
- :pipeline:`$bucketAuto`
- :pipeline:`$group`

.. note:: Other Uses of ``$maxN``

   This page describes ``$maxN`` when used as an **accumulator**.
   Accumulators return an aggregated value like sum, maximum,
   or minimum across a group of input documents.

   You can also use ``$maxN`` in these other contexts:

   - :expression:`$maxN (expression) <$maxN>`, which returns the
     largest ``n`` values from an array.

   - :window:`$maxN (window function) <$maxN>`, which is used in the
     :pipeline:`$setWindowFields` stage to return the largest ``n``
     values from documents in a particular window.

Syntax
------

.. code-block:: javascript
   :category: syntax example
   :copyable: false

   {
      $maxN:
         {
            input: <expression>,
            n: <expression>
         }
   }

.. list-table::
   :header-rows: 1
   :class: border-table
   :widths: 10 15 75

   * - Field
     - Type
     - Description

   * - ``input``
     - Expression
     - The expression evaluated for each element in the group. ``$maxN``
       preserves the maximum ``n`` values.

   * - ``n``
     - Expression
     - The number of elements that ``$maxN`` returns from the group.
       For an example of setting ``n`` dynamically, see
       :ref:`max-n-with-group-key`.

Null and Missing Values
~~~~~~~~~~~~~~~~~~~~~~~

``$maxN`` filters out null and missing values.

The following aggregation demonstrates how ``$maxN`` handles null and
missing values:

.. io-code-block::
   :copyable: false

   .. input::
      :language: javascript
      :category: syntax example
      :emphasize-lines: 7,8

      db.aggregate( [
         {
            $documents: [
               { title: "Fight Club", genre: "Drama", rating: 8.9 },
               { title: "The Matrix", genre: "Drama", rating: 8.7 },
               { title: "The Green Mile", genre: "Drama", rating: 8.5 },
               { title: "Magnolia", genre: "Drama" },
               { title: "Dogma", genre: "Drama", rating: null }
            ]
         },
         {
            $group: {
               _id: "$genre",
               topFourRatings: {
                  $maxN: {
                     input: "$rating",
                     n: 4
                  }
               }
            }
         }
      ] )

   .. output::
      :language: javascript

      [
         {
            _id: 'Drama',
            topFourRatings: [ 8.9, 8.7, 8.5 ]
         }
      ]

In this example:

- :pipeline:`$documents` creates the literal documents that contain
  movie ratings.
- :pipeline:`$group` groups the documents by ``genre``. This example
  has only one ``genre``, ``Drama``.
- ``Magnolia`` has a missing ``rating`` and ``Dogma`` has a null
  ``rating``. Both values are filtered out.
- Since only 3 documents have valid ratings, ``$maxN`` returns 3
  values even though ``n = 4``.

Comparison of $maxN and $topN Accumulators
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

You can use ``$maxN`` or :group:`$topN` to return the highest-ranked
``n`` elements from a group. The choice between them depends on
whether your input documents are already sorted.

- If the input documents are already sorted, use ``$maxN`` to return the
  maximum ``n`` values.

- If you need to sort and select the top ``n`` elements at the same time,
  use :group:`$topN` to accomplish both with a single accumulator.
