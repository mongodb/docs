=========================
$eq (expression operator)
=========================

.. meta::
   :description: Compare two values using the `$eq` operator in MongoDB aggregation to check for equivalence in both value and type.

.. contents:: On this page
   :local:
   :backlinks: none
   :depth: 1
   :class: singlecol

Definition
----------

.. expression:: $eq

   Compares two values and returns:

   - ``true`` when the values are equivalent.

   - ``false`` when the values are not equivalent.

   .. include:: /includes/extracts/fact-agg-comparison-expression-eq.rst

   ``$eq`` has this syntax:

   .. code-block:: javascript

      { $eq: [ <expression1>, <expression2> ] }

   The arguments can be any valid :ref:`expression
   <aggregation-expressions>`. For more information on expressions, see
   :ref:`aggregation-expressions`.
