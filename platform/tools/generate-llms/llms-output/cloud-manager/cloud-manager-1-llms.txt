# Cloud Manager (Part 1 of 4)

> Cloud Manager helps you deploy, monitor, and back up MongoDB, with core administration features like a data explorer and a performance advisor.

- [Analyze Slow Queries](https://www.mongodb.com/docs/cloud-manager/analyze-slow-queries.md): Analyze slow queries on your clusters using Cloud Manager tools like Performance Advisor, Query Insights, and Profiler to optimize query performance.
- [Cloud Manager Overview](https://www.mongodb.com/docs/cloud-manager/application.md): Manage your MongoDB infrastructure with Cloud Manager automation, monitoring, and backup features, including real-time reporting and point-in-time recovery.
- [Process International Payments](https://www.mongodb.com/docs/cloud-manager/billing/international-billing.md): Learn how to process international payments with Cloud Manager, including compliance with Strong Customer Authentication and handling VAT for EU customers.
- [View or Download Your Invoices](https://www.mongodb.com/docs/cloud-manager/billing/invoices.md): Access and download current and past invoices in Cloud Manager, with options to filter by status and date, and export in PDF, TXT, or CSV formats.
- [Public :abbr:`API (Application Programming Interface)` Principles](https://www.mongodb.com/docs/cloud-manager/core/api.md): Explore the principles and features of the Cloud Manager Public API, including authentication methods, HTTP methods, JSON formatting, and rate limiting.
- [Backup Preparations](https://www.mongodb.com/docs/cloud-manager/core/backup-preparations.md): Prepare for Cloud Manager backups by reviewing data sizing, snapshot frequency, retention policies, storage engine requirements, and key backup considerations.
- [Manage Your Multi-Factor Authentication Options](https://www.mongodb.com/docs/cloud-manager/core/multi-factor-authentication.md): Manage multi-factor authentication options in Cloud Manager to enhance your account security by configuring Okta Verify, Google Authenticator, or email.
- [Process Payment for Cloud Manager](https://www.mongodb.com/docs/cloud-manager/core/pricing.md): Learn about Cloud Manager pricing, billing methods, and how to manage your billing profile and payment methods.
- [Security Overview](https://www.mongodb.com/docs/cloud-manager/core/security.md): Ensure the security of your Cloud Manager MongoDB deployments with configurable encryption, authentication, and authorization features, including TLS and SCRAM.
- [Interact with Your Data](https://www.mongodb.com/docs/cloud-manager/data-explorer.md): Use the Cloud Manager UI to view, create, and manage databases, collections, indexes, and documents, and run aggregation pipelines.
- [Aggregation Pipeline Builder](https://www.mongodb.com/docs/cloud-manager/data-explorer/cloud-agg-pipeline.md): Explore how to use the Aggregation Pipeline Builder in Cloud Manager to create, modify, and export aggregation pipelines for data processing.
- [Manage Databases and Collections in Data Explorer](https://www.mongodb.com/docs/cloud-manager/data-explorer/databases-collections.md): Manage your cluster's databases and collections using the Data Explorer in Cloud Manager, including creating, viewing, and dropping databases and collections.
- [Manage Documents in Data Explorer](https://www.mongodb.com/docs/cloud-manager/data-explorer/documents.md): Manage documents in your cluster collections using Data Explorer, including inserting, editing, and deleting documents with specified roles and query options.
- [Manage Indexes in Data Explorer](https://www.mongodb.com/docs/cloud-manager/data-explorer/indexes.md): Manage indexes on your collections using the Data Explorer in Cloud Manager, including creating, viewing, and dropping indexes.
- [Frequently Asked Questions](https://www.mongodb.com/docs/cloud-manager/faq.md): Explore answers to common questions about using Cloud Manager for user administration, automation, backup, billing, and monitoring MongoDB instances.
- [MongoDB Cloud Manager](https://www.mongodb.com/docs/cloud-manager/index.md): Manage MongoDB deployments with Cloud Manager automation, monitoring, and backup features, including real-time reporting and point-in-time recovery.
- [Invitations to Organizations and Projects](https://www.mongodb.com/docs/cloud-manager/invitations.md): Access and accept pending invitations to Cloud Manager Organizations and Projects through the Invitations tab.
- [Migrate Deployments](https://www.mongodb.com/docs/cloud-manager/migration.md): Migrate MongoDB deployments to Atlas using live migration methods or `mongorestore`, depending on your version and network configuration.
- [Organizations and Projects](https://www.mongodb.com/docs/cloud-manager/organizations-projects.md): Manage your Cloud Manager deployments with the new organizations and projects hierarchy, allowing shared billing and team assignments across multiple projects.
- [Review Drop Index Recommendations](https://www.mongodb.com/docs/cloud-manager/performance-advisor/drop-indexes.md): Improve write performance and storage by using the Performance Advisor to drop unused, redundant, and hidden indexes in Cloud Manager.
- [Review Index Ranking](https://www.mongodb.com/docs/cloud-manager/performance-advisor/index-ranking.md): Review how the Performance Advisor suggests and ranks indexes based on their impact to improve query performance in Cloud Manager.
- [Improve Your Schema](https://www.mongodb.com/docs/cloud-manager/performance-advisor/schema-advisor.md): Improve your schema using the Cloud Manager Performance Advisor and Data Explorer, which offer schema design suggestions based on MongoDB best practices.
- [Configure the Slow Query Threshold](https://www.mongodb.com/docs/cloud-manager/performance-advisor/slow-query-threshold.md): Configure the slow query threshold in Cloud Manager to optimize query performance by adjusting the `slowms` and `sampleRate` parameters.
- [Monitor Collection-Level Query Latency](https://www.mongodb.com/docs/cloud-manager/query-insights.md): Monitor collection-level query latency with Query Insights, view metrics, manage pinned namespaces, and filter data by host, shard, and time range.
