.. _activity-feed:

==================
View Activity Feed
==================

.. meta::
   :keywords: atlas cli, atlas api, atlas ui
   :description: Access and filter activity feeds in Atlas to view organization and project events, including billing, access, and auto-scaling changes, in the UI, CLI, or API.

.. default-domain:: mongodb

.. facet::
   :name: genre
   :values: tutorial

.. contents:: On this page
   :local:
   :backlinks: none
   :depth: 1
   :class: singlecol

The |service| :guilabel:`Organization Activity Feed` displays select events
that occurred for a given |service| :ref:`organization <create-organization>`,
such as billing or access events.

The |service| :guilabel:`Project Activity Feed` provides more granular detail
about the state of your {+cluster+}. The Project Activity Feed
displays select events that occurred for a given |service|
:ref:`project <create-project>`, such as auto-scaling changes to a
minimum or maximum {+cluster+} tier, log export status changes, and
integration lifecycle events.

Required Access
---------------

To view the Organization Activity Feed, you must have at minimum
:authrole:`Organization Member` access to the organization.

To view the Project Activity Feed, you must have at minimum
:authrole:`Project Read Only` access to the project.

Activity Feed Event Types
-------------------------

For a complete list of all event types that appear in the Activity
Feed, see :ref:`atlas-alert-event-types`.

The following event types are specific to :ref:`log export
<export-logs>`:

- :guilabel:`Log export has failed. Check your integration settings and
  credentials.`
- :guilabel:`Log export is failing after multiple attempts. Logs are
  being queued and will be sent once the connection is restored.`
- :guilabel:`Log export replay has failed to deliver records to an
  external platform, even after an automatic replay attempt. These
  records will be permanently deleted once their retention window
  expires. Contact MongoDB Support to request redelivery.`
- :guilabel:`Log export has recovered. Queued logs are ready to resume
  sending.`
- :guilabel:`Log export has recovered. Queued logs are now being sent.`
- :guilabel:`All queued logs have been delivered to sink.`
