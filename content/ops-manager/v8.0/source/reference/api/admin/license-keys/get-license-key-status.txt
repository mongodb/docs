=============================================
Get the License Key Status of an Installation
=============================================

.. default-domain:: mongodb

.. meta::
   :description: Retrieve the license key status, installed license keys, and active entitlements of your Ops Manager installation. This endpoint requires the Global Owner role.

.. contents:: On this page
   :local:
   :backlinks: none
   :depth: 1
   :class: singlecol

Retrieves the current license key status, the installed license keys,
and the active entitlements of an |mms| installation. |mms| reads the
current status instead of a cached value.

Required Roles
--------------

To access this resource, your |api| key must have
the :authrole:`Global Owner` role. The Global Owner role is the
highest role in |mms|. Only users with this role can view and manage
license keys.

Request
-------

Send a ``GET`` request to retrieve the license key status.

.. include:: /includes/api/base-api-uri.rst

.. code-block:: http

   GET /admin/licenses

Example Request
---------------

Use ``curl`` to send a ``GET`` request to the ``/admin/licenses`` endpoint:

.. code-block:: sh

   curl --user "{PUBLIC-KEY}:{PRIVATE-KEY}" --digest \
        --header "Accept: application/json" \
        --include \
        --request GET \
        "https://{+opsmgr-url+}/api/public/v1.0/admin/licenses?pretty=true"
