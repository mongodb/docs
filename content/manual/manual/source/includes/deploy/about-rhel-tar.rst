
Use this tutorial to manually install MongoDB {+version+} |edition|
Edition on Red Hat Enterprise Linux, CentOS Linux, or Oracle Linux using
a downloaded ``.tgz`` tarball.

.. important::

   MongoDB only supports Oracle Linux running the Red Hat Compatible
   Kernel (RHCK). MongoDB does not support the Unbreakable Enterprise
   Kernel (UEK).
