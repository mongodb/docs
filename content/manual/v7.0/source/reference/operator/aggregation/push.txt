============================
$push (accumulator operator)
============================

.. meta::
   :description: Use $push as an accumulator in $group, $bucket, and $bucketAuto pipeline stages to return an array of all values from documents in a group, including duplicates.

.. contents:: On this page
   :local:
   :backlinks: none
   :depth: 1
   :class: singlecol

Definition
----------

.. group:: $push

Returns an array of all values that result from applying an
:ref:`expression <aggregation-expressions>` to each document in a
group.

The ``$push`` accumulator is available in these stages:

- :pipeline:`$bucket`
- :pipeline:`$bucketAuto`
- :pipeline:`$group`

.. note:: Disambiguation

   This page describes ``$push`` when used as an **accumulator**.
   Accumulators return an aggregated value across a group of input
   documents.

   You can also use ``$push`` in these other contexts:

   - :window:`$push (window function) <$push>`, which is used in the
     :pipeline:`$setWindowFields` stage to return an array of all
     values from documents in a particular window.
   - :update:`$push (update operator) <$push>`, which appends a value
     to an array field in a document.

Syntax
------

.. code-block:: none
   :copyable: false
   :category: syntax example

   { $push: <expression> }

For more information on expressions, see :ref:`aggregation-expressions`.

Behavior
--------

When you use ``$push`` as an accumulator, the order of the documents
coming into the pipeline determines the order of the documents in the
output array. To guarantee a defined order, place a :pipeline:`$sort` stage
before the :pipeline:`$group` stage.

Example
-------

.. include:: /includes/sample-data-usage.rst

The following operation groups movies by director and uses the ``$push``
accumulator to collect the primary genre of each film directed by that
director.

   :copyable: true

   .. input:: /code-examples/tested/command-line/mongosh/aggregation/accumulators/push/run-pipeline.snippet.push-accumulator-example.js
      :language: javascript
      :category: usage example

   .. output:: /code-examples/tested/command-line/mongosh/aggregation/accumulators/push/output.sh
      :visible: false
      :language: javascript

The preceding pipeline:

- Uses :pipeline:`$match` to filter to movies from 2010-2015 that
  have genre and director information.
- Uses :pipeline:`$unwind` to create a separate document for each
  director in the ``directors`` array.
- Groups the resulting documents by director and uses ``$push`` to
  collect the primary genre of each film.
- Sorts the results by director name in alphabetical order.
- Limits the output to five directors.

In the output, ``A.R. Murugadoss`` has ``Action`` listed twice because
they directed two films with ``Action`` as the primary genre. This
demonstrates that ``$push`` includes duplicate values, unlike
:group:`$addToSet`, which returns an array of unique values.
