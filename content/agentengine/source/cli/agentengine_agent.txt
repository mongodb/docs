agentengine agent
-----------------

Inspect, edit, and generate agent configuration.

Synopsis
~~~~~~~~

Inspect, edit, and generate agent configuration.

Bump-version and egress use the nearest agent.yaml, resolved the same
way as build and deploy; edits apply on the next agentengine deploy.
Validate reads ./agent.yaml by default. Create-tool compiles an OpenAPI
document or an existing catalog into connector authoring files in the
workspace; it needs Docker, not a platform session. Source reads
source.yaml from the CLI state directory.
