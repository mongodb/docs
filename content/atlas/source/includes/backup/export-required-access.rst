- To create or manage a {+Cloud-Backup+} export schedule or configure a
  {+Cloud-Backup+} export bucket in |service|, you must have
  :authrole:`Project Backup Manager` or :authrole:`Project Owner` to the
  project.

- To create or manage a {+Cloud-Backup+} export job, you must have
  :authrole:`Project Backup Export Operator` or :authrole:`Project
  Owner` access to the project.

- To create or manage a {+Cloud-Backup+} object storage private
  endpoint, you must have :authrole:`Project Owner` access to the
  project.
