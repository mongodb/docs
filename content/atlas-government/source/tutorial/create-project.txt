================
Create a Project
================

.. meta::
   :description: Create a project in Atlas for Government, designating it as a FedRAMP Class C (Moderate) or FedRAMP Class D (High) project, and manage member access.

.. default-domain:: mongodb

.. contents:: On this page
   :local:
   :backlinks: none
   :depth: 1
   :class: singlecol

When you create a project, you are added as a
:authrole:`Project Owner` for the project.

Prerequisites
-------------

To create a project for an organization, you must be either an
:authrole:`Organization Owner` or an
:authrole:`Organization Project Creator`.

-----------------------------------
