.. _api-admin-license-keys:

===================================
License Keys API Resource Reference
===================================

.. default-domain:: mongodb

.. meta::
   :description: Use the Ops Manager API to check the license key status of your installation, install or release a license key, and retrieve the Key Manager ID. These endpoints require the Global Owner role.

.. contents:: On this page
   :local:
   :backlinks: none
   :depth: 1
   :class: singlecol

Use this resource to manage the license keys of an |mms|
installation. To learn how |mms| calculates license key status, see
:ref:`license-keys`.

Required Roles
--------------

To access this resource, your |api| key must have the
:authrole:`Global Owner` role.

Endpoints
---------

The following endpoints are available for the License Keys resource:

.. list-table::
   :header-rows: 1
   :stub-columns: 1
   :widths: 10 50 40

   * - Method
     - Endpoint
     - Description

   * - ``GET``
     - :ref:`/admin/licenses <om-api-get-license-key-status>`
     - Retrieves the license key status.

   * - ``PUT``
     - :ref:`/admin/licenses <om-api-install-license-key>`
     - Installs a license key.

   * - ``DELETE``
     - :ref:`/admin/licenses/{artifactId} <om-api-release-license-key>`
     - Releases an installed license key.

   * - ``POST``
     - :ref:`/admin/licenses/recompute
       <om-api-recompute-license-key-status>`
     - Recalculates the license key status.

   * - ``GET``
     - :ref:`/admin/artifacts/identity <om-api-get-key-manager-id>`
     - Retrieves the Key Manager ID of the |mms| installation.

   * - ``POST``
     - :ref:`/admin/artifacts/identity/rotate
       <om-api-rotate-identity-key>`
     - Rotates the identity key of the |mms| installation.

   * - ``GET``
     - :ref:`/admin/artifacts/{artifactId}/receipt
       <om-api-get-license-key-release-receipt>`
     - Retrieves the release receipt of a released license key.
