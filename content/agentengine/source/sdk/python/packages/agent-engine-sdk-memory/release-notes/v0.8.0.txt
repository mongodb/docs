agent-engine-sdk-memory v0.8.0
==============================

What's new
----------

- Caller-supplied semantic metadata has its own field.
  ``create_semantic`` accepts ``metadata`` for arbitrary caller
  key-value pairs, kept distinct from the platform's internal
  ``contextual_metadata`` extraction blob rather than sharing one field.

Breaking changes
----------------

- ``create_semantic``'s ``contextual_metadata`` parameter is renamed to
  ``metadata``. Passing ``contextual_metadata`` still works for now: the
  value is forwarded to ``metadata`` and a ``DeprecationWarning`` is
  raised. Migrate to ``metadata`` before the alias is removed. Explicit
  ``metadata`` takes precedence when both are given.
