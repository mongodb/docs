===================
$lastN (expression)
===================

.. meta::
   :description: Use $lastN as an expression to return an array containing the last n elements from the end of the input array.

.. contents:: On this page
   :local:
   :backlinks: none
   :depth: 1
   :class: singlecol

Definition
----------

.. expression:: $lastN

Returns the specified number of elements from the end of an array.

.. note:: Disambiguation

   This page describes ``$lastN`` when used as an **expression**, which
   returns the specified number of elements from the end of an array.

   You can also use ``$lastN`` in these other contexts:

   - :group:`$lastN (accumulator) <$lastN>`, used in grouping to
     return the last ``n`` elements from each group.

   - :window:`$lastN (window function) <$lastN>`, which is used in the
     :pipeline:`$setWindowFields` stage to return the last ``n`` values
     from documents in a particular window.

Syntax
------

.. code-block:: javascript
   :copyable: false
   :category: syntax example

   { $lastN: { input: <expression>, n: <expression> } }

Options
~~~~~~~

.. list-table::
   :header-rows: 1
   :widths: 20 20 80

   * - Field
     - Type
     - Description

   * - ``input``
     - Expression
     - The array from which to return the last ``n`` elements.

   * - ``n``
     - Expression
     - The number of elements that ``$lastN`` returns. Must resolve to a
       positive integer.

Behavior
--------

- ``$lastN`` returns elements in the same order they appear in
  the input array.

- ``$lastN`` does not filter out ``null`` values in the input
  array.

- You cannot specify a value of ``n`` less than ``1``.

- If the specified ``n`` is greater than or equal to the number of
  elements in the ``input`` array, ``$lastN`` returns the entire
  ``input`` array.

- If ``input`` resolves to a non-array value, the expression
  errors.
