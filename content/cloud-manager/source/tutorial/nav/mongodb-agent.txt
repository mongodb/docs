.. _mongodb-agent:

=====================================
MongoDB Agent for Cloud Manager Hosts
=====================================

.. meta::
   :description: Learn how the MongoDB Agent connects your MongoDB hosts to Cloud Manager and runs the Automation, Monitoring, and Backup functions from one binary per host.

.. default-domain:: mongodb

.. contents:: On this page
   :local:
   :backlinks: none
   :depth: 1
   :class: singlecol

The {+mdbagent+} is a single binary that connects your MongoDB hosts to
|mms|. You install the {+mdbagent+} on the hosts that run the MongoDB
processes you want |mms| to manage. Each agent polls |mms| to determine
the current goal, performs the work needed to reach that goal, and
continually reports its status back to |mms|.

Agent Functions
---------------

The {+mdbagent+} performs any -- or all -- of the following three
functions, depending on what you need:

.. list-table::
   :header-rows: 1
   :widths: 20 80

   * - Function
     - Description

   * - {+aagent+}
     - Deploys and maintains MongoDB nodes and clusters to match the
       goal state that your project's
       :ref:`automation configuration <automation-configuration-ref>`
       defines.

   * - {+magent+}
     - Collects statistics from the nodes in your MongoDB deployment
       and transmits them to |mms| so that |mms| can report deployment
       status in real time.

   * - {+bagent+}
     - Takes snapshots of the MongoDB processes you specify so that you
       can restore your deployment to an earlier state.

To activate the {+magent+} or {+bagent+} function, use the |mms| UI. To
activate the {+aagent+} function, create a new cluster or import an
existing one. To learn how to activate and deactivate each function,
see :ref:`manage-automation`.

Agents send deployment configuration information and MongoDB logs only.
They don't send any data records from your MongoDB deployment.

Legacy Agents
-------------

Before the introduction of the {+mdbagent+}, each function --
{+aagent+}, {+bagent+}, and {+magent+} -- ran as a separate agent
binary in your project. These legacy Agents are now end of life. To
learn about the update process, see
:ref:`mongodb-agent-faq-three-agents`.
