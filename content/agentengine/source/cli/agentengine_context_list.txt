.. _agentengine_context_list:

agentengine context list
------------------------

List the named platform targets on this machine.

Synopsis
~~~~~~~~

List every context in ~/.agentengine/contexts.json. A ’\*’ marks the
context the current agent directory is pinned to, when it is pinned to
one.

.. code-block:: bash

   agentengine context list [flags]

Examples
~~~~~~~~

.. code-block:: bash

     agentengine context list
     agentengine context list --json

Options
~~~~~~~
