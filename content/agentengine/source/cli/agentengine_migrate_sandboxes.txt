agentengine migrate sandboxes
-----------------------------

Migrate agent to named sandboxes (placement + SDK terminology).

Synopsis
~~~~~~~~

Analyze agent source and agent.yaml and migrate legacy is_local/isLocal
placement to named sandbox profiles. The migration creates or verifies
the sandbox policy, moves legacy top-level network policy into the
corresponding sandbox profiles, renames legacy sandbox scaling options,
removes legacy placement arguments, and updates public SDK symbol
references.

Supported SDKs: Python LangGraph and TypeScript LangGraph.

.. code-block:: bash

   agentengine migrate sandboxes [flags]
