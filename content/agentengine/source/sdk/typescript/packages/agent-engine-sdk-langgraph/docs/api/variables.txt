MAX_SUBAGENT_NESTING_DEPTH
--------------------------

.. code-block:: typescript

   const MAX_SUBAGENT_NESTING_DEPTH: 10 = 10;

Recursion is bounded so an adversarial spec (or an accidental cycle)
can't blow the stack at agent-construction time.
