=================
$min (Expression)
=================

.. meta::
   :description: Use the $min expression to return the minimum value from an array. $min traverses arrays and supports multiple expressions as inputs for comparison.

.. contents:: On this page
   :local:
   :backlinks: none
   :depth: 1
   :class: singlecol

Definition
----------

.. expression:: $min

Returns the minimum value from an array.

.. note:: Disambiguation

   This page describes ``$min`` when used as an **expression**.

   You can also use ``$min`` in these other contexts:

   - :group:`$min (accumulator) <$min>`, used in grouping to return the
     minimum value from a group of documents.

   - :window:`$min (window function) <$min>`, used in
     the :pipeline:`$setWindowFields` stage to return the
     minimum value from documents in a particular window.

Syntax
------

.. code-block:: none
   :copyable: false
   :category: syntax example

   { $min: <expression> }

The ``expression`` must evaluate to an array.

Behavior
--------

Result Type
~~~~~~~~~~~

.. include:: /includes/expressions/min/result-type.rst

Null or Missing Values
~~~~~~~~~~~~~~~~~~~~~~

If some, **but not all**, input values are ``null`` or missing,
``$min`` considers only the non-null and non-missing values.

If **all** input values are ``null`` or missing, ``$min``
returns ``null``.

The preceding pipeline:

- Uses :pipeline:`$match` to filter for three specific movies.
- Uses :pipeline:`$project` with ``$min`` to create two fields:

  - ``firstAlphabeticalGenre``: First genre in alphabetical order from
    the genres array, using ``{ $min: "$genres" }``
  - ``lowestRating``: Lowest rating between IMDb and
    Metacritic, both normalized to a 0–100 scale, using
    ``{ $min: [ { $multiply: [ "$imdb.rating", 10 ] }, "$metacritic" ] }``

- Uses :pipeline:`$sort` to sort results by title.
