==========================================
Recompute the License Key Status on Demand
==========================================

.. default-domain:: mongodb

.. meta::
   :description: Recalculate the license key status of your Ops Manager installation on demand instead of waiting for the hourly calculation. This endpoint requires the Global Owner role.

.. contents:: On this page
   :local:
   :backlinks: none
   :depth: 1
   :class: singlecol

|mms| calculates the license key status every hour and after you
install or release a license key. Use this endpoint to recalculate the
status on demand instead of waiting for the next scheduled
calculation, for example after you fix a verification issue outside
the |api|.

Required Roles
--------------

To access this resource, your |api| key must have
the :authrole:`Global Owner` role. The Global Owner role is the
highest role in |mms|. Only users with this role can view and manage
license keys.

Request
-------

Send a ``POST`` request. The endpoint has no request body.

.. include:: /includes/api/base-api-uri.rst

.. code-block:: http

   POST /admin/licenses/recompute

~~~~~~~~~~~~~~~~~~~~~~~

Example Request
---------------

Use ``curl`` to send a ``POST`` request to the ``/admin/licenses/recompute`` endpoint:

.. code-block:: sh

   curl --user "{PUBLIC-KEY}:{PRIVATE-KEY}" --digest \
        --header "Accept: application/json" \
        --include \
        --request POST \
        "https://{+opsmgr-url+}/api/public/v1.0/admin/licenses/recompute?pretty=true"
