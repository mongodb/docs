.. _python:

Atlas Agent Engine Python SDKs
==============================

Python SDK packages for MongoDB's Atlas Agent Engine.

Framework SDKs
--------------

Install the SDK for your agent framework, plus
``agent-engine-sdk-memory`` if your agent uses project memory. The
Google ADK SDK is Python-only.

.. list-table::
   :header-rows: 1

   * - Package
     - Install
     - Description
   * - :ref:`agent-engine-sdk-langgraph <python-packages-agent-engine-sdk-langgraph>`
     - ``pip install agent-engine-sdk-langgraph``
     - LangGraph framework SDK
   * - :ref:`agent-engine-sdk-adk <python-packages-agent-engine-sdk-adk>`
     - ``pip install agent-engine-sdk-adk``
     - Google ADK framework SDK
   * - :ref:`agent-engine-sdk-memory <python-packages-agent-engine-sdk-memory>`
     - ``pip install agent-engine-sdk-memory``
     - Project memory (semantic and episodic)

Internal core packages
----------------------

The framework SDKs depend on these packages. Agents don't install or
import them directly.

.. list-table::
   :header-rows: 1

   * - Package
     - Description
   * - :ref:`agent-engine-sdk <python-packages-agent-engine-sdk>`
     - Framework-neutral core protocols and models
   * - :ref:`agent-engine-runner-shared <python-packages-agent-engine-runner-shared>`
     - Shared runtime that serves agents and tools on the platform

Development
-----------

.. code-block:: bash

   uv sync
   uv run ruff check .

Release notes are on the `GitHub
releases <https://github.com/mongodb/agent-engine-client-libraries/releases>`__
page.
