.. _agentengine_dev_up:

agentengine dev up
------------------

Start the local dev environment.

Synopsis
~~~~~~~~

Start the local development stack.

Hot reload is the default: the app container runs the application
processes and file watching restarts them on change. --isolated runs one
container per process and needs a rebuild for changes.

--all starts every agent under one UI with shared project services. It
supports hot reload only and is rejected with --isolated, --headless, and
--with-egress.

The memory-server is configured from the memory: section of a
project-config.yaml. A single-agent run uses the nearest one at or above
the agent directory, stopping at the repository root, so a workspace
file overrides the monorepo root’s. --all reads only the monorepo root’s
file. For an agent project, features.memory in agent.yaml also gates
whether a memory-server runs. A memory-only project always starts one.

Local egress is on by default. --no-egress skips the CONNECT proxy and
opens the internet. --with-egress is a deprecated alias that forces the
proxy on.

Agents that declare artifact_repositories get registry auth for private
PyPI indexes, resolved from a UV_INDEX\_\* override, then a .env secret,
then a minted AWS CodeArtifact token. --no-artifact-auth leaves
UV_INDEX\_\* credentials to you.

Use --ca-bundle to trust a company intercept CA in local image builds
when a TLS-inspecting proxy (for example Zscaler) re-signs HTTPS. The
PEM is recorded per workspace under ~/.agentengine/ and reused on later
runs on this machine; the generated image embeds the authorized copy,
and repository content is never a source of trust.
AGENTENGINE_CA_BUNDLE is an equivalent process-environment fallback; a
workspace .env value is ignored. Use --clear-ca-bundle to stop trusting
a previously supplied CA.

.. code-block:: bash

   agentengine dev up [flags]

Options
~~~~~~~

.. code-block:: bash

         --all                Monorepo: start all agents under a single UI
         --ca-bundle string   PEM file of extra CA certificates to trust in local image builds (TLS-inspecting proxies).
                              Recorded per workspace under ~/.agentengine/ and reused on later runs. Also AGENTENGINE_CA_BUNDLE.
         --clear-ca-bundle    Remove a previously persisted extra CA and build without it
         --headless           Omit the playground UI service (for CI and automated testing)
     -h, --help               help for up
         --isolated           Run each process in its own container to simulate production
         --local-sdk string   Install SDK from local source instead of pre-built wheels.
                              Also hot-reloads playground UI (unless --headless) from the same SDK checkout.
                              Pass the path to the client-libraries checkout root.
         --no-artifact-auth   Skip auto-configuring registry auth for declared artifact_repositories
         --no-cache           Build images without Docker layer cache
         --no-egress          Do not start the local CONNECT proxy (open internet)
         --with-egress        Force local egress even if preflight would skip (deprecated alias; default is on)
         --workspace string   Monorepo: target a specific agent by name (from root agent.yaml)
