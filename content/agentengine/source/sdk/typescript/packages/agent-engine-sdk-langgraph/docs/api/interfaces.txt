EntrypointOptions
-----------------

Options accepted by
:ref:`App.entrypoint <typescript-packages-agent-engine-sdk-langgraph-docs-api-entrypoint>`.

Properties
~~~~~~~~~~

.. list-table::
   :header-rows: 1

   * - Property
     - Type
     - Description
   * - ``loadStrategy?``
     - :ref:`LoadStrategy <typescript-packages-agent-engine-sdk-langgraph-docs-api-loadstrategy>`
     - ``"global"`` (default) builds once and caches the graph.
       ``"per-execution"`` runs the builder on every invocation with
       that invocation's ``(input, ctx)``, so it can do its own
       request-scoped I/O first.

.. _typescript-packages-agent-engine-sdk-langgraph-docs-api-tooldecoratoroptions:

ToolDecoratorOptions
--------------------

Properties
~~~~~~~~~~

.. list-table::
   :header-rows: 1

   * - Property
     - Type
     - Description
   * - ``description?``
     - ``string``
     - Human-readable description shown to the LLM (mirrors Python's
       docstring). TypeScript has no docstring introspection, so callers
       pass it explicitly.
   * - ``isLocal?``
     - ``boolean``
     - -
   * - ``name?``
     - ``string``
     - Override the registered tool name. Defaults to the wrapped
       function's ``name``.
   * - ``network?``
     - readonly ``string``\ []
     - -
   * - ``onUnknownOutcome?``
     - :ref:`OnUnknownOutcome <typescript-packages-agent-engine-sdk-langgraph-docs-api-onunknownoutcome>`
     - What a retry does when the platform lost the runner while this
       tool was running in a durable workflow, so nobody knows whether
       it ran. ``"rerun"`` runs the tool again (at-least-once execution;
       declare it only for a tool that is safe to run twice). ``"fail"``
       refuses the retry, so the tool never runs twice. Leave unset for
       the platform default.
   * - ``provider?``
     - ``string``
     - -
   * - ``redactFields?``
     - readonly ``string``\ []
     - -
   * - ``schema?``
     - ``ZodType``\ <``unknown``, ``unknown``,
       ``$ZodTypeInternals``\ <``unknown``, ``unknown``>>
     - Zod schema describing the tool's arguments. Without it, the LLM
       has no structured view of the parameters and tool calling will
       fail. Mirrors the type hints + Pydantic-style auto-schema that
       Python's ``@app.tool()`` derives from the function signature.
   * - ``scopes?``
     - readonly ``string``\ []
     - -
   * - ``timeout?``
     - ``number``
     - -
