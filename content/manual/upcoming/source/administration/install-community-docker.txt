.. include:: /includes/release-banner.rst

.. You can run MongoDB Community Edition as a Docker container using the
.. official MongoDB Community image. This page describes how to install,
.. run, verify, and connect to MongoDB Community Edition in Docker.

.. Before You Begin
.. ----------------

.. Before you install MongoDB Community Edition on Docker, complete the
.. following prerequisites:

.. - Install `Docker <https://docs.docker.com/get-started/get-docker/>`__
..   on your host.

.. - Install :ref:`mongosh <mdb-shell-install>`.

.. - Confirm that your host platform is supported. To learn which
..   platforms MongoDB runs on, see :ref:`prod-notes-supported-platforms`.

.. .. include:: /includes/fact-avx-support-docker

.. Install
.. -------

.. To pull the MongoDB {+version+} Community Server image, run the
.. following command:

.. .. code-block:: sh

..    docker pull mongodb/mongodb-community-server:{+version+}-ubi9-slim

.. Start and Verify
.. ----------------

.. .. procedure::
..    :style: normal

..    .. step:: Run the Image as a Container

..       Run the following command to start a container named
..       ``mongodb`` from the image:

..       .. code-block:: sh

..          docker run --name mongodb -p 27017:27017 -d mongodb/mongodb-community-server:{+version+}-ubi9-slim

..       The ``-d`` flag runs the container in the background. The
..       ``-p 27017:27017`` flag publishes the container port to the
..       host port.

..       You can append :ref:`mongod command-line options
..       <conf-file-command-line-mapping>` to the ``docker run``
..       command. For example, to start a single-node replica set
..       instead, run the following command:

..       .. code-block:: sh

..          docker run --name mongodb -p 27017:27017 -d mongodb/mongodb-community-server:{+version+}-ubi9-slim --replSet myReplicaSet

..    .. step:: Verify That the Container Is Running

..       To list running containers, run ``docker ps``. The output
..       includes the container ID, image, status, and published ports:

..       .. io-code-block::

..          .. input::
..             :language: sh

..             docker ps

..          .. output::
..             :language: text

..             CONTAINER ID   IMAGE                                            COMMAND                  CREATED         STATUS         PORTS                      NAMES
..             c29db5687290   mongodb/mongodb-community-server:9.0-ubi9-slim   "docker-entrypoint.s…"   4 seconds ago   Up 3 seconds   0.0.0.0:27017->27017/tcp   mongodb

.. Connect
.. -------

.. .. procedure::
..    :style: normal

..    .. step:: Connect to the MongoDB Deployment

..       To connect to your deployment, run ``mongosh``:

..       .. code-block:: sh

..          mongosh

..       Because the ``docker run`` command publishes the container port
..       to the host, ``mongosh`` connects to the default address,
..       ``localhost:27017``.

..    .. step:: Report the MongoDB Server Status

..       To report the status of your MongoDB instance, run the
..       :dbcommand:`serverStatus` command:

..       .. code-block:: javascript

..          db.runCommand( { serverStatus: 1 } )

..       The command returns a document that describes your ``mongod``
..       deployment.
