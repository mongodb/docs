Troubleshoot Atlas Managed MCP Configurations
=============================================

Use the information on this page to resolve errors that you encounter
when you create or update a {+remote-mcp-programmatic+}
configuration.

Failed Update Leaves a Configuration in an Inconsistent State
-------------------------------------------------------------

The Atlas UI or the Atlas Administration API returns the following
error:

.. code-block:: text

   Failed to update the MCP configuration and the partial update could not be fully reverted. The configuration may be in an inconsistent state.

This error means that Atlas applied part of your update and did not
apply the rest. One field reflects the value that you requested, while
another field keeps its previous value.

To resolve this error, wait a few minutes, then retry the update. If
the error persists, `contact MongoDB Support
<https://support.mongodb.com>`__.

Configuration Created Without a Client Secret
---------------------------------------------

The Atlas UI reports that it created the MCP configuration without a
client secret.

Atlas created the configuration, but did not generate its client
secret. The configuration is still usable, and you can generate a
client secret for it at any time.

To generate a client secret for an existing configuration:

.. procedure::
   :style: normal

   .. step:: Open the configuration's detail page.

      In the :guilabel:`Atlas Managed MCP` card on the
      :guilabel:`Service Accounts` page, click the ellipsis
      (:guilabel:`...`) icon in the configuration's row, then click
      :guilabel:`View Details`.

   .. step:: Generate a new client secret.

      Click :guilabel:`Generate new client secret`, then select an
      expiration.

      .. important::

         Atlas displays the client secret only once. Copy it and store
         it in a secure location.

If secret generation continues to fail, `contact MongoDB Support
<https://support.mongodb.com>`__.
