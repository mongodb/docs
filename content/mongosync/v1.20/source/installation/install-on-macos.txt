Install {+c2c-product-name+}
-------------------------------

Follow these steps to manually install {+c2c-product-name+} from
the ZIP file.

.. procedure::
   :style: normal

   .. step:: Download the ZIP file.

      Download the {+c2c-product-name+} ZIP file from the following
      link:

      |arrow| {+mdb-download-center+}

      a. In the :guilabel:`Version` dropdown, select the version of
         {+c2c-product-name+} to download.

      #. In the :guilabel:`Platform` dropdown, select your :guilabel:`macOS` 
         platform.

      #. In the :guilabel:`Package` dropdown, select :guilabel:`zip`.

      #. Click :guilabel:`Download`.

   .. step:: Unzip the files from the downloaded archive.

      To unzip ``mongosync``, use the ``unzip`` command in a system
      shell:

      .. literalinclude:: /code-examples/installation/install-on-macos/1.sh
         :language: bash

Release Artifact Reports
------------------------

Every release artifact of {+c2c-product-name+} contains a Software
Bill of Materials (SBOM) report and a static analysis report. Both
reports are JSON files named after the artifact that contains them:

- The SBOM report uses the `CycloneDX <https://cyclonedx.org/>`__
  format and ends with ``.bom.json``.
- The static analysis report uses the `SARIF
  <https://docs.oasis-open.org/sarif/sarif/v2.1.0/sarif-v2.1.0.html>`__
  format and ends with ``.sarif.json``.

The reports are located at the top level of the archive. For
example, the ``mongosync-macos-arm-arm64-1.20.0.zip`` archive
contains:

- ``mongosync-macos-arm-arm64-1.20.0.bom.json``
- ``mongosync-macos-arm-arm64-1.20.0.sarif.json``
