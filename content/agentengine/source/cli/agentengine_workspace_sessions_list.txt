agentengine workspace sessions list
-----------------------------------

List sessions that currently hold runtime capacity.

Synopsis
~~~~~~~~

List sessions that currently hold reserved agent or tool sandbox
capacity, or are still releasing it.

Status is active while capacity is held and stopping while release is in
progress. Last activity and scheduled release follow the workspace idle
timeout. Scheduled release is omitted while a session is still stopping.

.. code-block:: bash

   agentengine workspace sessions list [flags]

Examples
~~~~~~~~

.. code-block:: bash

     agentengine workspace sessions list
     agentengine workspace sessions list --json
