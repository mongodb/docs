Perform Text Queries

Overview
--------

In this guide, you can learn how to use the {+driver-short+} to run
**text queries** on your documents.

You can use a text query to retrieve documents that contain a term or a
phrase in a specified field. A term contains only non-whitespace
characters. A phrase contains terms separated by any number of
whitespace characters.

.. note::

   Text queries require a **text index** on the collection fields
   you want to search. To learn how to create indexes, see the
   :ref:`scala-indexes` guide.

Specify Query Text Options
--------------------------

You can customize text query behavior by passing a
``TextSearchOptions`` object as the second parameter to
``Filters.text()``. The following table describes the methods you
can chain to a ``TextSearchOptions`` instance:

.. list-table::
   :widths: 35 65
   :header-rows: 1

   * - Method
     - Description

   * - ``caseSensitive()``
     - | Sets whether the text query is case-sensitive.
         Defaults to ``false``.
       | **Parameter Type**: ``Boolean``

   * - ``diacriticSensitive()``
     - | Sets whether the text query is diacritic-sensitive.
         Defaults to ``false``.
       | **Parameter Type**: ``Boolean``

   * - ``language()``
     - | Sets the language for the text query. Defaults to the
         ``default_language`` of the text index. If no language
         is set, the default is ``"english"``.
       | **Parameter Type**: ``String``

The following example counts documents that match a case-sensitive
search for the term ``"Time"`` in the ``title`` field:
