Overview
--------

In this guide, you can learn how to use the 
:atlas:`{+vector-search+} </atlas-vector-search/vector-search-overview/>` 
feature in the {+driver-short+}. The ``Aggregates`` builders class provides the
``vectorSearch()`` helper method that you can use to
create a :atlas:`$vectorSearch </atlas-vector-search/vector-search-stage/>`
pipeline stage. This pipeline stage allows you to perform a **semantic
search** on your documents. A semantic search is a type of search which
locates information that is similar in meaning, but not necessarily
identical, to your provided search term or phrase.

.. important:: Feature Compatibility

   {+vector-search+} supports approximate nearest neighbor (ANN) search on Atlas clusters running MongoDB
   v6.0.11, v7.0.2, or later and exact nearest neighbor (ENN) search on clusters running
   MongoDB v6.0.16, v7.0.10, v7.3.2, or later. You can also use {+vector-search+}
   with :ref:`self-managed <install-mdb-community-edition>` or
   :atlascli:`local Atlas deployments </atlas-cli-deploy-local>` that you
   create with the Atlas CLI.

Sample Data
~~~~~~~~~~~

The examples in this guide use the ``embedded_movies`` collection in the
``sample_mflix`` database from the :ref:`Atlas sample datasets <available-sample-datasets>`.
To learn how to create a free MongoDB Atlas cluster and load the sample datasets, see the
:ref:`<scala-get-started>` tutorial.

Perform a Vector Search
-----------------------

To run vector search queries, you must create a vector search index and index your
vector embeddings. To learn about how to programmatically create a
vector search index, see the :ref:`scala-atlas-search-index-create` section in the
Indexes guide. To learn more about vector embeddings, see
:atlas:`How to Index Vector Embeddings for Vector Search
</atlas-search/field-types/knn-vector/>` in the Atlas documentation.

After you create a vector search index on your vector embeddings, you
can reference this index in your pipeline stage, as shown in the
following section.

Vector Search Example
~~~~~~~~~~~~~~~~~~~~~

The example in this section requires a vector search index on the
``embedded_movies`` collection with the following configuration:

- Index name: ``vector_index``
- Vector field: ``plot_embedding``, with ``1536`` dimensions
- Filter field: ``year``, indexed as the ``filter`` type to support
  the pre-filter on the ``year`` field

This {+vector-search+} example performs the following actions:

- Creates a query vector as a ``Seq[Double]``
- Builds an aggregation pipeline that runs an ENN search on the
  ``plot_embedding`` field
- Limits results to 1 document
- Matches documents where the ``year`` value is greater than or equal to ``2016``
- Projects the vector search score into a field called ``vectorSearchScore``
