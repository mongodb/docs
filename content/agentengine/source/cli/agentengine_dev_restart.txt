.. _agentengine_dev_restart:

agentengine dev restart
-----------------------

Restart the hot-reload app container.

Synopsis
~~~~~~~~

Restart the running hot-reload app container.

Restarting reruns the container’s startup environment sync, which is
useful after changing host dependencies, for example with uv sync.

The stack is checked for health afterward, with one automatic recovery
(docker compose up -d). A stack that still fails is reported as an error
with the recovery steps to run.

For an agent that declares artifact_repositories, registry auth is
refreshed first and the app container is recreated when the credentials
change; --no-artifact-auth restarts in place.

.. code-block:: bash

   agentengine dev restart [flags]

Options
~~~~~~~

.. code-block:: bash

     -h, --help               help for restart
         --no-artifact-auth   Skip refreshing registry auth for declared artifact_repositories
         --workspace string   Monorepo: target a specific agent by name (from root agent.yaml)
