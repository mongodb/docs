agentengine service-account
---------------------------

Manage service accounts.

Synopsis
~~~~~~~~

Manage service accounts, the programmatic identities that call the
platform.

A service account is scoped to an organization or a project and is
identified by a client ID and secret.

Exchange the client ID and secret for a 1-hour access token at POST
/api/v1/oauth/token. Send that token only to endpoints explicitly
enabled for service-account authentication and that the assigned role
allows:

.. code-block:: bash

   curl --fail-with-body --silent --show-error
   --user ‘’
   --data grant_type=client_credentials
   ‘/api/v1/oauth/token’ \|
   jq -er ‘“Authorization: Bearer” + .access_token’ \|
   curl --fail-with-body --silent --show-error
   --header @-
   ‘/api/v1/’

The create and rotate commands print safe curl examples for both steps.
