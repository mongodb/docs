.. _om-telemetry:

================================
Telemetry API Resource Reference
================================

.. default-domain:: mongodb

.. meta::
   :description: Use the Ops Manager telemetry API to retrieve telemetry status and enable or disable telemetry collection for your installation.

.. contents:: On this page
   :local:
   :backlinks: none
   :depth: 2
   :class: singlecol

Telemetry collection gathers usage information about your |mms|
installation and sends it to MongoDB. Starting in |mms| 8.0.17 and
7.0.20, |mms| enables collecting and sending telemetry data by
default.

Starting in |mms| 9.0.2 and 8.0.28, product usage telemetry replaces
the anonymous telemetry of |mms| 8.0.27 and earlier:

- The product usage report is no longer anonymous. |mms| signs each
  report with a key unique to your installation, and MongoDB uses
  your license enrollment to tie the data to your Enterprise Advanced
  account.

- The :ref:`Retrieve Telemetry Data
  <om-get-telemetry-collection-details>` endpoint returns the product
  usage report, which has a new response format.

- The :ref:`Toggle Telemetry Status
  <om-patch-toggle-telemetry-status>` endpoint can turn product usage
  telemetry off only if your license key has an active telemetry
  exemption.

For details, see :ref:`Product Usage Telemetry
<om-telemetry-overview>`. For telemetry in |mms| 8.0.27 and earlier,
see :ref:`om-telemetry-8-0-27`.

Endpoints
-------------------

The following lists the endpoints available for telemetry.

.. list-table::
   :widths: 30 15 55
   :header-rows: 1

   * - Endpoint
     - Method
     - Description

   * - :ref:`Retrieve Telemetry Data <om-get-telemetry-collection-details>`
     - GET
     - Retrieve telemetry collection status and configuration details.

   * - :ref:`Toggle Telemetry Status <om-patch-toggle-telemetry-status>`
     - PATCH
     - Enable or disable telemetry collection for your |mms|
       installation. Starting in |mms| 9.0.2 and 8.0.28, turns
       product usage telemetry on or off.

Required Roles
--------------

All telemetry endpoints require the :authrole:`Global Owner` role.
