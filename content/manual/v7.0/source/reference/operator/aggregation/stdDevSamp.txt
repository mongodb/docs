$stdDevSamp (accumulator operator)
==================================

Definition
----------

.. group:: $stdDevSamp

Calculates the sample standard deviation of values across a group of
documents.

Use ``$stdDevSamp`` if the input values represent a sample of a
population of data from which you want to generalize about the
population. If the values represent the entire population of data, use
:group:`$stdDevPop` instead.

The ``$stdDevSamp`` accumulator is available in these stages:

- :pipeline:`$bucket`
- :pipeline:`$bucketAuto`
- :pipeline:`$group`

.. note:: Disambiguation

   This page describes ``$stdDevSamp`` when used as an **accumulator**.
   Accumulators return an aggregated value across a group of input
   documents.

   You can also use ``$stdDevSamp`` in these other contexts:

   - :expression:`$stdDevSamp (expression) <$stdDevSamp>`, which
     returns the sample standard deviation of numeric values in an
     array.

   - :window:`$stdDevSamp (window function) <$stdDevSamp>`, which
     is used in the :pipeline:`$setWindowFields` stage to calculate
     the sample standard deviation of values in a window.

Single Value

If the input consists of a single numeric value, ``$stdDevSamp`` returns
``null``.

.. include:: /includes/sample-data-usage.rst

This example returns the five directors with the most varied IMDb
ratings among directors with at least 10 movies.

.. io-code-block::

   .. input:: /code-examples/tested/command-line/mongosh/aggregation/accumulators/stdDevSamp/stdDevSamp-group-example.js
      :language: javascript

   .. output:: /code-examples/tested/command-line/mongosh/aggregation/accumulators/stdDevSamp/stdDevSamp-group-example-output.sh
      :visible: false

The preceding pipeline:

- Uses :pipeline:`$match` to filter for movies that have a
  ``directors`` field and a numeric ``imdb.rating``.
- Uses :pipeline:`$unwind` to create a separate document for each
  director credit.
- Uses :pipeline:`$group` to group by director, counts the movies
  with ``$sum``, and computes ``stdDevSampRating`` using
  ``$stdDevSamp`` on ``imdb.rating``.
- Uses a second :pipeline:`$match` to keep only directors with at
  least 10 movies.
- Uses :pipeline:`$sort` to sort by ``stdDevSampRating`` descending.
- Uses :pipeline:`$limit` to return the top 5 results.
