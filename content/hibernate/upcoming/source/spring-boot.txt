Overview
--------

The {+extension-long+} provides a Spring Boot starter that lets a
Spring Boot application persist JPA entities to MongoDB. When you
activate the starter, it configures the following components for you:

- A JPA ``EntityManagerFactory`` backed by MongoDB
- A ``JpaTransactionManager``
- Spring Data JPA repository support

The starter reuses the ``MongoClient`` that Spring Boot's MongoDB
support creates, so your application maintains a single connection
pool. 

The Spring Boot starter is not Spring Data MongoDB, and you can use it
without adding a SQL ``DataSource`` to your application.
