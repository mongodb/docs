agentengine agent bump-version
------------------------------

Bump the agent’s declared version in agent.yaml (or its delegated
manifest).

Synopsis
~~~~~~~~

Bump the version declared by the agent.yaml in the current directory, or
in the nearest parent directory that has one.

With a literal version such as “1.2.0”, the bump edits agent.yaml
directly. With “version: auto”, it edits the delegated manifest instead:
pyproject.toml [project].version for Python, package.json “version” for
TypeScript. When agent.yaml declares no version, the command errors.

Comments and formatting in the edited file are preserved.

.. code-block:: bash

   agentengine agent bump-version <patch|minor|major> [flags]
