.. important:: {+atlas-infinite-cluster+}s do not support manual MongoDB versioning.

   Only {+atlas-core-cluster+}s support upgrading and downgrading
   MongoDB versions.

   {+atlas-infinite-cluster+}s run MongoDB using
   :guilabel:`Latest Version With Auto Upgrades`, and do not support manual
   version upgrades. {+service+} automatically manages versioning for
   {+atlas-infinite-cluster+}s.
