================================
Connect Your SQL Tool to MongoDB
================================

.. meta::
   :description: Connect your SQL tool, such as Tableau, Power BI, or DBeaver, to your MongoDB Atlas or Enterprise Advanced database using MongoDB custom drivers and connectors.

.. default-domain:: mongodb

.. contents:: On this page
   :local:
   :backlinks: none
   :depth: 1
   :class: singlecol

Connect your SQL tool, such as Tableau, Power BI, or DBeaver to your MongoDB
{+service+} or {+ea+} database.

All three {+sql-interface+} deployment options use the same |jdbc| and
|odbc| drivers, so the steps on this page are the same whether you
connect to an {+service+} {+dedicated-cluster+}, an {+service+}
{+fdi+}, or a self-managed {+ea+} deployment. Configure your deployment
to accept SQL connections first. To learn how, see
:ref:`connect-with-sql-composable`.

.. include:: /includes/fact-driver-bi-tool-compatibility.rst

.. _sql-connect-tableau:

Connect Tableau
---------------

Connect an {+service+} {+dedicated-cluster+}, an {+service+} {+fdi+},
or a self-hosted {+ea+} database to Tableau (Desktop or Server) using
the Tableau Connector for MongoDB.

Prerequisites
~~~~~~~~~~~~~

.. include:: /includes/fact-sql-database-prereq.rst

- The MongoDB |jdbc| driver. To install, see :ref:`sql-connect-jdbc`.

- `Tableau <https://www.tableau.com/>`__ Desktop, Server, or Cloud.
  :manual:`SCRAM authentication </core/security-scram/>` is preferred
  for Tableau Server, and X.509 authentication is also supported.
  Tableau Cloud supports SCRAM authentication only. To learn more
  about supported authentication mechanisms, see
  :ref:`sql-authentication`.

.. _sql-connect-tableau-get-info:

Procedure
~~~~~~~~~

The following steps show you how to connect to MongoDB with Tableau:

.. procedure::
   :style:  normal

   .. step:: Download the Tableau Connector for MongoDB.

      .. note::

         Tableau Desktop and Tableau Server version 2025 and later
         bundle the Tableau Connector for MongoDB. If your version of
         Tableau already includes the connector, skip this step. To
         use a different version than the one bundled with Tableau,
         complete this step.

      For Tableau Desktop, you can also install the connector from
      Tableau. Search the Tableau Exchange for
      :guilabel:`MongoDB SQL interface by MongoDB`, then click
      :guilabel:`Install and restart Tableau`.

      a. Download the latest Tableau Connector ``taco`` file from the `MongoDB download center <https://www.mongodb.com/try/download/tableau-connector/>`__.

      #. Move the ``taco`` file into the appropriate 
         directory for your operating system:
      
         - **Windows:** ``C:\Users\<user>\Documents\My Tableau Repository\Connectors``
      
         - **MacOS:** ``~/Documents/My Tableau Repository/Connectors``

         - **Linux:** ``/opt/tableau/connectors``

      .. important::

         If you download a new version of the Tableau Connector for MongoDB, 
         delete the previous ``taco`` file from your ``Connectors``
         directory to ensure that Tableau uses the latest version.

   .. step:: Get your MongoDB database connection information.

      Select the tab for your deployment type for instructions on how to get your connection information:

      .. tabs::

         .. tab:: Atlas
            :tabid: atlas

            a. Go to your |service| {+dedicated-cluster+} or {+fdi+}
               for your project.

            #. Click :guilabel:`Connect`.

            #. Select the :guilabel:`Atlas SQL Interface` option.

            #. Select the :guilabel:`Tableau Connector` option under the :guilabel:`Select your driver` dropdown.

            #. Select :guilabel:`Tableau` from the dropdown.

            #. Select the database you want to connect to from the :guilabel:`Database` dropdown.

            #. Copy your connection string and connection parameters.

               Use this information to connect with Tableau in a later step.

         .. tab:: Self-Managed (On-premises)
            :tabid: ea-database

            Use a connection string that is compatible with the
            MongoDB Java driver. To learn more, see
            :driver:`Connection URI </java/sync/current/connection/mongoclient/#connection-uri>`.
   
   .. step:: Open Tableau Desktop or Tableau Server.

   .. step:: Go to the :guilabel:`Connect` menu.

   .. step:: Select :guilabel:`MongoDB SQL Interface by MongoDB`.

      A connection modal displays.

   .. step:: Enter your database connection information:

      .. tabs::

         .. tab:: Atlas
            :tabid: atlas

            Enter your {+sql-interface+} connection string you saved in
            a previous step.

         .. tab:: Self-Managed (On-premises)
            :tabid: ea-database

            Enter the following connection string:

            .. code-block:: none

               mongodb://localhost:<port>/?authSource=admin

            Replace ``<port>`` with the port number configured for the
            {+sql-interface+} server to listen on.

            The ``authSource`` parameter specifies the database used to
            authenticate the MongoDB user. If you omit ``authSource``,
            the database specified in the :guilabel:`Database` field is
            used for authentication.

            In the :guilabel:`Database` field, enter the name of the
            MongoDB database you want to query.

   .. step:: Select your authentication method.

      Choose your :guilabel:`Authentication Mechanism` from the dropdown.

      For information about all supported authentication mechanisms,
      see :ref:`sql-authentication`.

      .. tabs::

         .. tab:: Username and Password
            :tabid: username-password

            - :guilabel:`Username`: Enter your MongoDB username.
            - :guilabel:`Password`: Enter your MongoDB password.

         .. tab:: X509
            :tabid: x509

            Configure your PEM certificate using one of the following methods:

            - **Use a PEM File Path:**

              In your ``mongodb_jdbc.properties`` file, set the ``x509pempath`` 
              property to your PEM file's path. For example, ``x509pempath=/certs/client-cert.pem``.

              - If your PEM file is **unencrypted**, do not select :guilabel:`Provide PEM Contents`. 
                No further action is required.
              - If your PEM file is **encrypted**, select :guilabel:`Provide PEM Contents` and 
                enter the file's passphrase in the :guilabel:`Password` field.

            - **Provide PEM Contents:**

              Select the checkbox next to :guilabel:`Provide PEM Contents` and enter your 
              certificate data into the :guilabel:`Password` field:

              - **Unencrypted Content**: Paste the full certificate content directly into the field.
              - **Encrypted Content**: Paste a JSON object containing the content and passphrase:

                .. code-block:: json
                 
                   { "pem": "<PEM-CONTENT>", "passphrase": "<PEM-PASSPHRASE>" }


         .. tab:: GSSAPI (Kerberos)
            :tabid: kerberos

            Enter the Kerberos principal name in the :guilabel:`Username` field. 
            For example, ``user@EXAMPLE.COM``.

         .. tab:: OIDC
            :tabid: oidc

            No additional properties or fields are required in the connection dialog for {+oidc+}.

   .. step:: Click :guilabel:`Sign In`.

.. _sql-connect-tableau-logging:

Configure Tableau Logging
~~~~~~~~~~~~~~~~~~~~~~~~~

To change the logging configuration for the MongoDB |jdbc| driver,
add logging properties to the ``mongodb_jdbc.properties`` file. The
location of this file depends on your platform:

.. list-table::
   :header-rows: 1
   :widths: 30 70

   * - Platform
     - Path

   * - macOS
     - | ``~/Documents/My Tableau Repository/Datasources/mongodb_jdbc.properties``
       | ``~/Documents/My Tableau Prep Repository/Datasources/mongodb_jdbc.properties``

   * - Windows
     - | ``C:\Users\<username>\Documents\My Tableau Repository\Datasources\mongodb_jdbc.properties``
       | ``C:\Users\<username>\Documents\My Tableau Prep Repository\Datasources\mongodb_jdbc.properties``

   * - Tableau Server (RHEL)
     - ``/var/opt/tableau/tableau_server/data/tabsvc/vizqlserver/Datasources/mongodb_jdbc.properties``

       Copy this file to all server nodes.

To configure logging, add the following properties to the file:

.. code-block:: properties

   loglevel=INFO
   logdir=<path-to-log-directory>

The ``loglevel`` property sets the verbosity of the driver logs. It
accepts the following values, in order of increasing verbosity:
``OFF``, ``SEVERE``, ``WARNING``, ``INFO``, ``FINE``, and ``FINER``.
The default is ``OFF``.

The ``logdir`` property sets the directory where the driver writes log
files. The directory must already exist. If you omit ``logdir`` or set
it to ``console``, the driver writes logs to the console instead of to
a file.

.. important::

   In production environments, start with the ``SEVERE`` log level.
   Raise the level only when you must diagnose an issue, because each
   level adds a large amount of output. At the ``FINER`` level, the
   driver logs every call that retrieves data for each cell of each
   result set.

To learn more about properties files in Tableau, see the `Tableau
documentation <https://help.tableau.com/current/pro/desktop/en-us/connect_customize.htm#use-a-properties-file-to-customize-a-jdbc-connection>`__.

.. _sql-connect-powerbi:

Connect Power BI
----------------

Connect an {+service+} {+dedicated-cluster+}, an {+service+} {+fdi+},
or a self-hosted {+ea+} database to Power BI using the 
Power BI Connector for MongoDB.

Prerequisites
~~~~~~~~~~~~~

.. include:: /includes/fact-sql-database-prereq.rst

- The MongoDB |odbc| driver. To install, see :ref:`sql-connect-odbc`.
  To use :ref:`Direct Query <direct-query-mode>`, you must install
  version 1.2 or later.

- `Power BI Desktop <https://learn.microsoft.com/en-us/power-bi/fundamentals/desktop-get-the-desktop/>`__ 64 bit.      
  Microsoft updates and releases Power BI monthly, and |service| supports only
  the latest version of Power BI Desktop.

- Windows operating system. To learn the Windows OS versions that
  Power BI Desktop supports, see the `Microsoft documentation
  <https://www.microsoft.com/en-us/download/details.aspx?id=58494>`__.

.. _connect-powerbi:

Procedure
~~~~~~~~~

The following steps show you how to connect to MongoDB with Power BI:

.. procedure::
   :style: normal
   
   .. step:: Download the Power BI Connector for MongoDB.

      a. Download the latest Power BI Connector ``pqx`` file from the `MongoDB download center <https://www.mongodb.com/try/download/power-bi-connector/>`__. 

         .. note:: 
         
            The Power BI Connector for MongoDB ships with Power BI Desktop.
            If your version of Power BI Desktop already has the MongoDB Atlas SQL connector, skip this step. 
            To use a different version than the one bundled with Power BI Desktop, complete this step.
   
      #. Move the connector file to the following directory path: 
      
         ``C:\Users\<user>\Documents\Power BI Desktop\Custom Connectors``.

         Create this folder if it doesn't already exist.

   .. step:: Get your MongoDB database connection information.

      Select the tab for your deployment type for instructions on how
      to get your connection information:

      .. tabs::

         .. tab:: Atlas
            :tabid: atlas

            a. Go to your |service| {+dedicated-cluster+} or {+fdi+}
               for your project.

            #. Click the :guilabel:`Connect` button.

            #. Select the :guilabel:`Atlas SQL Interface` option.

            #. Select the :guilabel:`Power BI Connector` option under
               the :guilabel:`Select your driver` dropdown.

            #. Copy your connection string.

               Use this information to connect with Power BI in a
               later step.

         .. tab:: Self-Managed (On-premises)
            :tabid: ea-database

            Use your MongoDB deployment |uri|. To learn more, see
            :manual:`Connection Strings
            </reference/connection-string/>`.

   .. step:: Connect from Power BI Desktop.

      a. Open Power BI Desktop.

      #. Select :guilabel:`Get data` from the :guilabel:`Home` menu.

      #. Find and select the :guilabel:`MongoDB Atlas SQL` connector.
            
         i. Type ``mongo`` in the search bar to find the new connector.
         #. Select :guilabel:`MongoDB Atlas SQL`.
         #. Click :guilabel:`Connect`.

      #. Enter the URI and the database name and click :guilabel:`OK`.

         The :guilabel:`MongoDB URI` is the connection string that
         you copied in a previous step.

         In the :guilabel:`Native query` field, you can optionally
         enter a SQL query. Power BI uses the SQL query as the direct
         source for the data. You can also add or change the SQL
         query in the Power Query editor after you connect.

      #. Enter your {+service+} :guilabel:`User name` and :guilabel:`Password` and click :guilabel:`Connect`.

         By default, users can access all namespaces that their roles
         and connection URI permit. If you use custom roles to
         restrict access, you can grant users access to additional
         namespaces in the :guilabel:`Edit User` menu. To learn more,
         see :ref:`Configure Database Users <modify-mongodb-users>`.

         For information about other supported authentication mechanisms,
         see :ref:`sql-authentication`.

.. _direct-query-mode:

Direct Query
~~~~~~~~~~~~

Direct Query is a connection mode available with the Power BI
Connector for MongoDB version 1.2 and later. To use Direct Query,
you must install `MongoDB ODBC Driver
<https://www.mongodb.com/try/download/odbc-driver/>`__ version 1.2
or later. You don't need to configure a DSN.

Direct Query is an alternative to the standard Import Mode, and
allows you to query your database directly. This guarantees
up-to-date data but may take longer to return results.

Direct Query does not support some actions. If you try to perform an unsupported
action, Power BI prompts you to switch to Import Mode.
