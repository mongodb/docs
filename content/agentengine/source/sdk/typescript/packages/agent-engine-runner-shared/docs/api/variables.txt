.. _typescript-packages-agent-engine-runner-shared-docs-api-authschema:

AuthSchema
----------

.. code-block:: typescript

   const AuthSchema: ZodPipe<ZodUnknown, ZodObject<{
     api_keys: ZodOptional<ZodNullable<ZodArray<ZodObject<{
        env: ZodString;
        location: ZodEnum<{
           cookie: "cookie";
           header: "header";
           path: "path";
           query: "query";
        }>;
        name: ZodString;
        prefix: ZodDefault<ZodString>;
     }, $strict>>>>;
     basic: ZodOptional<ZodNullable<ZodPipe<ZodUnknown, ZodObject<{
        password: ZodString;
        username: ZodString;
     }, $strict>>>>;
     bearer: ZodOptional<ZodNullable<ZodString>>;
     headers: ZodOptional<ZodNullable<ZodRecord<ZodString, ZodString>>>;
     provider: ZodOptional<ZodNullable<ZodString>>;
     scopes: ZodOptional<ZodNullable<ZodArray<ZodString>>>;
   }, $strict>>;

How each request of one connector authenticates. Exactly one credential
key is present, and the key is the mechanism: ``bearer``, ``basic`` and
``api_keys`` name workspace secrets read per call, and ``provider``
names the project's OAuth app whose token Delegated auth issues per
call. Whose identity a provider call carries comes from the app's grant
type, never from the binding. A key set to ``null`` is absent.

--------------

.. _typescript-packages-agent-engine-runner-shared-docs-api-exit_import_error:

EXIT_IMPORT_ERROR
-----------------

.. code-block:: typescript

   const EXIT_IMPORT_ERROR: 82 = 82;

Startup-failure exit codes. OE's readiness wait can observe a workload's
real exit code once it exits (via fctr's Wait RPC) but not the exception
that caused it, so the exit code itself is the only signal that reliably
survives a startup crash to reach OE. Chosen to avoid every range fctr's
own const.go already claims: 0/1 (generic), 64-78 (sysexits.h), and
128+signal (signal deaths, e.g. 137=SIGKILL, 143=SIGTERM).

Frozen wire contract: OE's classification of a startup failure depends
on these exact values, and they are duplicated in
runner-shared/src/agent_engine_runner_shared/launcher.py. Changing
either file breaks OE's ability to distinguish failure causes and/or
cross-language parity — keep the two in lockstep.

--------------
