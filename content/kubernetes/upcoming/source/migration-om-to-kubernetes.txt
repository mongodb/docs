.. _k8s-migration-om-to-kubernetes:

================================================
Migrate a Self-Managed Deployment to Kubernetes
================================================

.. meta::
   :description: Migrate a replica set or sharded cluster managed by Ops Manager or Cloud Manager on virtual machines into Kubernetes under the Kubernetes Operator, using a live, incremental workflow.

.. default-domain:: mongodb

.. contents:: On this page
   :local:
   :backlinks: none
   :depth: 1
   :class: singlecol

This page group covers migrating a MongoDB deployment that |mms|
or Cloud Manager manages on virtual machines or bare metal into
Kubernetes under |k8s-op-short|. The migration process is live and
incremental: you extend the deployment into Kubernetes, promote
the Kubernetes members, and then prune the external members. This
migration workflow is available as a Public Preview feature.
