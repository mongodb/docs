If you are archiving stale data to save on storage costs, consider
:atlas:`Online Archive </online-archive/manage-online-archive>` in
`MongoDB Atlas <https://www.mongodb.com/cloud>`__. Online
Archive features data tiering, which automatically archives infrequently
accessed data to fully-managed S3 buckets for availability.

Online Archive isn't supported on {+atlas-infinite-db+}
clusters. See
:atlas:`Public Preview Availability </infinite/atlas-infinite-landing/#public-preview-availability>`.
