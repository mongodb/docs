==============================
{+sql-interface+} Driver Setup
==============================

.. meta::
   :keywords: connect, sql, mongodb
   :description: Install and configure the MongoDB ODBC or JDBC driver required to connect your business intelligence (BI) tool to an Atlas or self-managed MongoDB Enterprise database.
.. default-domain:: mongodb

.. facet::
   :name: genre
   :values: tutorial

.. contents:: On this page
   :local:
   :backlinks: none
   :depth: 2
   :class: singlecol

This page describes how to install and configure the MongoDB |jdbc| or |odbc| drivers
for connecting your |bi| tool to your |service| or self-managed {+ea+} database.

Reference the table below to find the correct driver for your |bi| tool.  

.. list-table::
   :widths: 50 50
   :header-rows: 1

   * - Driver
     - BI Tool

   * - **JDBC Driver**
     - `Tableau <https://www.tableau.com/>`__ Desktop, Server, or Cloud or other JDBC-supported tools such as DBeaver, DataGrip, or a Maven project.

   * - **ODBC Driver**
     - `Power BI Desktop <https://learn.microsoft.com/en-us/power-bi/fundamentals/desktop-get-the-desktop/>`__ or other ODBC-supported tools such as Excel.
