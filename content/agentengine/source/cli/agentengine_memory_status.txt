.. _agentengine_memory_status:

agentengine memory status
-------------------------

Show the project’s memory runtime status.

Synopsis
~~~~~~~~

Report the project’s memory runtime state without changing anything.

Run it after ``agentengine memory apply`` to check whether the memory
server has finished starting. The ``state:`` line reads ``ready`` once
it has; re-run to check again. When the runtime is not ready, the output
names what it is blocked on. ``agentengine memory apply --wait`` waits
inline for the same condition.

Memory is project-scoped. The target project comes from --context, this
directory’s pin, or explicit target flags. No initialized agent
directory is required.

Example: agentengine memory status

.. code-block:: bash

   agentengine memory status [flags]
