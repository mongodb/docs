.. _agentengine_completion_powershell:

agentengine completion powershell
---------------------------------

Generate the autocompletion script for powershell

Synopsis
~~~~~~~~

Generate the autocompletion script for powershell.

To load completions in your current shell session:

.. code-block:: bash

   agentengine completion powershell | Out-String | Invoke-Expression

To load completions for every new session, add the output of the above
command to your powershell profile.

.. code-block:: bash

   agentengine completion powershell [flags]

Options
~~~~~~~

.. code-block:: bash

     -h, --help              help for powershell
         --no-descriptions   disable completion descriptions
