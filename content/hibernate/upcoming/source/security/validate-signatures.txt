Validate Hibernate Extension Artifact Signatures
================================================

.. contents:: On this page
   :local:
   :backlinks: none
   :depth: 1
   :class: singlecol

.. facet::
   :name: genre
   :values: tutorial

.. meta::
   :description: Learn how to confirm that a MongoDB Extension for Hibernate ORM artifact published on Maven Central was signed by MongoDB and has not been modified.
   :keywords: security, signature, verify, maven

Overview
--------

You can validate the signature of a {+extension-long+} artifact that
MongoDB publishes to Maven Central. Validating an artifact signature
helps you confirm that the artifact is authentic and unmodified.

Procedure
---------

These steps describe how you can validate {+extension-short+}
artifact signatures.

.. procedure::
   :style: normal

   .. step:: Install encryption software

      You must install the `GnuPG <https://gnupg.org/>`__ encryption suite
      to validate artifact signatures from the command line.

      On macOS, you can install GnuPG by using Homebrew:

      .. code-block:: bash

         brew install gnupg

      .. tip::

         You can also install `GPG Suite <https://gpgtools.org/>`__, which
         provides a graphical interface for GnuPG. There is a
         `Homebrew installation <https://formulae.brew.sh/cask/gpg-suite>`__
         for GPG Suite.

   .. step:: Download and import the MongoDB signing key

      Download and import the public key that MongoDB uses to sign the
      release:

      .. code-block:: bash

         gpg --keyserver hkps://keyserver.ubuntu.com --recv-keys 1a75005e142192223d6a7c3b76e0008d166740a8

      You can also find release-specific instructions on the
      `MongoDB Extension for Hibernate ORM releases
      <https://github.com/mongodb/mongo-hibernate/releases>`__ page.

   .. step:: Download the signed artifact

      Download the {+extension-long+} artifact that you want to verify
      from Maven Central.

      The following example downloads version {+extension-version+}
      of the extension:

      .. code-block:: bash

         curl -LO https://repo.maven.apache.org/maven2/org/mongodb/mongodb-hibernate/{+extension-version+}/mongodb-hibernate-{+extension-version+}.jar

      To verify a different version, replace {+extension-version+} in the
      command with the version that you want to verify.

   .. step:: Download the artifact signature

      Download the detached signature file for the same artifact and
      version:

      .. code-block:: bash

         curl -LO https://repo.maven.apache.org/maven2/org/mongodb/mongodb-hibernate/{+extension-version+}/mongodb-hibernate-{+extension-version+}.jar.asc

      The ``.asc`` file must correspond to the artifact file that
      you downloaded.

   .. step:: Verify the signature

      Run the following command from the directory containing the
      artifact and its signature:

      .. code-block:: bash

         gpg --verify mongodb-hibernate-{+extension-version+}.jar.asc mongodb-hibernate-{+extension-version+}.jar

      If the signature is valid, GnuPG prints a message similar to the
      following:

      .. code-block:: text
         :copyable: false

         gpg: Signature made Wed Sep 16 19:15:35 2026 IST
         gpg:                using RSA key 76E0008D166740A8
         gpg: Good signature from "MongoDB Java Driver Release Signing Key <packaging@mongodb.com>" [unknown]
         gpg: WARNING: This key is not certified with a trusted signature!
         gpg:          There is no indication that the signature belongs to the owner.
         Primary key fingerprint: 1A75 005E 1421 9222 3D6A 7C3B 76E0 008D 1667 40A8

      A valid signature confirms that the artifact matches the signed
      release. Review the key fingerprint and signing identity before
      trusting the result.
