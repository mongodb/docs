================================
$setUnion (accumulator operator)
================================

.. meta::
   :description: Use the $setUnion accumulator operator to combine the array values from a group of documents into a single array of unique elements, ignoring duplicates.

.. default-domain:: mongodb

.. contents:: On this page
   :local:
   :backlinks: none

   :class: singlecol

.. facet::

   :values: reference

Definition
----------

.. group:: $setUnion

Returns an array of the unique elements in the array values across a
group of documents.

.. versionadded:: 8.1

The ``$setUnion`` accumulator is available in these stages:

- :pipeline:`$bucket`
- :pipeline:`$bucketAuto`
- :pipeline:`$group`

.. note:: Disambiguation

   This page describes ``$setUnion`` when used as an **accumulator**.
   Accumulators return a single aggregated value across a group of
   input documents.

   You can also use ``$setUnion`` in these other contexts:

   - :expression:`$setUnion (expression) <$setUnion>`, which combines
     two or more arrays into a single array of unique elements.

   - :window:`$setUnion (window function) <$setUnion>`, which is used
     in the :pipeline:`$setWindowFields` stage to return a single array
     of the unique elements in the array values in a window.

specific directors have worked in:

The preceding pipeline:

- Uses :pipeline:`$unwind` to create a separate document for each
  director credit.

- Uses :pipeline:`$match` to filter for three specific directors.

- Uses :pipeline:`$group` to group by director, count the movies with
  :group:`$sum`, and combine the ``genres`` arrays of all of the
  director's movies into a single array of unique genres with
  ``$setUnion``.

- Uses :pipeline:`$sort` to sort results by director name.

Limitations
-----------

- ``$setUnion`` only supports arrays and expressions that resolve to an
  array.
