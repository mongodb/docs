You can integrate MongoDB with Fireworks AI to build retrieval-augmented
generation (|rag|) applications on open-source models. This
tutorial uses |voyage| to embed and rerank sample data, and then
uses a Fireworks chat model to generate a grounded recommendation.

In this tutorial, you perform the following tasks:

#. Set up your environment.
#. Use a |voyage| embedding model to embed movie data and store the
   embeddings in MongoDB.
#. Use {+avs+} and a |voyage| reranker model to retrieve and rerank movie
   documents.
#. Instruct a Fireworks chat model to generate a movie recommendation based on
   the reranked results.

Background
----------

`Fireworks AI <https://fireworks.ai/>`__ provides a platform
for training and running open-source AI models. You can use MongoDB
to store operational and memory data, and to retrain models for
specific use cases.

A |rag| application retrieves relevant data and passes it to a chat
model as context, so the model answers from your data instead of
relying only on what it learned during training. In this tutorial,
MongoDB stores and retrieves your data. |voyage| provides the
embedding model that embeds the data and the reranker model that
reranks the retrieved results, and Fireworks AI provides the chat
model that generates the final response.

Prerequisites
-------------

To complete this tutorial, you must have the following resources:

- .. include:: /includes/avs/shared/avs-requirements-cluster.rst

- The :ref:`sample dataset <sample-data>` loaded into your cluster.
  This tutorial uses the ``sample_mflix.movies`` collection.
- A Fireworks AI |api| key. To create one, go to `API Keys
  <https://app.fireworks.ai/settings/users/api-keys>`__ in your
  Fireworks account settings.
- A |voyage| |api| key. To create one, see :ref:`voyage-api-keys`.
- Python v3.11 or later.
- `uv <https://docs.astral.sh/uv/>`__.

Set Up the Environment
----------------------

In this section, you prepare your environment by creating a virtual
environment, installing the required dependencies, setting your
environment variables, and creating a project file.

.. procedure::
   :style: normal

   .. step:: Create and activate a virtual environment.

      From your terminal, run the following commands to create a new
      directory named ``fireworks-mongodb-project`` and start
      a virtual environment:

      .. code-block:: shell

         mkdir fireworks-mongodb-project
         cd fireworks-mongodb-project
         uv venv
         source .venv/bin/activate

   .. step:: Install the dependencies.

      From your ``fireworks-mongodb-project`` directory,
      run the following command to install the required
      dependencies:

      .. code-block:: shell

         uv pip install pymongo openai voyageai python-dotenv

   .. step:: Set your environment variables.

      In your ``fireworks-mongodb-project`` directory, create a
      ``.env`` file and add the following code:

      .. code-block:: shell

         FIREWORKS_API_KEY="<fireworks-api-key>"
         VOYAGE_API_KEY="<voyage-api-key>"
         MONGODB_URI="<connection-string>"

      Replace ``<fireworks-api-key>`` with your `Fireworks API key
      <https://app.fireworks.ai/settings/users/api-keys>`__, and replace
      ``<voyage-api-key>`` with your :ref:`Voyage AI API key <voyage-api-keys>`.

      .. include:: /includes/search-shared/find-connection-string.rst

   .. step:: Create a project file.

      In your ``fireworks-mongodb-project`` directory, create a file
      named ``main.py``. Add the following code to this file to load
      your environment variables and define two command-line
      arguments, which specify the search query and the number of
      results:

Run the File
------------

To run the ``main.py`` file, run the following command from your
``fireworks-mongodb-project`` directory. Use the ``--query`` and
``--count`` flags to specify the search query and the number of
results that the file returns:

.. code-block:: shell

   uv run main.py --query "a heist that goes wrong" --count 5

If the command runs successfully, the output resembles the following:

.. code-block:: text
   :copyable: false

   Embedded 50 movies.
   Waiting for the index to build...
   Index is ready.

   Vector search results:
   0.724  I Became a Criminal
   0.664  Hallelujah
   0.662  Zoo in Budapest
   0.658  Rear Window
   0.654  The Long Voyage Home

   Reranked, precise results:
   I Became a Criminal
   Hallelujah
   Foolish Wives
   Zoo in Budapest
   A Corner in Wheat

   Recommendation:
   **I Became a Criminal** -- This gritty film-noir follows cynical
   ex-RAF flyer Morgan, who joins a break-in gang led by Narcy. Their
   first job quickly turns disastrous when the getaway car crashes
   after the crew accidentally kills a policeman. The movie centers on
   a heist that goes badly wrong, showcasing the chaos, moral fallout,
   and gritty consequences of a botched robbery.
