.. procedure::
   :style: normal

   .. step:: Click :guilabel:`Stream Processors` in the left-hand navigation menu.

   .. step:: Select the stream processor that you want to modify.

      From the list of stream processors, click the one that you want
      to modify. The :guilabel:`View Stream Processor` screen opens.

   .. step:: Click :guilabel:`Edit Processor`.

      The stream processor fields become editable.

   .. step:: Make your changes to the stream processor.

      You can edit any of the fields available for your stream
      processor.

   .. step:: Click :guilabel:`Save changes`.
