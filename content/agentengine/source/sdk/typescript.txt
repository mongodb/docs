.. _typescript:

Atlas Agent Engine TypeScript SDKs
==================================

TypeScript SDK packages for MongoDB's Atlas Agent Engine.

Framework SDKs
--------------

Install the SDK for your agent framework, plus
``@mongodb-js/agent-engine-sdk-memory`` if your agent uses project
memory.

.. list-table::
   :header-rows: 1

   * - Package
     - Install
     - Description
   * - :ref:`@mongodb-js/agent-engine-sdk-langgraph <typescript-packages-agent-engine-sdk-langgraph>`
     - ``npm install @mongodb-js/agent-engine-sdk-langgraph``
     - LangGraph framework SDK
   * - :ref:`@mongodb-js/agent-engine-sdk-memory <typescript-packages-agent-engine-memory>`
     - ``npm install @mongodb-js/agent-engine-sdk-memory``
     - Project memory (semantic and episodic)

Internal core packages
----------------------

The framework SDKs depend on these packages. Agents don't install or
import them directly.

.. list-table::
   :header-rows: 1

   * - Package
     - Description
   * - :ref:`@mongodb-js/agent-engine-sdk <typescript-packages-agent-engine-sdk>`
     - Framework-neutral core protocols, models, and schemas
   * - :ref:`@mongodb-js/agent-engine-runner-shared <typescript-packages-agent-engine-runner-shared>`
     - Shared runtime that serves agents and tools on the platform

Development
-----------

.. code-block:: bash

   npm ci
   npm run build --workspaces
   npm test --workspaces

Release notes are on the `GitHub
releases <https://github.com/mongodb/agent-engine-client-libraries/releases>`__
page.
