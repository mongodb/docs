agentengine dev login
---------------------

Log the local container tooling in to the platform image registry.

Synopsis
~~~~~~~~

Fetches a short-lived pull credential for the platform’s first-party
container images from the Agent Engine API and runs ‘docker login’ with
it, so ‘agentengine dev up’ can pull images without a GitHub or AWS
account. This requires the internal image source; other sources fail.

The credential is cached, and ‘agentengine dev up’ re-runs this flow
when a platform image is missing locally and the credential is absent or
expiring. Run it by hand only to troubleshoot registry auth or pull
images directly.

Gateway-proxy flows are the default; AGENTENGINE_USE_GATEWAY_PROXY=false
pulls from the legacy GHCR location instead and disables this command.

.. code-block:: bash

   agentengine dev login [flags]
