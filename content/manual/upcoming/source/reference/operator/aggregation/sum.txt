Definition
----------

.. group:: $sum

Returns the collective sum of numeric values across a group of
documents.

The ``$sum`` accumulator is available in these stages:

- :pipeline:`$bucket`
- :pipeline:`$bucketAuto`
- :pipeline:`$group`

.. note:: Other Uses of ``$sum``

   This page describes ``$sum`` when used as an **accumulator**.
   Accumulators return an aggregated value like sum, maximum, or
   minimum across a group of input documents.

   You can also use ``$sum`` in these other contexts:

   - :expression:`$sum (expression) <$sum>`, which returns the sum
     of numeric values in an array.

   - :window:`$sum (window function) <$sum>`, which is used in the
     :pipeline:`$setWindowFields` stage to calculate the cumulative
     sum of values in a window.

Non-Numeric or Non-Existent Fields
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

When you use ``$sum`` on a field that contains both numeric and
non-numeric values, ``$sum`` ignores the non-numeric values and returns
the sum of the numeric values.

For example, when not used in a ``$group`` stage:

- If the ``$sum`` operand is ``[ 2, 2 ]``, ``$sum`` adds the array
  elements and returns 4.

- If the ``$sum`` operand is ``[ 2, [ 3, 4 ] ]``, ``$sum`` returns 2
  because it treats the nested array ``[ 3, 4 ]`` as a non-numeric
  value.

.. _sum-project-example:

Use in $project Stage
~~~~~~~~~~~~~~~~~~~~~

A collection ``students`` contains the following documents:

.. code-block:: javascript

   { "_id": 1, "quizzes": [ 10, 6, 7 ], "labs": [ 5, 8 ], "final": 80, "midterm": 75 }
   { "_id": 2, "quizzes": [ 9, 10 ], "labs": [ 8, 8 ], "final": 95, "midterm": 80 }
   { "_id": 3, "quizzes": [ 4, 5, 5 ], "labs": [ 6, 5 ], "final": 78, "midterm": 70 }

The following example uses :group:`$sum` in the
:pipeline:`$project` stage to calculate total quiz scores,
total lab scores, and the combined final and midterm score:

.. code-block:: javascript

   db.students.aggregate([
      {
        $project: {
          quizTotal: { $sum: "$quizzes"},
          labTotal: { $sum: "$labs" },
          examTotal: { $sum: [ "$final", "$midterm" ] }
        }
      }
   ])

The operation returns:

.. code-block:: javascript
   :copyable: false

   { "_id" : 1, "quizTotal" : 23, "labTotal" : 13, "examTotal" : 155 }
   { "_id" : 2, "quizTotal" : 19, "labTotal" : 16, "examTotal" : 175 }
   { "_id" : 3, "quizTotal" : 14, "labTotal" : 11, "examTotal" : 148 }

.. _sum-window-example:

Use in $setWindowFields Stage
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. versionadded:: 5.0

.. include:: /includes/setWindowFields-example-collection.rst

This example uses :group:`$sum` in the :pipeline:`$setWindowFields`
stage to output the sum of the ``quantity`` of cakes sold in each
``state``:

.. code-block:: javascript

   db.cakeSales.aggregate( [
      {
         $setWindowFields: {
            partitionBy: "$state",
            sortBy: { orderDate: 1 },
            output: {
               sumQuantityForState: {
                  $sum: "$quantity",
                  window: {
                     documents: [ "unbounded", "current" ]
                  }         
               }
            }
         }
      }
   ] )
