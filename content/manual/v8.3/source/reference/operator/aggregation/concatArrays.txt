====================================
$concatArrays (accumulator operator)
====================================

.. meta::
   :description: Use the $concatArrays accumulator operator in MongoDB aggregation to concatenate the array values of a field across the documents in a group, returning a single concatenated array.

.. contents:: On this page
   :local:
   :backlinks: none
   :depth: 1
   :class: singlecol

.. facet::
   :name: genre
   :values: reference

Definition
----------

.. group:: $concatArrays

Returns a single array that concatenates the array values of a field
across a group of documents.

The ``$concatArrays`` accumulator is available in these stages:

- :pipeline:`$bucket`
- :pipeline:`$bucketAuto`
- :pipeline:`$group`

.. note:: Disambiguation

   This page describes ``$concatArrays`` when used as an **accumulator**.
   Accumulators return a single aggregated value across a group of input
   documents.

   You can also use ``$concatArrays`` in these other contexts:

   - :expression:`$concatArrays (expression) <$concatArrays>`, which
     concatenates two or more arrays into a single array within a
     single document.

   - :window:`$concatArrays (window function) <$concatArrays>`, which
     is used in the :pipeline:`$setWindowFields` stage to concatenate
     the array values from a field across a window of documents.

Limitations
-----------

``$concatArrays`` only supports arrays and expressions that resolve to
an array.
