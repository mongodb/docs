.. _release-version-numbers:

==================
MongoDB Versioning
==================

.. meta::
   :description: Find where to learn about MongoDB Server, MongoDB Atlas, driver, MongoDB Shell, and Database Tools version numbers, release types, and upgrade guidance.

.. contents:: On this page
   :local:
   :backlinks: none
   :depth: 1
   :class: singlecol

MongoDB Server, {+atlas+}, the MongoDB drivers, and MongoDB tools use
separate version numbers. Use the following sections to find version
guidance for each product.

Server Versions
---------------

To learn how MongoDB Server versions are numbered, which release types
are available, and how to plan an upgrade, see
:ref:`versions-and-upgrade-paths`. For per-version release notes and
compatibility changes, see :ref:`server-release-notes-landing`.

Atlas Versions
--------------

To learn about the release options available for Atlas clusters, see
:ref:`atlas-versions`.

Driver Versions
---------------

The version numbering system for MongoDB differs from the system
used for the :ecosystem:`MongoDB drivers </drivers>`.

MongoDB Shell (``mongosh``)
---------------------------

The :mongosh:`MongoDB Shell </>` (``mongosh``) is released separately
from the MongoDB Server and uses its own version numbering system.

Database Tools
--------------

:dbtools:`MongoDB Database Tools </>` are released separately from the
MongoDB Server and use their own version numbering system.
