Version Compatibility
---------------------

The {+driver-short+} uses the {+extension-short+} to compress network
traffic. The following table lists the minimum {+extension-short+} and
{+mdb-server+} version required for each compression algorithm:

.. list-table::
   :header-rows: 1
   :stub-columns: 1

   * - Compression Algorithm
     - Minimum Extension Version
     - Minimum Server Version

   * - `Snappy <https://google.github.io/snappy/>`__
     - 1.4.0
     - 4.2

   * - `Zlib <https://zlib.net/>`__
     - 1.4.0
     - 4.2

   * - `Zstandard <https://facebook.github.io/zstd/>`__
     - 1.8.0
     - 4.2

.. _php-enable-compression:

Enable Network Compression
--------------------------

To enable network compression for your MongoDB connection, install the
required dependencies and specify the compression algorithms that you
want to use.

.. _php-compression-dependencies:

Install Dependencies
~~~~~~~~~~~~~~~~~~~~

Because the {+extension-short+} uses the MongoDB C driver to implement
network compression, you must install the required dependencies for the
C driver. To view these dependencies, see
:ref:`c-compression-dependencies` in the C driver documentation.

Specify Compression Algorithms
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

To enable compression for the connection to your MongoDB deployment, use the
``compressors`` connection option and specify the compression algorithms you want to use.
You can do this in two ways:

- Pass the algorithms as an argument to the ``MongoDB\Client`` constructor.
- Specify the algorithms in your connection string.

Specify the Zlib Compression Level
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

If you specify Zlib as one of your compression algorithms, you can also use the
``zlibCompressionLevel`` option to specify a compression level. This option accepts
an integer value between ``-1`` and ``9``:

- **-1:** (Default). zlib uses its default compression level (usually ``6``).
- **0:** No compression.
- **1:** Fastest speed but lowest compression.
- **9:** Best compression but slowest speed.
