To set up the {+mdb-atlas-ai-client-title+} plugin in ChatGPT Desktop or Web, 
follow these steps:

.. procedure::
   :style: normal

   .. step:: Open a ChatGPT session.

   .. step:: Install the plugin.

      Go to **Settings → Plugins → Browse directory**. 
      
      Search for **MongoDB Atlas**, select it, and click **Install plugin**.

   .. step:: Login to Atlas.
         
         Click **Connect to MongoDB Atlas** and complete the guided Atlas 
         :ref:`OAuth flow <remote-mcp-security>`.

   .. step:: Confirm the requested permissions.

      Click **Authorize**.
