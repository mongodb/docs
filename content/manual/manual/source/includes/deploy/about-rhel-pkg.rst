
Use this tutorial to install MongoDB {+version+} |edition| Edition on
Red Hat Enterprise Linux, Rocky Linux, AlmaLinux, or Oracle Linux using
the YUM package manager.

.. important::

   MongoDB only supports Oracle Linux running the Red Hat Compatible
   Kernel (RHCK). MongoDB does not support the Unbreakable Enterprise
   Kernel (UEK).
