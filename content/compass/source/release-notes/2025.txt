|compass| 1.48.2
----------------

*Released November 13, 2025*

New Features

- Add a right-click copy/cut/paste context menu (:issue:`COMPASS-9919`)
- Show shard key in indexes table (:issue:`COMPASS-6868`)
- Show warning for invalid relationships (:issue:`COMPASS-9847`)

Bug Fixes

- Remove delete when document is in edit mode (:issue:`COMPASS-9971`)
- Disable guide cues in the app until the Welcome modal is hidden
- Use ``getConnectionTitle()`` instead of fav name (:issue:`COMPASS-10038`)
- Filter out related source links without a title or URL (:issue:`COMPASS-10036`)
- Remove divergent user data types from Atlas implementation (:issue:`CLOUDP-334901`)
- Disable dropping database in readonly in the context menu (:issue:`COMPASS-10058`)
    
`Full Changelog available on GitHub
<https://github.com/mongodb-js/compass/compare/v1.48.1...v1.48.2>`__
