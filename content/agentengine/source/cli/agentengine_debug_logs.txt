.. _agentengine_debug_logs:

agentengine debug logs
----------------------

View CLI debug logs.

Synopsis
~~~~~~~~

View the CLI’s own debug logs.

Each invocation writes a structured JSON log file unless --no-log is set.
Log files are at:

- macOS: ``~/Library/Logs/agentengine/``
- Linux: ``${XDG_STATE_HOME:-~/.local/state}/agentengine/logs/``
- Windows: ``%LOCALAPPDATA%\agentengine\Logs\``

Flags and their environment variables:

--log-level AGENTENGINE_LOG_LEVEL (default info) --log-file
AGENTENGINE_LOG_FILE --no-log AGENTENGINE_NO_LOG --verbose -v, -vv raise
stderr verbosity --quiet -q silence stderr below error

AGENTENGINE_LOG_MAX_FILES sets the retained file count (default 20).
AGENTENGINE_NO_LOG_PRUNE disables automatic pruning.

When a command fails, the final stderr line shows the active log path:

For details:
~/Library/Logs/agentengine/agentengine-2026-05-13T11-43-57Z-12345.log

Examples:

.. code-block:: bash

   agentengine debug logs list
   agentengine debug logs get --last --pretty

Options
~~~~~~~

.. code-block:: bash

     -h, --help   help for logs

Options inherited from parent commands
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. code-block:: bash

         --log-file string    override log file path
         --log-level string   file log verbosity (error|warn|info|debug) (default "info")
         --no-log             disable file logging
     -q, --quiet              silence stderr below error
     -v, --verbose count      raise stderr verbosity (-v info, -vv debug)
