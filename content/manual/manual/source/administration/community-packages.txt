==================================
MongoDB Community Edition Packages
==================================

.. meta::
   :keywords: on-prem
   :description: MongoDB Community packages available in the official MongoDB repositories for Linux, including database tools and mongosh, with considerations for conflicting system packages.

.. contents:: On this page
   :local:
   :backlinks: none
   :depth: 1
   :class: singlecol

MongoDB provides repositories to install MongoDB Community on
Linux-based operating systems through the native package manager.

To install MongoDB Community, see :ref:`Install
<install-mdb-community-edition>`.

Considerations
--------------

Distribution Packages
~~~~~~~~~~~~~~~~~~~~~

The ``mongodb`` package provided by most Linux distributions is *not*
maintained by MongoDB, Inc., and conflicts with the official
MongoDB Community packages.

If you installed MongoDB through your distribution repositories,
uninstall this package before installing from the official MongoDB
repositories.

Packages
--------

.. _pkg-mongodb-database-tools-org:

``mongodb-database-tools``
~~~~~~~~~~~~~~~~~~~~~~~~~~

This package contains the following MongoDB database tools:

.. hlist::
   :columns: 4

   - :binary:`~bin.mongodump`
   - :binary:`~bin.mongorestore`
   - :binary:`~bin.bsondump`
   - :binary:`~bin.mongoimport`
   - :binary:`~bin.mongoexport`
   - :binary:`~bin.mongostat`
   - :binary:`~bin.mongotop`
   - :binary:`~bin.mongofiles`

.. _pkg-mongodb-database-tools-extra-org:

``mongodb-database-tools-extra``
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

This package contains the :ref:`install-compass` script.

.. _pkg-mongodb-mongosh-org:

``mongodb-mongosh``
~~~~~~~~~~~~~~~~~~~

This package contains the MongoDB Shell (:binary:`~bin.mongosh`).

.. _pkg-mongodb-org:

``mongodb-org``
~~~~~~~~~~~~~~~

This metapackage installs the following metapackages:

.. hlist::
   :columns: 3

   - :ref:`pkg-mongodb-org-database`
   - :ref:`pkg-mongodb-org-tools`
   - :ref:`pkg-mongodb-mongosh-org`

.. _pkg-mongodb-org-database:

``mongodb-org-database``
~~~~~~~~~~~~~~~~~~~~~~~~

This metapackage installs the following packages:

.. hlist::
   :columns: 2

   - :ref:`pkg-mongodb-org-server`
   - :ref:`pkg-mongodb-org-mongos`

.. _pkg-mongodb-org-mongos:

``mongodb-org-mongos``
~~~~~~~~~~~~~~~~~~~~~~

This package contains the :binary:`~bin.mongos` daemon.

.. _pkg-mongodb-org-server:

``mongodb-org-server``
~~~~~~~~~~~~~~~~~~~~~~

This package contains the :binary:`~bin.mongod` daemon, the
associated systemd service file, and a
:ref:`configuration file <conf-file>` (``/etc/mongod.conf``).

.. _pkg-mongodb-org-tools:

``mongodb-org-tools``

This metapackage installs the following packages:

.. hlist::
   :columns: 2

   - :ref:`pkg-mongodb-database-tools-org`
   - :ref:`pkg-mongodb-database-tools-extra-org`
