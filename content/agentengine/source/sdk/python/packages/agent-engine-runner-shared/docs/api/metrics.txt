.. _python-packages-agent-engine-runner-shared-docs-api-metrics:

agent_engine_runner_shared.metrics
==================================

Metrics and observability for the Runner SDK.

Provides metrics collection and structured logging for observability.

Usage: from agent_engine_runner_shared.metrics import Metrics,
record_latency, record_error

.. code-block:: text

   # Record tool latency
   with record_latency("tool_execution", tool_name="lookup_policy"):
       result = tool.invoke(args)

   # Record error
   record_error("tool_execution", tool_name="lookup_policy", error="Connection timeout")

   # Get all metrics
   metrics = Metrics.get_all()

.. _python-packages-agent-engine-runner-shared-docs-api-agent_engine_runner_shared.metrics.metrics:

Metrics
-------

.. code-block:: python

   class Metrics()

Thread-safe metrics collector for the Runner SDK.

Collects:

- Tool execution latency (per tool)
- LLM call latency
- Error counts (per operation type)
- Request counts

.. _python-packages-agent-engine-runner-shared-docs-api-agent_engine_runner_shared.metrics.metrics.record_latency:

record_latency
~~~~~~~~~~~~~~

.. code-block:: python

   @classmethod
   def record_latency(cls, operation: str, duration_ms: float,
                      **labels: str) -> None

Record a latency measurement.

**Arguments**:

- ``operation`` - Operation name (e.g., "tool_execution", "llm_call")
- ``duration_ms`` - Duration in milliseconds
- ``**labels`` - Additional labels (e.g., tool_name="lookup_policy")

with_metrics
------------

.. code-block:: python

   def with_metrics(operation: str, record_errors: bool = True)

Decorator to record latency and errors for a function.

Works with both sync and async functions.

Usage: @with_metrics("oe_agent_start") async def \_handle_start(self,
request): ...

.. code-block:: text

   def execute_tool(self, ...):
       ...
