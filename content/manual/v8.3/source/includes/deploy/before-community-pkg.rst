
These instructions use the official ``mongodb-org`` package to install
MongoDB Community Edition. MongoDB, Inc., maintains and supports this
package. The package always contains the latest version of MongoDB
{+version+} available from its own dedicated repository.

.. important::

   The ``mongodb`` package provided by your distribution is not
   maintained by MongoDB, Inc., and conflicts with the official
   ``mongodb-org`` package. If you have already installed the
   ``mongodb`` package on your system, you must uninstall it before
   proceeding.
