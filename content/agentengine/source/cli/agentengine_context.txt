.. _agentengine_context:

agentengine context
-------------------

Manage named platform targets.

Synopsis
~~~~~~~~

A context names one platform target: a base URL, an organization, and a
project. Contexts live in ~/.agentengine/contexts.json and are shared
across every agent directory on this machine; an agent directory binds
to one with ``agentengine context pin``.
