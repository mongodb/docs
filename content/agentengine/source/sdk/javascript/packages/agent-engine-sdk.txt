@mongodb-js/agent-engine-sdk
============================


Core TypeScript protocols, models, schemas, and clients shared by Atlas
Agent Engine SDK integrations. The package has no dependency on the
platform runtime and can be used to define agent, execution, message,
tool, and LLM contracts in an independent application.

.. blockquote::

   This is an internal core package; agents don't install it directly. Install a
   framework SDK (``@mongodb-js/agent-engine-sdk-langgraph``), which depends on it.

Install
-------

.. code:: bash

   npm install @mongodb-js/agent-engine-sdk

The package exports the core types and runtime schemas from its root
entry point. See the `API reference <docs/api.md>`__ for the full
exported surface.
