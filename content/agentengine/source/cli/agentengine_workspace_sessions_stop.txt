agentengine workspace sessions stop
-----------------------------------

Stop a runtime session’s reserved sandbox capacity.

Synopsis
~~~~~~~~

Stop a session’s reserved agent and tool sandboxes.

Stop returns as soon as termination is accepted. The session appears as
stopping until both reservations are released, after which it disappears
from the list. Conversation history is kept.

Any state held only in those sandboxes (process memory, ephemeral files,
undurable local writes) is lost.

.. code-block:: bash

   agentengine workspace sessions stop <session-id> [flags]

Examples
~~~~~~~~

.. code-block:: bash

     agentengine workspace sessions stop <session-id>
     agentengine workspace sessions stop <session-id> --workspace-id <workspace-id>
