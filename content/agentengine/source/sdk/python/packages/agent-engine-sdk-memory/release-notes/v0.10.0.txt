agent-engine-sdk-memory v0.10.0
===============================

What's new
----------

- Hosted authentication is now documented and named as a service-account
  access token: construct with
  ``Memory(service_account_token=..., project_id=...)`` or set
  ``AGENTIC_MEMORY_SERVICE_ACCOUNT_TOKEN``. The README's hosted guide
  walks through minting a token (``agentic service-account create``,
  then the OAuth token exchange). The previous ``api_key`` argument and
  ``AGENTIC_MEMORY_API_KEY`` environment variable remain accepted as
  deprecated aliases, emit a ``DeprecationWarning`` when used, and
  conflict with the new input — passing both raises ``ValueError``.
