.. _om-manage-license-keys:

==================================
Manage License Keys in Ops Manager
==================================

.. default-domain:: mongodb

.. meta::
   :description: Use the License Key Manager page in Ops Manager to find your Key Manager ID, install a license key, review license key status and entitlements, release a license key, and download a release receipt.

.. contents:: On this page
   :local:
   :backlinks: none
   :depth: 1
   :class: singlecol

Use the License Key Manager page to review the license key status of
your |mms| installation and to install or release a license key. To
learn how |mms| calculates license key status, see
:ref:`license-keys`.

Prerequisites
-------------

Before you begin, ensure that you have the :authrole:`Global Owner`
role. Users without this role see only the message ``Only Global Owners
can view and manage license keys.`` on the License Key Manager page.

.. _om-license-key-manager-page:

About the License Key Manager Page
----------------------------------

The License Key Manager page shows the license key status of your |mms|
installation. To open the page, click :guilabel:`Admin`,
:guilabel:`License Keys`. The page has the following sections:

- :guilabel:`Overall status` shows the status of your installation and
  the message that matches it. To learn about each status, see
  :ref:`license-keys`.
- :guilabel:`Key Manager ID` shows the ID that identifies your |mms|
  installation, including every instance in a high-availability setup.
  The Key Portal uses the Key Manager ID to issue a license key for your
  installation.
- :guilabel:`Installed license keys` lists your license keys. The
  :guilabel:`Active` list shows license keys that cover your
  installation. The :guilabel:`Inactive` list shows expired, released,
  and denied license keys with their status. Use the :guilabel:`View`
  control to switch between the lists. The table shows the license key
  ID, the expiry date, when MongoDB generated the license key, and when
  you installed it.
- :guilabel:`Entitlements` shows the entitlements of the selected
  license key. Click a license key ID to select it.

Find the Key Manager ID
-----------------------

Use the following procedure to find the Key Manager ID of your |mms|
installation.

.. procedure::
   :style: normal

   .. step:: Open the License Key Manager page

      Click :guilabel:`Admin`, :guilabel:`License Keys`.

   .. step:: Copy the Key Manager ID

      In the :guilabel:`Key Manager ID` section, click the copy button
      next to the ID.

.. _om-install-license-key:

Install a License Key
---------------------

Use the following procedure to generate a license key in the Key Portal
and install it in |mms|.

.. procedure::
   :style: normal

   .. step:: Open the License Key Manager page

      Click :guilabel:`Admin`, :guilabel:`License Keys`.

   .. step:: Open the instructions for getting a license key

      Click :guilabel:`How to get a license key`. The
      :guilabel:`Get your license key` window shows the Key Manager ID
      and a link to the Key Portal.

   .. step:: Generate the license key in the Key Portal

      Open the Key Portal at ``https://support.mongodb.com/keyportal``.
      Use the Key Manager ID to add the Key Manager, and then generate
      your license key. Download the license key file. The file has the
      ``.json`` extension.

      If you can't generate a license key, your MongoDB order might be
      expiring or pending renewal. Contact the person who manages your
      MongoDB Enterprise Advanced order or your MongoDB account team.

   .. step:: Upload the license key

      Return to |mms|, click :guilabel:`Upload license key`, and select
      the license key file.

      If |mms| accepts the license key, the page shows the new status.
      If |mms| rejects the license key, an error window appears. To
      resolve the error, see :ref:`om-license-key-install-errors`.

If you already have a license key file, click :guilabel:`Upload license
key` at the top of the page to skip the instructions window.

If your |mms| installation can connect to MongoDB, |mms| installs
renewed license keys automatically. To learn more, see
:ref:`license-keys-auto-install`.

Release a License Key
---------------------

Use the following procedure to release a license key from your |mms|
installation.

.. important::

   After you release a license key, you can't use it again. Without a
   valid license key, your |mms| installation might lose its active
   status. To restore the status, generate a new license key in the Key
   Portal and install it. For the steps, see
   :ref:`om-install-license-key`.

.. procedure::
   :style: normal

   .. step:: Open the License Key Manager page

      Click :guilabel:`Admin`, :guilabel:`License Keys`.

   .. step:: Release the license key

      In the :guilabel:`Active` list, click :guilabel:`Release` next to
      the license key, and then click :guilabel:`Confirm release`.

Download a Release Receipt
--------------------------

Use the following procedure to download the release receipt of a
license key that you released. |mms| offers a receipt only for released
license keys. Keep the receipt as proof of the release. If your
installation can't connect to MongoDB, upload the receipt in the Key
Portal.

.. procedure::
   :style: normal

   .. step:: Open the License Key Manager page

      Click :guilabel:`Admin`, :guilabel:`License Keys`.

   .. step:: Open the list of inactive license keys

      In the :guilabel:`Installed license keys` section, click
      :guilabel:`Inactive`.

   .. step:: Download the receipt

      Click :guilabel:`Release receipt` next to the license key that
      has the status ``Released``. |mms| downloads a JSON file named
      ``release-receipt-{artifactId}.json``, where ``{artifactId}`` is
      the license key ID.

.. _om-license-key-install-errors:

Troubleshoot Install Errors
---------------------------

When |mms| rejects a license key, the interface shows the message
``License key install failed`` with the following explanation:

.. code-block:: none
   :copyable: false

   The license key could not be validated. It may be corrupted or
   issued for a different Key Manager ID. Upload the correct license
   key to continue.

The window also shows the error code and message that the |api|
returns. The following table lists each error code with its HTTP status
and message. The messages use the word ``artifact`` to refer to a
license key:
