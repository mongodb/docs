=========================================
sh.shardDrainingStatus() (mongosh method)
=========================================

.. meta::
   :description: Use the sh.shardDrainingStatus() method in mongosh to check the draining progress of a specific shard, or of all draining shards, in a sharded cluster.

.. contents:: On this page
   :local:
   :backlinks: none
   :depth: 1
   :class: singlecol

Definition
----------

.. method:: sh.shardDrainingStatus(shardId)

   .. include:: /includes/command/shardDrainingStatus.rst

   .. versionadded:: 9.0


   If you don't specify ``shardId``, the method returns the status of
   all shards that are currently draining.

   .. |dbcommand| replace:: :dbcommand:`shardDrainingStatus` command
   .. include:: /includes/fact-mongosh-shell-method-alt.rst

Syntax
------

.. code-block:: javascript

   sh.shardDrainingStatus( <shardId> )

Parameters
~~~~~~~~~~

.. list-table::
   :header-rows: 1
   :stub-columns: 1
   :widths: 20 20 60

   * - Parameter
     - Type
     - Description

   * - ``shardId``
     - string
     - Optional. Name of the draining shard to report on. If
       omitted, the method reports on all draining shards.

Output Fields
~~~~~~~~~~~~~

For output fields, see the :ref:`shardDrainingStatus
<manual-shardDrainingStatus-output>` command.

Example
-------

The following example returns the draining status of the ``shard04``
shard:

.. io-code-block:: 

   .. input::
      :language: javascript

      sh.shardDrainingStatus( "shard04" )

   .. output::
      :language: javascript

      {
         msg: "draining ongoing",
         state: "ongoing",
         remaining: {
            chunks: Long(2),
            dbs: Long(2),
            jumboChunks: Long(0),
            collectionsToMove: Long(2)
         },
         shard: "shard04",
         note: "you need to call moveCollection for collectionsToMove and afterwards movePrimary for the dbsToMove",
         dbsToMove: [
            "fizz",
            "buzz"
         ],
         collectionsToMove: [
            "fizz.coll1",
            "buzz.coll1"
         ],
         ok: 1,
         operationTime: Timestamp(1575399086, 1655),
         $clusterTime: {
            clusterTime: Timestamp(1575399086, 1655),
            signature: {
               hash: BinData(0,"XBrTmjMMe82fUtVLRm13GBVtRE8="),
               keyId: Long("6766255701040824328")
            }
         }
      }
