Overview
--------

This page describes the connection options available in the {+driver-short+} and
explains how to apply them to your MongoDB connection.

How to Specify Connection Options
---------------------------------

The following sections describe how you can specify connection options by
using a connection string or a ``ClientOptions`` struct.

.. _template-connection-uri:

Use the Connection String
~~~~~~~~~~~~~~~~~~~~~~~~~~

You can specify connection options in a connection string by passing a ``ClientOptions`` struct 
to the  ``Connect()`` method. In the connection string, you can include
connection options in the string as ``<name>=<value>`` pairs. In the following example,
the connection string contains the ``connectTimeoutMS`` option with a value of ``60000`` milliseconds
and the ``tls`` option with a value of ``true``:

   :language: go
   :dedent:

   :end-before: end-connection-uri

Use the ClientOptions Struct
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

You can also chain connection options to the ``ClientOptions`` struct to configure 
connection settings. Configuring the connection this way makes it easier to
change settings at runtime, helps you catch errors during compilation, and provides
more configuration options than the connection string.

and enables TLS by passing an empty ``tls.Config`` struct to the ``SetTLSConfig()`` method:

      Zlib Compression Level
      ~~~~~~~~~~~~~~~~~~~~~~

      The compression level for ``zlib`` to use. This option is ignored if ``zlib`` is not specified 
      as a compressor through ``ApplyURI`` or ``SetCompressors``. This option accepts an
      integer value between ``-1`` and ``9``:

      - ``-1``: (Default). ``zlib`` uses its default compression level
        (usually ``6``).
      - ``0``: No compression.
      - ``1``: Fastest speed but lowest compression.
      - ``9``: Best compression but slowest speed.

      *Data Type:* ``int``

      *Default Value:* ``-1``

      *Example:*

      .. literalinclude:: /includes/connect/connection-options.go
         :language: go
         :copyable: true
         :dedent:
         :start-after: start-uri-zlib-level
         :end-before: end-uri-zlib-level

      Zstandard Compression Level
      ~~~~~~~~~~~~~~~~~~~~~~~~~~~~

      The compression level for ``zstd`` to use. This option is ignored if ``zstd`` is not specified 
      as a compressor through ``ApplyURI`` or ``SetCompressors``. This option accepts integer values
      between ``1`` and ``20``:
      
      - ``1``: Fastest speed but lowest compression.
      - ``20``: Best compression but slowest speed.

      *Data Type:* ``int``

      *Default Value:* ``6``
