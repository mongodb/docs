{+local-short+} Server Configuration

Configure the {+local-short+} to interact with your MongoDB
deployments from AI clients.

The following sections describe AI client compatibility and
prerequisites for the {+local-short+}, and provide links to pages with
the {+local-short+} configuration options. For a basic {+local-short+}
configuration and introduction, see :ref:`mcp-get-started`.

AI Client Compatibility
-----------------------

The {+local-short+} is compatible with AI clients that support MCP.
For example, you can use these AI clients:


- `Claude Desktop <https://modelcontextprotocol.io/quickstart/user>`__
- `Claude Code <https://code.claude.com/docs/en/mcp>`__
- `Cursor <https://docs.cursor.com/context/model-context-protocol>`__
- `fx <https://fx.sh/docs/capabilities/mcp>`__

The JSON configuration file structure can vary for each AI client. Read
the AI client documentation for details.

For a list of clients that support MCP, see `MCP Clients
<https://modelcontextprotocol.io/clients>`__.

Prerequisites
-------------

Ensure you have already installed the software as specified in :ref:`MCP
Server software prerequisites <mcp-get-started-prerequisites>`.

The {+local-short+} can run Atlas tools that perform various Atlas
operations. To run the Atlas tools, your Atlas cluster requires a
service account with the appropriate permissions.

To set up a service account, see :ref:`mcp-server-prerequisites`.

For a list of the tools, see :ref:`mcp-server-tools`.

{+local-short+} Configuration Tasks and Operations
--------------------------------------------

To perform {+local-short+} configuration tasks and operations, see
the following pages:

.. list-table::
   :header-rows: 1
   :widths: 30 70

   * - Page
     - Description
   * - :ref:`Options <mcp-server-configuration-options>`
     - View {+local-short+} options that specify how to connect to a
       cluster and control {+local-short+} operations.
   * - :ref:`Methods <mcp-server-configuration-methods>`
     - Set {+local-short+} options in a JSON configuration file, a
       command line, and environment variables.
   * - :ref:`Enable or disable features
       <mcp-server-configuration-enable-or-disable-features>`
     - Enable or disable {+local-short+} features such as read-only
       mode, specific MCP tools, telemetry data collection about
       system use, and using indexes in queries.
   * - :ref:`Export data <mcp-server-configuration-export-data>`
     - Export results returned by queries and aggregation pipelines to
       files.
   * - :ref:`Standalone service
       <mcp-server-configuration-standalone-service>`
     - Configure the {+local-short+} to run as a standalone service.
   * - :ref:`Troubleshoot problems
       <mcp-server-configuration-troubleshooting>`
     - Examine {+local-short+} logs for information that can help
       resolve problems.
