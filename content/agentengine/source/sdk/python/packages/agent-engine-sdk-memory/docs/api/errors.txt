agent_engine_sdk_memory.errors
==============================

Exceptions raised by the memory seam.

.. _python-packages-agent-engine-sdk-memory-docs-api-agent_engine_sdk_memory.errors.memoryidentityerror:

MemoryIdentityError
-------------------

.. code-block:: python

   class MemoryIdentityError(ValueError)

Raised when a required identity dimension cannot be resolved.

.. _python-packages-agent-engine-sdk-memory-docs-api-agent_engine_sdk_memory.errors.memoryclienterror:

MemoryClientError
-----------------

.. code-block:: python

   class MemoryClientError(ValueError)

Base for pre-HTTP client/usage errors (no status code or response body).

Subclasses ``ValueError`` so callers that guard client-side validation
with a plain ``except ValueError`` keep working.

.. _python-packages-agent-engine-sdk-memory-docs-api-agent_engine_sdk_memory.errors.memorynotsupportederror:

MemoryNotSupportedError
-----------------------

.. code-block:: python

   class MemoryNotSupportedError(MemoryClientError)

Raised when an operation is unavailable in the active transport mode.

This is a client-side capability check raised before any HTTP request is
attempted, so it carries no status code or response body.

.. _python-packages-agent-engine-sdk-memory-docs-api-agent_engine_sdk_memory.errors.memoryroutenotfounderror:

MemoryRouteNotFoundError
------------------------

.. code-block:: python

   class MemoryRouteNotFoundError(MemoryBadRequestError)

Raised when a core-loop request 404s, hinting a route-shape mismatch.

The SDK selects the route shape from ``project_id`` presence (set =>
project-scoped Gateway routes; empty => flat OE routes). A 404 on a
core-loop POST most often means that shape does not match the backend
the ``base_url`` points at, so this carries a directional, actionable
hint rather than the opaque 404. It subclasses ``MemoryBadRequestError``
so existing 4xx handling still catches it.
