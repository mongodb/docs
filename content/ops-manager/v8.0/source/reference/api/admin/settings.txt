===================
Global App Settings
===================

.. default-domain:: mongodb

.. meta::
   :description: Use the |onprem| API to retrieve or update global application settings for your installation. The Global App Settings resource requires the Global Owner role to access.

Use this resource to retrieve or update the global application
settings for an |onprem| installation. These settings
correspond to the options in :guilabel:`Admin` >
:guilabel:`General` > :guilabel:`Ops Manager Config` in the
|onprem| UI.

Required Roles
--------------

To access this resource, your |api| key must have the
:authrole:`Global Owner` role.

Endpoints
---------

The following endpoints are available for the Global App
Settings resource:

.. list-table::
   :header-rows: 1
   :stub-columns: 1
   :widths: 10 50 40

   * - Method
     - Endpoint
     - Description

   * - ``GET``
     - :ref:`/admin/settings <om-api-get-global-app-settings>`
     - Retrieves the global app settings.

   * - ``PATCH``
     - :ref:`/admin/settings <om-api-update-global-app-settings>`
     - Updates the global app settings.
