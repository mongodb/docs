.. _agentengine_egress_clear:

agentengine egress clear
------------------------

Reset both components to deny_all (unsupported).

Synopsis
~~~~~~~~

Live outbound-access edits are no longer supported; the command fails
locally.

Declare destinations in the agent file with
``agentengine agent egress add`` or ``remove``, then deploy. Inspect
with ``agentengine egress``.

.. code-block:: bash

   agentengine egress clear [flags]
