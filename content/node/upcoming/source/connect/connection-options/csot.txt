===========================
Limit Server Execution Time
===========================

.. contents:: On this page
   :local:
   :backlinks: none
   :depth: 2
   :class: singlecol

.. facet::
   :name: genre
   :values: reference

.. meta::
   :keywords: error, blocking, thread, task

Overview
--------

When you use the {+driver-short+} to perform a server operation, you can
limit the duration allowed for each stage of the operation. Specify the
per-stage timeout options to limit stages such as server selection,
connection checkout, and server-side execution. When a timeout expires,
the {+driver-short+} raises a timeout exception.

.. warning::

   The ``timeoutMS`` and ``timeoutMode`` connection options are deprecated
   in {+driver-short+} v7.8 and later. These options have no effect and are
   slated for removal in a future release.

   In {+driver-short+} versions 6.11 through 6.21 and 7.0 through 7.7,
   the ``timeoutMS`` connection option can cause connection pool
   desynchronization. The desynchronization occurs after an operation
   timeout and can expose other users' data. To learn more, see the
   upgrade warning in the :ref:`Version 7.8 release notes
   <version-7.8>`.

   Use the per-stage timeout options described on this page instead.

Per-Stage Timeout Options
-------------------------

The {+driver-short+} provides the following options to limit the time
allowed for each stage of a server operation:

- ``serverSelectionTimeoutMS``: Limits the time in milliseconds that
  the driver blocks for server selection before raising an error.

- ``waitQueueTimeoutMS``: Limits the time in milliseconds that the
  driver spends attempting to check out a connection from a server's
  connection pool.

- ``socketTimeoutMS``: Limits the time in milliseconds that the driver
  spends attempting to send or receive on a socket.

- ``maxTimeMS``: Limits the time in milliseconds that the server
  spends executing an operation after the operation reaches the server.
  You can pass ``maxTimeMS`` only to an individual operation or to a
  cursor.

To learn how to specify these options, including code examples, see the
Connection Timeout Options section of the
:ref:`Specify Connection Options <node-connection-options>` guide.
