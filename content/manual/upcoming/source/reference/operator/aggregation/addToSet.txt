================================
$addToSet (accumulator operator)
================================

.. meta::
   :description: Use `$addToSet` in aggregation to return an array of unique values from an expression applied to each document in a group.

.. contents:: On this page
   :local:
   :backlinks: none
   :depth: 1
   :class: singlecol

Definition
----------

.. group:: $addToSet

Returns an array of unique values for an :ref:`expression <aggregation-expressions>`
evaluated across documents in a group. The order of elements in the array
is unspecified.

``$addToSet`` is available in these stages:
  
- :pipeline:`$bucket`
- :pipeline:`$bucketAuto`
- :pipeline:`$group`

.. note:: Disambiguation

   This page describes ``$addToSet`` when used as an **accumulator**.
   Accumulators return a single aggregated value like sum, maximum, or
   minimum across a group of input documents.

   You can also use ``$addToSet`` in these other contexts:

   - :window:`$addToSet (window function) <$addToSet>`, which is used in the
     :pipeline:`$setWindowFields` stage to return an array of unique values
     from documents in a particular window.
   - :update:`$addToSet (update operator) <$addToSet>`, which adds
     unique elements to an array field in a document.

Syntax
------

.. code-block:: none
   :copyable: false

   { $addToSet: <expression> }

For more information on expressions, see :ref:`aggregation-expressions`.

Behavior
--------

.. include:: /includes/addToSet-behavior.rst

``$addToSet`` cannot write temporary files to disk. The
``internalQueryMaxAddToSetBytes`` server parameter controls the ``$addToSet``
memory limit and if the accumulated array exceeds that limit, MongoDB returns an
error even when :ref:`allowDiskUse <aggregate-cmd-allowDiskUse>` is ``true``.
By default, the parameter is 104857600 bytes (100 megabytes). You can raise the
limit at runtime with the :dbcommand:`setParameter` command.

Starting in MongoDB 9.0, you can also override the parameter for a single
:ref:`query shape <query-shapes>` with the ``queryKnobs`` setting, using the
wire name ``queryMaxAddToSetBytes``.

For more information about aggregation memory restrictions, see
:ref:`agg-pipeline-limits`.
