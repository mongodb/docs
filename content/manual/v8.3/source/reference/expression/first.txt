===================
$first (expression)
===================

.. meta::
   :description: Use $first to return the first element of an array.

.. contents:: On this page
   :local:
   :backlinks: none
   :depth: 1
   :class: singlecol

Definition
----------

.. expression:: $first

Returns the first element of an array.

.. note:: Disambiguation

   This page describes ``$first`` when used as an **expression**, which
   returns the first element of an array.

   You can also use ``$first`` in these other contexts:

   - :group:`$first (accumulator) <$first>`, used in grouping to return
     the first value from each group.
   - :window:`$first (window function) <$first>`, used in the
     :pipeline:`$setWindowFields` stage to return a value for the first
     document in a window.

Syntax
------

.. code-block:: javascript

   { $first: <expression> }

The ``<expression>`` must evaluate to an array.

Behavior
--------

- If the operand expression evaluates to an array, ``$first`` returns the first
  element of that array.

- If the array is empty, ``$first`` returns ``null``.

- If the expression evaluates to ``null`` or refers to a missing field,
  ``$first`` returns ``null``.

- :pipeline:`$match` filters for three specific movies.
- :pipeline:`$addFields` with ``$first`` creates a new field

  array.
- :pipeline:`$project` includes only the ``title``, ``cast``,
  and ``topBilledActor`` fields in the output.
- :pipeline:`$sort` sorts the results by title.
