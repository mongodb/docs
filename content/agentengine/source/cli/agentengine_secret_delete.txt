.. _agentengine_secret_delete:

agentengine secret delete
-------------------------

Delete a secret.

Synopsis
~~~~~~~~

Delete a secret.

The name must match ^[A-Z][A-Z0-9\_]{0,127}$. A name that has since
become a reserved platform name can still be deleted, so a stale secret
can be removed.

Deletion is permanent. The command prints the resolved target, then asks
for confirmation. Without --yes, a non-interactive run refuses instead of
deleting.

By default this deletes project-scoped secrets (shared across all
workspaces in the project). To delete a workspace-scoped secret instead,
pass --workspace-scope or supply --workspace-id. --context names the
organization and project only, so combine it with --project-scope.

.. code-block:: bash

   agentengine secret delete NAME [flags]

Options
~~~~~~~

.. code-block:: bash

         --base-url string       Platform base URL
         --context string        Named context to target (see 'agentengine context list')
     -h, --help                  help for delete
         --org-id string         Organization ID
         --project-id string     Project ID
         --project-scope         Target project-scoped secrets (the default; explicit alternative to --workspace-scope)
         --workspace string      Monorepo: target a specific workspace by name (from root agent.yaml)
         --workspace-id string   Workspace ID
         --workspace-scope       Target workspace-scoped secrets instead of project-scoped secrets (the default)
     -y, --yes                   Skip the interactive confirmation prompt
