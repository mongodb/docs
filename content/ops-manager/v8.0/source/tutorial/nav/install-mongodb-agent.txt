.. _install-agent:

=======================================
Install the {+mdbagent+} on Your Hosts
=======================================

.. meta::
   :description: Choose an Ops Manager installation workflow for the MongoDB Agent, depending on whether you want Automation to manage your deployments or only monitor and back them up.
   :robots: noindex, nosnippet

.. default-domain:: mongodb

.. contents:: On this page
   :local:
   :backlinks: none
   :depth: 1
   :class: singlecol

You install the {+mdbagent+} on each host that runs a MongoDB process
you want |mms| to work with. The workflow you follow depends on whether
you want {+aagent+} to manage those deployments.

Before you install the {+mdbagent+}, review the
:ref:`install-mongodb-agent-prereq`.

Installation Workflows
----------------------

Choose the workflow that matches what you want |mms| to do:

.. list-table::
   :header-rows: 1
   :widths: 45 55

   * - Workflow
     - When to Use

   * - :ref:`Install the MongoDB Agent to Manage Deployments
       <automation-agent-install-steps-manage>`
     - You want {+aagent+} to manage your MongoDB deployments. You can
       also monitor and back up those deployments with this workflow.

   * - :ref:`Install the MongoDB Agent to Monitor or Back Up Deployments
       <automation-agent-install-steps-monitor>`
     - You want to monitor or back up your MongoDB deployments without
       placing them under {+aagent+} management.
