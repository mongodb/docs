===============================================
Install the MongoDB Agent to Manage Deployments
===============================================

.. meta::
   :description: Install the MongoDB Agent on Windows, Linux, Ubuntu, Debian, or RHEL so Automation can manage your MongoDB deployments in Cloud Manager, and monitor and back them up.

.. default-domain:: mongodb

.. _automation-agent-install-steps:
.. _automation-agent-install-steps-manage:
.. _mongodb-agent-install-steps:
.. _mongodb-agent-install-from-package:
.. _mongodb-agent-install-from-archive:

Install the {+mdbagent+} on each host that runs a MongoDB process you
want {+aagent+} to manage. After you finish this workflow, you can also
monitor and back up those deployments.

Before you install the {+mdbagent+}, review the
:ref:`install-mongodb-agent-prereq`.
