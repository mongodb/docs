agentengine context pin
-----------------------

Bind the current agent directory to a named context.

Synopsis
~~~~~~~~

Bind the agent directory found by walking up from the current directory
to context NAME. Workspace-scoped commands run from here resolve NAME’s
base URL, organization, and project whenever no --context or explicit
target flags are given.

A directory with no pin is pinned without a prompt. Re-pinning a
directory to a different context asks first; --yes skips the prompt, and
a non-interactive run without --yes is refused.

.. code-block:: bash

   agentengine context pin NAME [flags]

Examples
~~~~~~~~

.. code-block:: bash

     agentengine context pin prod
     agentengine context pin local --yes

Options
~~~~~~~

.. code-block:: bash

     -h, --help   help for pin
         --json   Output JSON
     -y, --yes    Skip the interactive confirmation prompt
