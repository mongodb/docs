*Released 2026-10-26*

We are pleased to announce version 100.20.0 of the MongoDB Database
Tools.

This release removes support for MongoDB Server versions before 4.2.
The target server and any dump files must now be from MongoDB 4.2 or
later. This release also fixes two ``mongorestore`` bugs. The release
includes Go 1.27.3 and Go driver upgrades.

Bug:

- :issue:`TOOLS-4176` - ``mongorestore`` crash when namespace without
  active consumer is used
- :issue:`TOOLS-4373` - ``mongorestore --oplogReplay`` aborts with
  ``Location7667503`` when a time series collection was written during
  ``mongodump --oplog``

Task:

- :issue:`TOOLS-4350` - Remove support for pre-4.2 Server versions and
  dump files
- :issue:`TOOLS-4401` - Upgrade to the latest Go driver version
- :issue:`TOOLS-4404` - Remove Amazon 2018 from CI
- :issue:`TOOLS-4414` - Upgrade our ``github.com/deckarep/golang-set``
  dependency to v3
- :issue:`TOOLS-4432` - Upgrade to Go 1.27.3
