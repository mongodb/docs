===========================
$topN (expression operator)
===========================

.. meta::
   :description: Use $topN as an expression operator to return the top n elements of an array based on a specified sort order. Handles ties using secondary sort keys and works with any array values.

.. default-domain:: mongodb

.. contents:: On this page
   :local:
   :backlinks: none
   :depth: 1
   :class: singlecol

Definition
----------

.. expression:: $topN

   .. versionadded:: 8.3

   Returns the top ``n`` elements of an array according to the specified sort
   order. If the array contains fewer than ``n`` elements, ``$topN`` returns all
   elements in the array.

.. note:: Other Uses of ``$topN``

   This page describes ``$topN`` when used as an **expression**, which
   operates on array values.

   You can also use ``$topN`` in these other contexts:

   - :group:`$topN (accumulator) <$topN>`, which returns the top
     ``n`` elements within a group according to the specified sort
     order.

   - :window:`$topN (window function) <$topN>`, which is used in
     the :pipeline:`$setWindowFields` stage to return the top ``n``
     elements from documents in a particular window.

Syntax
------

When used as an expression operator, ``$topN`` has the following syntax:

.. code-block:: none
   :copyable: false

   {
      $topN:
         {
            n: <expression>,
            sortBy: <expression>,
            input: <expression>
         }
   }

.. list-table::
   :header-rows: 1
   :widths: 15 15 70

   * - Field
     - Necessity
     - Description

   * - n

     - Required

     - The number of array elements to return.

   * - sortBy

     - Required

     - Specifies the order of results. See :ref:`Sort Behavior <topN_sort_behavior>` for more
       information on ``sortBy`` values.

   * - input

     - Required

     - The array that ``$topN`` evaluates.

Behavior
--------

Null and Missing Values
~~~~~~~~~~~~~~~~~~~~~~~~~

- ``$topN`` does not filter out null values.
- ``$topN`` converts missing values to null.

Input Values
~~~~~~~~~~~~

The ``input`` field must resolve to an array. If you specify an ``input`` that is not
an array, MongoDB returns an error.
