.. _typescript-packages-agent-engine-runner-shared-docs-api-unknownoutcomepolicy:

UnknownOutcomePolicy
--------------------

UnknownOutcomePolicy tells OE what to do with a tool activity that was
started by an attempt whose runner was lost before reporting an outcome.
RERUN gives the tool at-least-once execution; the other values never run
it again.

Generated
~~~~~~~~~

from enum mongodb.agentic.workflow.v1.UnknownOutcomePolicy

Enumeration Members
~~~~~~~~~~~~~~~~~~~

.. list-table::
   :header-rows: 1

   * - Enumeration Member
     - Value
     - Description
   * - ``FAIL``
     - ``1``
     - Refuse a replacement attempt while the outcome is unknown.
       **Generated** from enum value: UNKNOWN_OUTCOME_POLICY_FAIL = 1;
   * - ``RERUN``
     - ``2``
     - Dispatch the activity again to the replacement attempt.
       **Generated** from enum value: UNKNOWN_OUTCOME_POLICY_RERUN = 2;
   * - ``UNSPECIFIED``
     - ``0``
     - **Generated** from enum value: UNKNOWN_OUTCOME_POLICY_UNSPECIFIED
       = 0;
