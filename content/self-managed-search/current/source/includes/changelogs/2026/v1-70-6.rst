Bug Fixes
~~~~~~~~~

.. list-table::
   :header-rows: 1
   :widths: 70 15 15

   * - Description
     - Available in Community Edition
     - Available in Enterprise Advanced

   * - **Incorrect index ID returned for existing indexes.** The
       ``createSearchIndexes`` command could return an index ID that
       was never stored when an equivalent index already existed, so
       later ``updateSearchIndex`` or ``dropSearchIndex`` requests by
       ``id`` did not match the index. The command now returns the
       stored index ID. *Fixed in v1.70.6.*
     - |checkmark|
     - |checkmark|

   * - **Cursor access across clients.** A gRPC client could read
       from or close a search cursor created by another client by
       using only its cursor ID. mongot now validates cursor
       ownership for ``getMore`` and ``killCursors`` requests.
       *Fixed in v1.70.6.*
     - |checkmark|
     - |checkmark|

   * - **Security dependency upgrades.** Third-party libraries with
       known vulnerabilities were updated: bcpkix-fips upgraded to
       2.1.13 (CVE-2026-17508), snappy-java upgraded to 1.1.10.10,
       logback upgraded to 1.6.5, httpclient5 upgraded to 5.6.5, and
       Guava upgraded to 33.7.2-jre. *Fixed in v1.70.6.*
     - |checkmark|
     - |checkmark|

   * - **Docker base image security updates.** The ``mongot`` Docker
       images now use refreshed Red Hat Universal Base Image 9 (UBI9)
       layers that address ``gawk`` (CVE-2026-40468) and ``pcre2``
       (CVE-2026-103111). *Fixed in v1.70.6.*
     - |checkmark|
     - |checkmark|
