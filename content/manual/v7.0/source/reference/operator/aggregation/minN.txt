===============================
$minN (aggregation accumulator)
===============================

.. meta::
   :description: Use `$minN` to aggregate the minimum `n` values within a group, filtering out null and missing values, with dynamic `n` based on group keys.

.. default-domain:: mongodb

.. contents:: On this page
   :local:
   :backlinks: none
   :depth: 1
   :class: singlecol

.. Substitution used in includes and in the body of this text
.. |operatorName| replace:: ``$minN``
.. |operatorOrder| replace:: lowest

Definition
----------

.. group:: $minN

Returns the minimum ``n`` values within a group. If the group
contains fewer than ``n`` elements, ``$minN`` returns all elements
in the group.

.. note:: Disambiguation

   This page describes ``$minN`` when used as an **accumulator**.
   Accumulators return an aggregated value like sum, maximum, or
   minimum across a group of input documents.

   You can also use ``$minN`` in these other contexts:

   - :expression:`$minN (expression) <$minN>`, which returns the ``n``
     minimum values in an array.

   - :window:`$minN (window function) <$minN>`, which is used in the
     :pipeline:`$setWindowFields` stage to return the minimum ``n``
     values from documents in a particular window.

Syntax
------

.. code-block:: javascript
   :copyable: false

   {
      $minN:
         {
            input: <expression>,
            n: <expression>
         }
   }

.. list-table::
   :header-rows: 1
   :class: border-table
   :widths: 10 15 75

   * - Field
     - Type
     - Description

   * - ``input``
     - Expression
     - An expression evaluated for each input document to
       determine the input values. The smallest ``n`` such
       values are retained for each group.

   * - ``n``
     - Expression
     - Determines the maximum number of results returned per group.
       ``n`` must evaluate to a positive integer.

Null and Missing Values
~~~~~~~~~~~~~~~~~~~~~~~

``$minN`` filters out null and missing values.

Consider the following aggregation that returns the minimum ``n`` 
values from a group:

.. code-block:: javascript
   :emphasize-lines: 7,8

   db.aggregate( [
      {
         $documents: [
            { playerId: "PlayerA", gameId: "G1", score: 1 },
            { playerId: "PlayerB", gameId: "G1", score: 2 },
            { playerId: "PlayerC", gameId: "G1", score: 3 },
            { playerId: "PlayerD", gameId: "G1" },
            { playerId: "PlayerE", gameId: "G1", score: null }
         ]
      },
      {
         $group:
         {  
            _id: "$gameId",
            minimumThreeScores:
               { 
                  $minN:
                     {    
                        input: "$score",
                        n: 4
                     }
               }
         }
      }
   ] )

In this example:

- :pipeline:`$documents` creates the literal documents that contain
  player scores.
- :pipeline:`$group` groups the documents by ``gameId``. This
  example has only one ``gameId``, ``G1``.
- ``PlayerD`` has a missing score and ``PlayerE`` has a
  null ``score``. These values are both ignored.
- The ``minimumThreeScores`` field is specified as ``$minN``
  with ``input : "$score"`` and returned as an array.
- Since there are only 3 documents with ``scores``, ``$minN`` returns
  the minimum 3 ``score`` fields even though ``n = 4``.

.. code-block:: javascript
   :copyable: false

   [ 
      { 
      _id: 'G1',
      minimumThreeScores: [ 1, 2, 3 ] 
      } 
   ]

Comparison of $minN and $bottomN Accumulators
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Both ``$minN`` and :group:`$bottomN` accumulators return ``n``
values from a group, but they differ in how they determine which
values to return.

- Use ``$minN`` when the values you want to compare are the
  same values you want to return. ``$minN`` selects the ``n``
  smallest values by comparing inputs directly.

- Use :group:`$bottomN` when you want to define the sort order
  separately from the output. ``$bottomN`` lets you specify a
  ``sortBy`` key to determine which documents are "bottom" and
  an ``output`` expression to control what values to return.

The example pipeline:

- Uses :pipeline:`$match` to filter the results to movies where
  ``Horror`` is included in the ``genres`` array.

  for the ``Horror`` genre with ``n: 3``.
