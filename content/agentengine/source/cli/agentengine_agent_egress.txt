agentengine agent egress
------------------------

Edit the egress allow-list in agent.yaml.

Synopsis
~~~~~~~~

Add, remove, or set the mode of egress destinations in agent.yaml.

These commands edit the local file only and never call the platform.
Changes take effect on the next deploy; agentengine egress shows the
deployed policy.
