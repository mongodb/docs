Introduction
------------

Welcome to the documentation site for the {+driver-long+}, the official
MongoDB driver for {+language+} applications.

Get Started
-----------

Learn how to install the driver, establish a connection to MongoDB, and
begin working with data in the :ref:`scala-get-started` tutorial.

Connect to MongoDB
------------------

Learn how to create and configure a connection to a MongoDB deployment
in the :ref:`Connect <scala-mongoclient>` section.

Databases and Collections
-------------------------

Learn how to use the {+driver-short+} to work with MongoDB databases
and collections in the :ref:`scala-databases-collections` section.

CRUD Operations
---------------

Learn how to insert, query, update, and delete data, and how to access
results from an ``Observable``, in the :ref:`CRUD Operations
<scala-write-insert>` section.

Transform Your Data with Aggregation
------------------------------------

Learn how to use the {+driver-short+} to perform aggregation operations
in the :ref:`scala-aggregation` section.

Data Formats
------------

Learn how to work with BSON, Extended JSON, and other data formats in
the :ref:`Data Formats <scala-bson>` section.

Optimize Queries with Indexes
-----------------------------

Learn how to work with common types of indexes in the
:ref:`scala-indexes` section.

Run a Database Command
----------------------

Learn how to run a database command in the :ref:`scala-run-command`
section.

{+search+}
--------------

Learn how to run {+search+} queries in the :ref:`scala-mongodb-search`
section.

{+vector-search+}
---------------------

Learn how to run {+vector-search+} queries in the
:ref:`scala-vector-search` section.

Logging and Monitoring
----------------------

Learn how to monitor changes to your application and write them to logs
in the :ref:`Logging and Monitoring <scala-monitoring>` section.

Secure Your Data
----------------

Learn how to authenticate your application and encrypt your data in the
:ref:`scala-security` section.

Reference
---------

Find information about new features, driver version compatibility, and
upgrade steps in the :ref:`Reference <scala-whats-new>` section.

Compatibility
-------------

To learn about the versions of the {+mdb-server+} and Scala that are
compatible with each version of the {+driver-short+}, see the
:driver:`Compatibility </compatibility/?driver-language=scala>`
page.

API Documentation
-----------------

For detailed information about the classes and methods in the
{+driver-short+}, see the `{+driver-long+} API documentation
<{+api-root+}/driver-scala/index.html>`__.

Issues & Help
-------------

Learn how to report bugs, contribute to the driver, and find more
resources for asking questions and receiving help in the
:ref:`scala-issues-and-help` section.
