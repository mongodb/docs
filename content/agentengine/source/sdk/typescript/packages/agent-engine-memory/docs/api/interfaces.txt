.. _typescript-packages-agent-engine-memory-docs-api-ambientidentityruntime:

AmbientIdentityRuntime
----------------------

Optional capability: a runtime that can supply per-call ambient
identity.

Only app-bound runtimes running inside the platform stack have access to
per-request context. This is a separate interface so the facade can
detect the capability without requiring every runtime to implement it.
