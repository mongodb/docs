=========================================
Get the Release Receipt for a License Key
=========================================

.. default-domain:: mongodb

.. meta::
   :description: Retrieve the release receipt for a license key that you released from your Ops Manager installation. Ops Manager returns a receipt only for a released license key. Requires the Global Owner role.

.. contents:: On this page
   :local:
   :backlinks: none
   :depth: 1
   :class: singlecol

Retrieves a signed receipt that confirms you released a license key
from an |mms| installation. |mms| returns a receipt only for a
released license key. The |mms| interface offers the same receipt as a
download.

Keep the receipt as proof of the release. If your installation can't
connect to MongoDB, upload the receipt in the Key Portal at
``https://support.mongodb.com/keyportal``.

Required Roles
--------------

To access this resource, your |api| key must have
the :authrole:`Global Owner` role. The Global Owner role is the
highest role in |mms|. Only users with this role can view and manage
license keys.

Request
-------

Send a ``GET`` request with the license key ID in the path.

.. include:: /includes/api/base-api-uri.rst

.. code-block:: http

   GET /admin/artifacts/{artifactId}/receipt

Request Path Parameters
~~~~~~~~~~~~~~~~~~~~~~~

The request path contains the following parameter:

.. list-table::
   :header-rows: 1
   :widths: 20 15 15 50
   :stub-columns: 1

   * - Parameter
     - Type
     - Necessity
     - Description

   * - ``artifactId``
     - string
     - Required
     - Unique identifier of the released license key.

Request Query Parameters
~~~~~~~~~~~~~~~~~~~~~~~~

This endpoint accepts the following query parameters:

.. include:: /includes/api/base-query-single-parameters.rst

Request Body Parameters
~~~~~~~~~~~~~~~~~~~~~~~

This endpoint doesn't use HTTP request body parameters.

Response
--------

The response contains the following field:

.. list-table::
   :header-rows: 1
   :widths: 30 15 55
   :stub-columns: 1

   * - Field
     - Type
     - Description

   * - ``receipt``
     - object
     - Release receipt for the license key, returned as a JSON
       document.

Errors
~~~~~~

If you specify an ``artifactId`` that doesn't match a released license
key, the endpoint returns the HTTP status ``404``. The ``errorCode``
field of the response body contains ``ARTIFACT_NOT_FOUND``, and the
``detail`` field contains ``No released artifact with that id.``

Example Request
---------------

Use ``curl`` to send a ``GET`` request to the ``/admin/artifacts/{artifactId}/receipt`` endpoint:

.. code-block:: sh

   curl --user "{PUBLIC-KEY}:{PRIVATE-KEY}" --digest \
        --header "Accept: application/json" \
        --include \
        --request GET \
        "https://{+opsmgr-url+}/api/public/v1.0/admin/artifacts/{ARTIFACT-ID}/receipt?pretty=true"
