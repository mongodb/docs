==================================
Model Lifecycle and Support Status
==================================

.. facet::
   :name: genre
   :values: reference

.. meta::
   :keywords: support status, retirement, migration, model changelog
   :description: Learn the support status of each Voyage AI embedding and reranking model, what the Active, Legacy, Deprecated, and Retired statuses mean, and how status changes are recorded.

.. contents:: On this page
   :local:
   :backlinks: none
   :depth: 2

Every {+voyageai+} model has a support status that indicates whether you
can use the model for new projects and whether the model remains
available through the :ref:`{+voyage-api+} <voyage-api-and-clients>`.
This page lists the current status of each model and records changes to
those statuses over time.

For model specifications, such as context length and embedding
dimensions, see :ref:`voyage-models`.

Model Statuses
--------------

{+voyageai+} models use the following support statuses:

.. list-table::
   :header-rows: 1
   :widths: 20 80

   * - Status
     - Description

   * - Active
     - The model is fully supported and recommended for new projects.

   * - Legacy
     - The model remains available through the {+voyage-api+}, but a
       newer model supersedes it. Use the recommended replacement for
       new projects.

   * - Deprecated
     - The model remains available through the {+voyage-api+} and is
       scheduled for retirement. Migrate to the recommended replacement
       before the retirement date.

   * - Retired
     - The model is no longer available. Requests that specify a retired
       model fail.
