.. _agentengine_version:

agentengine version
-------------------

Print the agentengine CLI version.

Synopsis
~~~~~~~~

Print the agentengine CLI version.

By default only the version is printed. Pass --full to also print the
build commit, artifact source and image registry, and the embedded
container image defaults.

.. code-block:: bash

   agentengine version [flags]

Options
~~~~~~~

.. code-block:: bash

         --full   Also print the build commit, artifact source, image registry, and embedded image defaults
     -h, --help   help for version
         --json   Output version information as JSON
