Version Compatibility
---------------------

The {+driver-short+} uses the MongoDB C Driver to compress network traffic.
The following table lists the minimum supported C driver and {+mdb-server+} version for
each compression algorithm:

.. list-table::
   :header-rows: 1
   :stub-columns: 1

   * - Compression Algorithm
     - Minimum C Driver Version
     - Minimum Server Version

   * - `Snappy <https://google.github.io/snappy/>`__
     - 1.7
     - 4.2

   * - `Zlib <https://zlib.net/>`__
     - 1.7
     - 4.2

   * - `Zstandard <https://facebook.github.io/zstd/>`__
     - 1.15
     - 4.2

To learn which C driver version your {+driver-short+} version requires,
see :driver:`libmongoc Compatibility </compatibility/?driver-language=cpp#libmongoc-compatibility>`.

.. _cpp-enable-compression:

Enable Network Compression
--------------------------

To enable network compression for your MongoDB connection,
install the required dependencies and specify the compression algorithms
that you want to use.

Install Dependencies
~~~~~~~~~~~~~~~~~~~~

Because the {+driver-short+} uses the MongoDB C Driver to implement
network compression, you must build the C driver with the required dependencies.
To view these dependencies, see :languages:`Install Dependencies
</c/c-driver/upcoming/connect/connection-options/network-compression/#install-dependencies>`
in the C driver documentation.

Set the zlib Compression Level
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

If you specify ``zlib`` as one of your compression algorithms, you can also use the
``zlibCompressionLevel`` option to specify a compression level. This option accepts
an integer value between ``-1`` and ``9``:

- **-1:** *(Default).* zlib uses its default compression level (usually ``6``).
- **0:** No compression.
- **1:** Fastest speed but lowest compression.
- **9:** Best compression but slowest speed.
