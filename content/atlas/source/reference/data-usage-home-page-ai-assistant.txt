MongoDB Atlas Home Page Assistant and Usage Information
-------------------------------------------------------

The MongoDB Atlas Home Page Assistant is an AI assistant that answers
questions about MongoDB and Atlas. It also helps you find the right
place in Atlas. You can follow the links it returns to open the relevant
Atlas page. The assistant is powered by generative AI and may give
inaccurate responses. See the `Generative AI FAQ
<https://dochub.mongodb.org/core/faq-ai-features>`__ for more
information.

The assistant is available within the {+atlas-ui+}, on the
:guilabel:`Project Overview Page`. The assistant cannot take any action
on your behalf.

Third Party Providers
---------------------

This feature currently uses the `Azure OpenAI Service
<https://azure.microsoft.com/en-us/products/ai-services/openai-service>`__
hosted by Microsoft. The AI provider is subject to change.

How Your Data Is Used
---------------------

When you use the MongoDB Atlas Home Page Assistant in |service|, the
following information may be sent to the MongoDB backend or the
third-party AI provider:

- The full text of your prompt.
- A snapshot of your active project, including:

  - The project name and the number of clusters.
  - For each cluster: the cluster name, tier, cloud provider, region,
    MongoDB version, state, whether backups are enabled, and disk size.

The AI provider does not store the information that is sent. MongoDB
does not send unsanitized connection strings, credentials, or
rows/documents from your databases.

Disable the Assistant
---------------------

The MongoDB Atlas Home Page Assistant respects organization-level
generative AI settings. It is not available if your organization
disables generative AI features across all projects from `Organization
Settings
<https://cloud.mongodb.com/v2#/org/69222872fdbcd54ca68d7374/settings/general>`__.
To do so, toggle off :guilabel:`Enable Atlas features that use
generative AI`.

If generative AI features are enabled at the organization level, you can
disable the assistant for a specific project by using the
{+atlas-admin-api+}. To do so,
:oas-bump-atlas-op:`update your project settings <updategroupsettings>`
to toggle ``isAtlasHomePageAiAssistantEnabled`` to ``false``. If
generative AI features are disabled at the organization level, the
assistant is unavailable for all projects, even if
``isAtlasHomePageAiAssistantEnabled`` is set to ``true``. Using the
{+atlas-admin-api+} is the only way to disable the assistant for a
specific project.

If both organization and project level settings are enabled, developers
who have access to the :guilabel:`Project Overview Page` see the
assistant. Interaction with the feature is optional.
