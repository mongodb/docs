.. procedure::
   :style: normal

   .. step:: Click :guilabel:`Stream Processors` in the left-hand navigation menu.

   .. step:: Select the stream processor that you want to delete.

      From the list of stream processors, click the one that you want
      to delete.

      If your stream processor has a status of ``STARTED``, click the
      stop button in the :guilabel:`Actions` column to stop it first.

   .. step:: Click the ellipsis (:icon:`ellipsis-h`) button in the :guilabel:`Actions` column.

   .. step:: Select :guilabel:`Delete stream processor` from the menu.

      In the confirmation dialog that appears, type the name of the
      stream processor to confirm that you want to delete it, then
      click :guilabel:`Delete`.
