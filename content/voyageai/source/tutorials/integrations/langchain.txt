==================================
Integrate {+voyageai+} with LangChain
==================================

LangChain is an open-source framework that provides **chains**
to simplify the creation of {+llm+} applications. Chains consist of
interconnected LangChain components that perform a sequence of
operations. You can use chains for a variety of AI use cases,
including :term:`RAG` and agentic retrieval.

LangChain provides dedicated packages that expose {+voyageai+}
embedding models as standard LangChain embedding classes. When you pair
those packages with MongoDB, you can store your embeddings alongside
your other data and query them with MongoDB Vector Search.

This tutorial demonstrates how to use {+voyageai+} embeddings with
LangChain to complete the following tasks:

#. Load and split source data into documents.
#. Store the documents and their embeddings in MongoDB.
#. Create a MongoDB Vector Search index on your embeddings.
#. Run semantic search queries on your data.
#. Implement RAG to answer questions about your data.

Background
----------

The LangChain integration includes the following {+voyageai+} packages:

- In Python, the ``langchain-voyageai`` package provides the
  ``VoyageAIEmbeddings`` class.

- In TypeScript, the ``@langchain/mongodb`` package provides the
  ``VoyageEmbeddings`` class alongside the
  ``MongoDBAtlasVectorSearch`` vector store.

Because both packages implement LangChain's standard embedding
interface, you can pass a {+voyage+} model to any LangChain component
that accepts embeddings, including vector stores and retrievers.

Next Steps
----------

After you have a working pipeline, you can make the following adjustments
to improve retrieval quality without changing your LangChain chain:

- To reduce the storage footprint of your embeddings, pass the
  ``output_dimension`` parameter when you instantiate
  ``VoyageAIEmbeddings``. The ``voyage-4-large`` model supports
  ``256``, ``512``, ``1024`` (default), and ``2048`` dimensions. To
  learn more, see :ref:`voyage-flexible-dims-quantization`.

- To choose a different embedding model for your domain or latency
  budget, see :ref:`voyage-text-embeddings`.

- To reorder your search results by relevance before you pass them to
  the LLM, add a reranker. To learn more, see :ref:`voyage-rerankers`.

To view additional tutorials, see the following resources:

- To implement RAG without a framework, see :ref:`voyage-rag`.

- To learn about other LangChain tutorials that use MongoDB, see
  :ref:`langchain-get-started`.

- To learn how to use {+voyageai+} models with other LLM frameworks and
  AI services, see :ref:`ai-integrations`.
