=============================
$count (accumulator operator)
=============================

.. meta::
   :description: Explore how to use the `$count` aggregation accumulator to count documents in MongoDB, including examples with `$group` and `$setWindowFields` stages.

.. contents:: On this page
   :local:
   :backlinks: none
   :depth: 1
   :class: singlecol

Definition
----------

.. group:: $count

Returns the number of documents in a group.

The ``$count`` accumulator is available in these stages:

- :pipeline:`$bucket`
- :pipeline:`$bucketAuto`
- :pipeline:`$group`

.. note:: Disambiguation

   This page describes the :group:`$count` aggregation accumulator. You
   can also use ``$count`` in these other contexts:
   
   - :pipeline:`$count (aggregation stage) <$count>`, which returns the
     number of input documents.
   
   - :window:`$count (window function) <$count>`, which is used in the
     :pipeline:`$setWindowFields` stage to return the number of
     documents in a particular window.

Syntax
------

.. code-block:: none
   :copyable: false

   { $count: { } }

The ``$count`` accumulator does not accept any parameters.

.. tip::

   The ``$count`` accumulator is functionally equivalent to using ``{
   $sum: 1 }`` within the :pipeline:`$group` stage.

Examples
--------

.. include:: /includes/sample-data-usage.rst

This example uses :group:`$count` in the :pipeline:`$group` stage to
count the number of movies in the ``sample_mflix.movies`` collection
for each selected ``genre``:

.. io-code-block::
   :copyable: true

   .. input:: /code-examples/tested/command-line/mongosh/aggregation/accumulators/count/count-movies-by-genre.js
      :language: shell
      :category: syntax example

   .. output:: /code-examples/tested/command-line/mongosh/aggregation/accumulators/count/count-movies-by-genre-output.sh
      :visible: false
      :language: shell

In the example:

- ``$unwind: "$genres"`` creates a document for each value in the
  ``genres`` array.

- ``$match`` limits the documents to the ``Drama`` and ``Short``
  genres.

- ``_id: "$genres"`` groups the documents by genre.

- ``$count: {}`` sets the ``countNumberOfMoviesForGenre`` field to the
  number of movies that share the same genre.

The output shows the number of movies for ``Drama`` and ``Short`` in the
``countNumberOfMoviesForGenre`` field.
