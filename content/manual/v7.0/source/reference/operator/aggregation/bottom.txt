.. _bottom_accumulator_operator:

==============================
$bottom (accumulator operator)
==============================

.. meta::
   :description: Use the `$bottom` accumulator to return the lowest element in a group based on a specified sort order in MongoDB aggregation.

.. contents:: On this page
  :local:
  :backlinks: none
  :depth: 1
  :class: singlecol

Definition
----------

.. group:: $bottom

.. include:: /includes/accumulators/bottom-definition.rst

Available in these stages:

- :pipeline:`$bucket`
- :pipeline:`$bucketAuto`
- :pipeline:`$group`

.. note:: Disambiguation

   This page describes ``$bottom`` when used as an **accumulator**.
   Accumulators return a single aggregated value across a group of input
   documents.

   You can also use the :window:`$bottom (window function) <$bottom>`
   in the :pipeline:`$setWindowFields` stage to return the bottom
   element from documents in a particular window.

Syntax
------

.. code-block:: none
   :copyable: false

   {
      $bottom:
         {
            sortBy: { <field1>: <sort order>, <field2>: <sort order> ... },
            output: <expression>
         }
   }

.. list-table::
   :header-rows: 1
   :widths: 15 15 70

   * - Field
     - Necessity
     - Description

   * - sortBy

     - Required

     - Defines the ranking order of elements within each group, with
       syntax similar to :pipeline:`$sort`. Does not affect the order of
       documents in pipeline output.

   * - output

     - Required

     - Represents the output for each element in the group 
       and can be any expression.

Behavior
--------

Null and Missing Values
~~~~~~~~~~~~~~~~~~~~~~~

``$bottom`` does not filter out null values, and ``$bottom`` converts
missing values to null.

Consider the following aggregation that returns the bottom 
document from a group of scores:

.. io-code-block::
   :copyable: true

   .. input::
      :language: javascript
      :emphasize-lines: 7,8

      db.aggregate( [
         {
            $documents: [
               { playerId: "PlayerA", gameId: "G1", score: 1 },
               { playerId: "PlayerB", gameId: "G1", score: 2 },
               { playerId: "PlayerC", gameId: "G1", score: 3 },
               { playerId: "PlayerD", gameId: "G1"},
               { playerId: "PlayerE", gameId: "G1", score: null }
            ]
         },
         {
            $group:
            {
               _id: "$gameId",
               playerId:
                  {
                     $bottom:
                        {
                           output: [ "$playerId", "$score" ],
                           sortBy: { "score": -1 }
                        }
                  }
            }
         }
      ] )

   .. output::
      :language: javascript
      :visible: true

      [
         {
            _id: 'G1',
            playerId: [ 'PlayerD', null ]
         }
      ]

In this example:

- :pipeline:`$documents` creates the literal documents that contain
  player scores.
- :pipeline:`$group` groups the documents by ``gameId``. This
  example has only one ``gameId``, ``G1``.
- ``PlayerD`` has a missing score and ``PlayerE`` has a
  null ``score``. These values are both considered as null.
- The ``playerId`` and ``score`` fields are specified as
  ``output : ["$playerId"," $score"]`` and returned as array values.
- Specify the ranking order with ``sortBy: { "score": -1 }``.
- ``PlayerD`` and ``PlayerE`` tied for the bottom element. ``PlayerD``
  is returned as the bottom ``score``.

Restrictions
------------

Memory Limit Considerations
~~~~~~~~~~~~~~~~~~~~~~~~~~~

Aggregation pipelines which call ``$bottom`` are subject to the
:ref:`100 MB limit <agg-memory-restrictions>`. If this
limit is exceeded for an individual group, the aggregation fails
with an error.

Find the Bottom Rating in a Genre
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

You can use the ``$bottom`` accumulator to find the lowest-rated movie
in a single genre.

.. io-code-block::
   :copyable: true

   .. input:: /code-examples/tested/command-line/mongosh/aggregation/accumulators/bottom/find-bottom-rating-genre.snippet.find-bottom-rating-genre.js
      :language: javascript
      :category: usage example

   .. output:: /code-examples/tested/command-line/mongosh/aggregation/accumulators/bottom/find-bottom-rating-genre-output.sh
      :language: javascript
      :visible: false

The example pipeline:

- Uses :pipeline:`$match` to filter the results on a single genre. 
  In this case, ``Comedy``.
- Uses :pipeline:`$group` to group all Comedy movies under a
  single ``"Comedy"`` group key.
- Specifies the fields that are output for ``$bottom`` with
  ``output : ["$title", "$imdb.rating"]``.
- Uses ``sortBy: { "imdb.rating": -1 }`` to define the bottom element in
  each group as the one with the lowest rating.
- Uses ``$bottom`` to return the lowest-rated movie for the genre.

The example pipeline:

- Uses :pipeline:`$match` to filter for movies from 2010-2012 that have an IMDb rating.
- Uses :pipeline:`$group` to group the results by ``year``.
- Uses ``$bottom`` to return the lowest-rated movie for each year.
- Specifies the fields that are output for ``$bottom`` with
  ``output : ["$title", "$imdb.rating"]``.
- Uses ``sortBy: { "imdb.rating": -1 }`` to define the bottom element in
  each group as the one with the lowest rating.
- Uses :pipeline:`$sort` to sort the results by year in ascending order.
