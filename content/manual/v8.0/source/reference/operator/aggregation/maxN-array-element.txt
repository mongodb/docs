.. _maxN:

===========================
$maxN (expression operator)
===========================

.. meta::
   :description: Retrieve the largest `n` values from an array using the `$maxN` operator in MongoDB aggregation.

.. default-domain:: mongodb

.. contents:: On this page
   :local:
   :backlinks: none
   :depth: 1
   :class: singlecol

Definition
----------

.. expression:: $maxN

   Returns the ``n`` largest values in an array.

.. note:: Other Uses of ``$maxN``

   This page describes ``$maxN`` when used as an **expression**,
   which returns the largest ``n`` values from an array.

   You can also use ``$maxN`` in these other contexts:

   - :group:`$maxN (accumulator) <$maxN>`, which returns the maximum
     ``n`` values within a group.

   - :window:`$maxN (window function) <$maxN>`, which is used in the
     :pipeline:`$setWindowFields` stage to return the largest ``n``
     values from documents in a particular window.

Syntax
------

.. code-block:: javascript
   :category: syntax example
   :copyable: false

   { $maxN: { n: <expression>, input: <expression> } }

.. list-table::
   :header-rows: 1
   :class: border-table
   :widths: 10 15 75

   * - Field
     - Type
     - Description

   * - ``n``
     - Expression
     - Specifies the number of elements to return. Must resolve to a
       positive integer.

   * - ``input``
     - Expression
     - Specifies the input array from which to return the maximum ``n`` elements.

Behavior
--------

- ``$maxN`` filters out ``null`` values.

- If the ``input`` array contains fewer than ``n`` elements,
  ``$maxN`` returns all elements in the array.

- If ``input`` resolves to a non-array value, the operation returns
  an error.

- If ``input`` contains both numeric and string elements, string
  elements are sorted before numeric elements according to the
  :ref:`BSON comparison order <bson-types-comparison-order>`.

The preceding pipeline:

- Uses :pipeline:`$match` to filter for three specific movies.
- Uses :pipeline:`$addFields` with ``$maxN`` to create a new field
  ``topTwoCast`` containing the two alphabetically last values from
  the ``cast`` array with ``n: 2``.
- Uses :pipeline:`$project` to include only the ``title``, ``cast``,
  and ``topTwoCast`` fields in the output.
- Uses :pipeline:`$sort` to sort the results by title.
