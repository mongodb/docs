================================
Add a Shard to a MongoDB Cluster
================================

.. meta::
   :description: Add a shard to a MongoDB cluster using Ops Manager by configuring settings like member roles, hostname, port, and more, then save the changes.

.. default-domain:: mongodb

You can use |mms| to add a shard to a MongoDB :term:`sharded cluster`.

This procedure adds a shard to the cluster's infrastructure. It does
not shard a collection. |mms| does not provide a UI action for
sharding a collection. To shard a collection, use
:method:`sh.shardCollection()` in {+mongosh+}. To learn how, see
:ref:`Shard a Collection <shard-a-collection>`.
