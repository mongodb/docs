.. note::

   {+atlas-sp+} enables continuous, MongoDB-native processing of
   streaming data from Apache Kafka and MongoDB change streams,
   including schema validation and real-time data transformations. It
   can write results directly to MongoDB collections or Apache Kafka
   topics, without deploying or managing Kafka Connect workers.

   To learn more about {+atlas-sp+}, see {+service+}
   `Stream Processing <https://www.mongodb.com/docs/atlas/atlas-sp/overview/>`__.
