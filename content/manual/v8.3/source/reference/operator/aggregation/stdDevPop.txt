=================================
$stdDevPop (accumulator operator)
=================================

.. meta::
   :description: Use the $stdDevPop accumulator in $group, $bucket, and $bucketAuto stages to calculate the population standard deviation of values across a group of documents.

.. contents:: On this page
   :local:
   :backlinks: none
   :depth: 1
   :class: singlecol

Definition
----------

.. group:: $stdDevPop

Calculates the population standard deviation of values across a group of
documents. Use ``$stdDevPop`` if the values encompass the entire
population of data you want to represent and you do not want to
generalize.

If the values represent only a sample from the population, use
:group:`$stdDevSamp` instead.

The ``$stdDevPop`` accumulator is available in these stages:

- :pipeline:`$bucket`
- :pipeline:`$bucketAuto`
- :pipeline:`$group`

.. note:: Disambiguation

   This page describes ``$stdDevPop`` when used as an **accumulator**.
   Accumulators return an aggregated value across a group of input
   documents.

   You can also use ``$stdDevPop`` in these other contexts:

   - :expression:`$stdDevPop (expression) <$stdDevPop>`, which
     returns the population standard deviation of numeric values in
     an array.

   - :window:`$stdDevPop (window function) <$stdDevPop>`, which is
     used in the :pipeline:`$setWindowFields` stage to calculate the
     population standard deviation of values from documents in a
     particular window.

Behavior
--------

Result Type
~~~~~~~~~~~

.. include:: /includes/expressions/stdDevPop/result-type.rst

Non-numeric or Missing Values
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. include:: /includes/expressions/stdDevPop/non-numeric-values.rst

Single Value
~~~~~~~~~~~~

If the input consists of a single numeric value, ``$stdDevPop``
returns ``0``.

The following example groups movies by director and returns the five
directors with the most varied IMDb ratings, among directors with at
least 10 movies.

The preceding pipeline:

- Uses :pipeline:`$match` to filter for movies that have a
  ``directors`` field and a numeric IMDb rating.
- Uses :pipeline:`$unwind` to create one document per director per
  movie, so each director-movie pair is grouped separately.
- Uses :pipeline:`$group` to group by director, count movies, and
  compute ``stdDevRating`` using ``$stdDevPop`` on ``imdb.rating``.
- Uses :pipeline:`$match` to keep only directors with at least 10
  movies.
- Uses :pipeline:`$sort` to return results in descending order by
  ``stdDevRating``.
- Uses :pipeline:`$limit` to return the top 5 results.
