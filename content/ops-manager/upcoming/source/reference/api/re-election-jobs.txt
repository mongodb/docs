.. _api-re-election-jobs:

=================================
Replica Set Re-Election Jobs API
=================================

.. meta::
   :description: Access Ops Manager API endpoints to request and track replica set re-election jobs, including primary step down and secondary step up requests, on paid unmanaged deployments.

.. default-domain:: mongodb

.. contents:: On this page
   :local:
   :backlinks: none
   :depth: 1
   :class: singlecol

You can use the |mms| |api| to perform replica set re-elections
without connecting directly to the deployment's hosts. Use this
resource to make the current primary step down, make a specific
secondary step up to become primary, and track the resulting jobs.

Each request queues a job that the target host's Automation Agent
executes on its next check-in. Use the following endpoints to create
and retrieve re-election jobs.

Prerequisites
-------------

Before you use the Re-Election Jobs resource, review the following
requirements.

.. include:: /includes/fact-groups-projects-synonyms.rst

.. include:: /includes/api/base-api-uri.rst

To use the Re-Election Jobs resources, you must be |a-mms| user with
the ``Project Automation Admin`` role.

.. important::

   This feature requires a paid |mms| subscription on an unmanaged
   (self-hosted) deployment.

Your deployment must run |mms| 8.0.27 or 9.0.0 or later, and the
target host's Automation Agent must run version 109.0.0.9226-1 or
later and must have pinged |mms| recently.

Only one re-election job, either a step-down or a step-up request,
can be outstanding per replica set at a time. If a job is already
queued or running, |mms| rejects a new request against the same
replica set with a ``409 REELECTION_ALREADY_IN_PROGRESS`` error.

.. important::

   Replica set re-election is not supported for Kubernetes Operator
   (MCK) deployments.

Endpoints
---------

The following table lists the endpoints available for the Re-Election
Jobs resource.

.. list-table::
   :header-rows: 1
   :widths: 10 50 40

   * - Method
     - Endpoint
     - Description

   * - ``POST``
     - :ref:`/groups/{GROUP-ID}/replicaSets/{RS-ID}/process/{HOST-PORT}:stepDown <api-re-election-jobs-step-down>`
     - Requests that the current primary of a replica set step down.

   * - ``POST``
     - :ref:`/groups/{GROUP-ID}/replicaSets/{RS-ID}/process/{HOST-PORT}:stepUp <api-re-election-jobs-step-up>`
     - Requests that a specific secondary step up to become primary.

   * - ``GET``
     - :ref:`/groups/{GROUP-ID}/replicaSets/{RS-ID}/reElectionJobs/{REELECTION-JOB-ID} <api-re-election-jobs-get-one>`
     - Retrieves a single re-election job as specified by the
       ``reElectionJobId``.

   * - ``GET``
     - :ref:`/groups/{GROUP-ID}/replicaSets/{RS-ID}/reElectionJobs <api-re-election-jobs-get-all>`
     - Retrieves all re-election jobs for the specified replica set.
