.. _sql-connect-powerbi-private-endpoint:

============================================================
Connect to the {+sql-interface-full+} with a Private Endpoint
============================================================

.. default-domain:: mongodb

.. meta::
   :description: Connect to the MongoDB SQL Interface over a private endpoint, using the standard Atlas cluster endpoint for a dedicated cluster or a Data Federation endpoint for a federated database instance.

.. contents:: On this page
   :local:
   :backlinks: none
   :depth: 1
   :class: singlecol

This page describes how to connect to the {+sql-interface-full+} over a
private endpoint. Which endpoint you use depends on how you connect:

- On a {+dedicated-cluster+}, the {+sql-interface+} uses the standard
  {+service+} {+cluster+} private endpoint, with no
  {+sql-interface+}-specific configuration. To configure one, see
  :ref:`atlas-configure-private-endpoint`.

- Through a {+fdi+}, the {+sql-interface+} uses a {+adf+} private
  endpoint, which is distinct from the {+cluster+} endpoint. MongoDB
  supports {+aws+} and {+azure+} private endpoints for {+fdi+}s. To
  learn more, see :ref:`config-private-endpoint`.

Connect Through a Federated Database Instance
---------------------------------------------

Prerequisites
~~~~~~~~~~~~~

- An |service| {+cluster+} running MongoDB version 5.0 or later.

- An {+aws+} or |azure| :ref:`private endpoint
  <config-private-endpoint>` configured in your {+fdi+}.

.. _connect-private-endpoint-fdi:

Procedure
~~~~~~~~~

Follow these steps to connect your |service| {+cluster+} to the
{+sql-interface+} using a {+fdi+}
:ref:`private endpoint <atlas-configure-private-endpoint>`.

.. procedure::
   :style:  normal

   .. include:: /includes/nav/steps-data-federation.rst

   .. step:: Click the :guilabel:`Connect` button for the {+fdi+} that you want to connect to. 

   .. step:: Select :guilabel:`Private Endpoint` and then do the following:
    
      a. Select your {+FDI+} private endpoint from the :guilabel:`Choose private endpoint` dropdown. 

      b. This endpoint includes "Data Federation" in the name and is 
         distinct from a "Dedicated" endpoint associated with your |service| {+cluster+}.

   .. step:: Click :guilabel:`Choose a connection method`.

   .. step:: Select :guilabel:`Atlas SQL`. 

   .. step:: Validate the provided connection string

      Confirm that the provided connection string in the :guilabel:`URL` field
      contains the characters ``pl``, which indicates a private link.

Connect to a Dedicated Cluster
------------------------------

A {+dedicated-cluster+} uses the standard {+service+} {+cluster+}
private endpoint. The {+sql-interface+} requires no separate endpoint
and no {+sql-interface+}-specific configuration.

Prerequisites
~~~~~~~~~~~~~

- A {+dedicated-cluster+}, ``M10`` and above, running MongoDB 6.0 or
  later.

- A :ref:`MongoDB database user <mongodb-users>` with which to connect.

Procedure
~~~~~~~~~

To connect over a private endpoint:

.. procedure::
   :style: normal

   .. step:: Configure a private endpoint for the {+cluster+}.

      To learn how, see :ref:`atlas-configure-private-endpoint`.

   .. step:: Enable the {+sql-interface+} on the {+cluster+}.

      To learn how, see :ref:`connect-with-sql-composable`.

   .. step:: Get your connection string.

      From :guilabel:`Connect`, click :guilabel:`Atlas SQL`, select
      your driver, and copy the :guilabel:`Connection URL`. When the
      {+cluster+} uses a private endpoint, the connection string
      reflects that endpoint.
