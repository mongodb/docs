When you create a {+Free-cluster+} or a {+Flex-cluster+}, you can
select either {+atlas-infinite-full+} or {+atlas-core-full+}.
However, the database edition you select doesn't impact how that {+cluster+}
operates unless you scale to a {+dedicated-cluster+}. {+service+} automatically
applies the stored database edition selection when you scale to a
{+dedicated-cluster+}, though you can also change the database edition at
that time.

To learn how to select a database edition and scale a Free or Flex cluster
to a {+dedicated-cluster+}, see :ref:`scale-free-flex-cluster`.
