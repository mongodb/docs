agentengine agent
-----------------

Inspect and edit agent configuration.

Synopsis
~~~~~~~~

Inspect and edit agent configuration.

Bump-version and egress use the nearest agent.yaml, resolved the same
way as build and deploy; edits apply on the next agentengine deploy.
Validate reads ./agent.yaml by default. Source reads source.yaml from
the CLI state directory.
