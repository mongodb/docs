.. _om-api-release-license-key:

======================================
Release a License Key from Ops Manager
======================================

.. default-domain:: mongodb

.. meta::
   :description: Release an installed license key from your Ops Manager installation and retrieve the recalculated license key status. This endpoint requires the Global Owner role.

.. contents:: On this page
   :local:
   :backlinks: none
   :depth: 1
   :class: singlecol

Releases a license key from an |mms| installation. Use this endpoint
when the installation no longer needs the license key. |mms|
recalculates the license key status and returns it. |mms| records a
``License released`` audit event.

.. important::

   After you release a license key, you can't use it again. If you
   release the only usable license key, your installation has no
   coverage. The state changes to ``GRACE``, and then to ``UNLICENSED``
   after 90 days. To generate a new license key, see
   :ref:`license-keys-get-and-install`.

Required Roles
--------------

To access this resource, your |api| key must have
the :authrole:`Global Owner` role. The Global Owner role is the
highest role in |mms|. Only users with this role can view and manage
license keys.

Request
-------

Send a ``DELETE`` request with the license key ID in the path.

.. include:: /includes/api/base-api-uri.rst

.. code-block:: http

   DELETE /admin/licenses/{artifactId}

Request Path Parameters
~~~~~~~~~~~~~~~~~~~~~~~

The request path contains the following parameter:

.. list-table::
   :header-rows: 1
   :widths: 20 15 15 50
   :stub-columns: 1

   * - Parameter
     - Type
     - Necessity
     - Description

   * - ``artifactId``
     - string
     - Required
     - Unique identifier of the license key to release. Retrieve this
       value from the ``licenses[n].artifactId`` field of the
       :ref:`om-api-get-license-key-status` response.

Response
--------

If |mms| releases the license key, the response contains the
recalculated license key status. The response contains the following
fields:

.. include:: /includes/api/license-key-status-response-fields.rst

Errors
~~~~~~

If you specify an ``artifactId`` that doesn't match an installed license
key, the endpoint returns the HTTP status ``404``. The ``errorCode``
field of the response body contains ``ARTIFACT_NOT_FOUND``, and the
``detail`` field contains ``No installed artifact with that id.``

Example Request
---------------

Use ``curl`` to send a ``DELETE`` request to the ``/admin/licenses/{artifactId}`` endpoint:

.. code-block:: sh

   curl --user "{PUBLIC-KEY}:{PRIVATE-KEY}" --digest \
        --header "Accept: application/json" \
        --include \
        --request DELETE \
        "https://{+opsmgr-url+}/api/public/v1.0/admin/licenses/{ARTIFACT-ID}?pretty=true"
