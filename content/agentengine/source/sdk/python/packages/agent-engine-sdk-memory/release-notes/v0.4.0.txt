agent-engine-sdk-memory v0.4.0
==============================

What's new
----------

- Ranked taxonomic search across backends.
  ``search_taxonomic(query=...)`` now runs a ranked similarity search,
  optionally filtered by ``domain``, the same as ``search_semantic`` and
  ``search_episodes``. Taxonomic search was previously unavailable on
  the hosted Gateway.
- Tool-call and model metadata on the hosted Gateway.
  ``record_turn(...)`` now accepts and forwards ``tool_calls``,
  ``tool_call_id``, ``tool_name``, ``is_error``, and ``model_name`` on
  the hosted Gateway, matching the local OE. These were previously
  rejected before the request was sent, so agents recording tool turns
  can now do so against the hosted service.

Breaking changes
----------------

- **Direct (OE) ``search_taxonomic`` is now ranked, not a listing.** It
  previously returned an unranked list of all matching entries and
  ignored ``query`` (emitting a ``UserWarning``); it now returns
  query-ranked results. Callers that relied on the unranked listing
  should read taxonomic entries via the taxonomic CRUD list route
  instead.
