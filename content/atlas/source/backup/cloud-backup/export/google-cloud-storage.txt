=========================================================
Export {+Cloud-Backup+} Snapshots to Google Cloud Storage
=========================================================

.. default-domain:: mongodb

.. contents:: On this page
   :local:
   :backlinks: none
   :depth: 2
   :class: singlecol

.. include:: /includes/fact-atlas-free-tier-limits.rst

|service| lets you export your {+Cloud-Backup+} snapshots to {+gcs+}
buckets automatically or manually. To configure and run exports, use the
procedure that matches the type of export that you want:

- To automatically export snapshots as your :ref:`backup policy
  <configure-backup-policy>` creates them, see
  :ref:`cloud-backup-configure-snapshot-policy-gcp`.
- To manually export a single existing snapshot, see
  :ref:`cloud-backup-create-export-job-gcp`.

Each procedure requires the same
:ref:`prerequisites <cloud-backup-export-prereqs-gcp>`.

For an overview of how {+service+} exports snapshots and the files it
uploads, see :ref:`cloud-provider-snapshot-export`.
