Overview
--------

In this guide, you can learn how to use the {+driver-short+} to run {+search+}
queries on a collection. {+search+} enables you to perform full-text searches on
your collections. {+search+} indexes specify the behavior of the search and the
fields to index.

To learn how to create and manage {+search+} indexes by using the
{+driver-short+}, see the :ref:`scala-atlas-search-index` guide.

Sample Data
~~~~~~~~~~~

The examples in this guide use the ``movies`` collection in the
``sample_mflix`` database from the :ref:`Atlas sample datasets
<atlas-sample-data>`. To learn how to create a free MongoDB Atlas cluster
and load the sample datasets, see
:ref:`Get Started with Atlas <unified-get-started>`.

Run a MongoDB Search Query
--------------------------

.. note::

   {+search+} is available on the following deployments:

   - MongoDB Atlas v4.2 or later
   - MongoDB Community Edition v8.2 or later

   Your collection must have a {+search+} index to run {+search+}
   queries. To learn how to create a {+search+} index, see the
   :ref:`scala-atlas-search-index` guide.

To perform a full-text search, call the ``aggregate()`` method with
a ``$search`` pipeline stage. The {+driver-short+} provides the
``Aggregates.search()`` helper method to create this stage. The
``search()`` method requires the following arguments:

- ``SearchOperator`` instance that specifies the field and text
  to search for
- ``SearchOptions`` instance that specifies options to customize
  the search, including the name of the {+search+} index to use

The following example searches the ``title`` field for the text ``"Alabama"``
and projects only the ``_id`` field, which is included by default, and the
``title`` field of matching documents:

.. io-code-block::
   :copyable: true

   .. input:: /includes/mongodb-search.scala
      :start-after: start-search-query
      :end-before: end-search-query
      :language: scala
      :dedent:

   .. output::
      :visible: false

      {"_id": {"$oid": "..."}, "title": "Alabama Moon"}
      {"_id": {"$oid": "..."}, "title": "Crazy in Alabama"}
      {"_id": {"$oid": "..."}, "title": "Sweet Home Alabama"}

.. tip::

   To view {+search+} tutorials in the Atlas documentation,
   see :atlas:`Run Atlas Search Queries </atlas-search/tutorials/>`.

MongoDB Search Metadata
-----------------------

.. note::

   {+search+} metadata is available on the following deployments:

   - MongoDB Atlas v4.4.11 or later
   - MongoDB Community Edition v8.2 or later

Use the ``Aggregates.searchMeta()`` helper method to retrieve only
the metadata from a {+search+} query without returning the search
results. The following example returns metadata for a query that
searches the ``year`` field for values near ``2010``:

.. io-code-block::
   :copyable: true

   .. input:: /includes/mongodb-search.scala
      :start-after: start-search-meta
      :end-before: end-search-meta
      :language: scala
      :dedent:

   .. output::
      :visible: false

      {"count": {"lowerBound": 35}}
