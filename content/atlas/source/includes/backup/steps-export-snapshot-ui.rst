.. procedure:: 
   :style: normal

   .. include:: /includes/nav/steps-backup-details.rst

   .. step:: In the :guilabel:`Snapshots` tab, click the :icon-fa5:`ellipsis-v` :guilabel:`Actions` menu for the snapshot you want to export.

      This displays the snapshot details.

   .. step:: From the dropdown, select :guilabel:`Export`.

      This displays the :guilabel:`Export Snapshot` dialog box.

   .. step:: From the :guilabel:`Export Bucket` dropdown, select the export bucket you want to use.

   .. step:: Click :guilabel:`Export`.

      This starts the export job and displays the :guilabel:`Exports` tab.

   .. step:: Click :guilabel:`Refresh` to view the export job status.
