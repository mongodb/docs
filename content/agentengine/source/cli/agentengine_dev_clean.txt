agentengine dev clean
---------------------

Stop containers and remove generated local artifacts.

.. code-block:: bash

   agentengine dev clean [flags]

Options
~~~~~~~

.. code-block:: bash

         --all                Monorepo: target the all-workspaces stack
     -h, --help               help for clean
         --workspace string   Monorepo: target a specific agent by name (from root agent.yaml)

~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. code-block:: bash

         --log-file string    override log file path
         --log-level string   file log verbosity (error|warn|info|debug) (default "info")
         --no-log             disable file logging
     -q, --quiet              silence stderr below error
     -v, --verbose count      raise stderr verbosity (-v info, -vv debug)
