*Released 2026-08-12*

We are pleased to announce version 100.18.0 of the MongoDB Database
Tools.

The highlight for this release is MongoDB Server 9.0 support. This
release also adds builds for SUSE 16, Debian 13, Ubuntu 26.04, and
RHEL 10 on ppc64le and s390x, and upgrades to Go 1.26.5.
