.. _agentengine_completion_zsh:

agentengine completion zsh
--------------------------

Generate the autocompletion script for zsh

Synopsis
~~~~~~~~

Generate the autocompletion script for the zsh shell.

If shell completion is not already enabled in your environment you will
need to enable it. You can execute the following once:

.. code-block:: bash

   echo "autoload -U compinit; compinit" >> ~/.zshrc

To load completions in your current shell session:

.. code-block:: bash

   source <(agentengine completion zsh)

To load completions for every new session, execute once:

Linux:
^^^^^^

.. code-block:: bash

   agentengine completion zsh > "${fpath[1]}/_agentengine"

macOS:
^^^^^^

.. code-block:: bash

   agentengine completion zsh > $(brew --prefix)/share/zsh/site-functions/_agentengine

You will need to start a new shell for this setup to take effect.

.. code-block:: bash

   agentengine completion zsh [flags]

Options
~~~~~~~

.. code-block:: bash

     -h, --help              help for zsh
         --no-descriptions   disable completion descriptions
