==============================
$median (accumulator operator)
==============================

.. meta::
   :description: Use $median in $group, $bucket, and $bucketAuto stages to return the approximate median (50th percentile) across a group of input documents. Added in MongoDB 7.0.

.. contents:: On this page
  :local:
  :backlinks: none
  :depth: 1
  :class: singlecol

.. Substitution used in includes and in the body of this text
.. |operatorName| replace:: ``$median``

Definition
----------

.. group:: $median

   .. versionadded:: 7.0

   .. include:: /includes/aggregation/fact-return-median-accumulator.rst

The ``$median`` accumulator is available in these stages:

- :pipeline:`$bucket`
- :pipeline:`$bucketAuto`
- :pipeline:`$group`

.. note:: Disambiguation

   This page describes ``$median`` when used as an **accumulator**.
   Accumulators return an aggregated value across a group of input
   documents.

   You can also use ``$median`` in these other contexts:

   - :expression:`$median (expression) <$median>`, which returns
     the median of an array of values within a single document.
   - :window:`$median (window function) <$median>`, which is used in
     the :pipeline:`$setWindowFields` stage to return the median
     value from documents in a window.

Syntax
------

.. code-block:: javascript
   :copyable: false
   :category: syntax example

   {
      $median: {
         input: <number>,
         method: <string>
      }
   }

Command Fields
~~~~~~~~~~~~~~

|operatorName| takes the following fields:

.. list-table::
   :header-rows: 1
   :widths: 15 17 17 51

   * - Field
     - Type
     - Necessity
     - Description

   * - ``input``
     - Expression
     - Required
     - |operatorName| calculates the 50th percentile over the values
       returned by this expression. ``input`` must be an expression
       that evaluates to a numeric type. If the expression does not
       evaluate to a numeric type, the |operatorName| calculation
       ignores that value.

   * - ``method``
     - String
     - Required
     - The method that ``mongod`` uses to calculate the 50th percentile
       value. The method must be ``'approximate'``.

Behavior
--------

When used as an accumulator, ``$median``:

- Calculates a single result for all the documents in the group.
- Uses the `t-digest <https://arxiv.org/abs/1902.04023>`__ algorithm for
  calculation of approximate percentiles. Approximation is necessary to
  calculate the median using a data structure of bounded size.

Calculation Considerations
~~~~~~~~~~~~~~~~~~~~~~~~~~

When used as an accumulator, ``$median`` always uses an approximation
algorithm. As a result, the computed percentiles ``$median`` returns on
the same data set might differ on each run, due to pseudorandomness in
the t-digest approximation algorithm. Additionally, ``$median`` may
return a value that differs slightly from the true statistical median.

The following example uses ``$median`` to calculate the median IMDb
rating of Action movies per year from 2000 to 2004:

In the preceding pipeline:

- :pipeline:`$match` filters for Action movies released between 2000
  and 2004 with a valid IMDb rating.
- :pipeline:`$group` groups documents by ``year`` and uses ``$median``
  to calculate the median ``imdb.rating`` across all Action movies in
  each year.
- :pipeline:`$sort` sorts the results by year in ascending order.
